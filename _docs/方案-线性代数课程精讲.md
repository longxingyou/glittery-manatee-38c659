### 2.3 公式实测（最关键的一条）

**不依赖 OCR，从 PDF 字形几何直接重建 LaTeX —— 已跑通。** 对 Axler p116（三角不等式证明）：

```
|w+z|^{2}=(w+z)(\overline{w}+z)
=|w|^{2}+ |z|^{2}+2 Re(wz)
=(|w| + |z|)^{2}.
```

上标 `^{2}`、共轭 `\overline{w}` 都还原了。原理：

- 正文 10.5pt、上下标 7.0pt，**字号即可分辨**
- 基线偏移判上/下标（y 比正文基线高 → 上标）
- 共轭横线/根号线是**矢量线段**，`page.get_drawings()` 能取到，与下方字形 x 区间配对即得上划线

**但**：同一实测也暴露了反面 —— 该页矩阵与 `∑` 区域是这样的原始文本：

```
𝑛
∑
𝑟=1
```

纵向结构全塌。所以几何重建只解决**行内公式**，显示公式块必须走第二层。

### 4.4 「去书本化」写作规范（**v2 新增，最高优先级**）

这是 v2 相对 v1 最本质的改动。**讲义是知识梳理，不是某本书的导读。**

#### 必须遵守

| 规则 | ✗ 不要写 | ✓ 应该写 |
|---|---|---|
| **不用"本书/原书"作主语** | 「本书 1.20 定义向量空间」 | 「向量空间的定义是……」 |
| **不默认读者手上有某本书** | 「请翻到 p24 对照」 | 「这条性质的出处见文末延伸（可选）」 |
| **不按书的章节组织内容** | 「第 1 章 向量空间」 | 「向量空间」 |
| **不把书的结构当知识结构** | 「Axler 故意只写六条」 | 「有的教材写八条、有的写六条，内容一致」 |
| **出处只作旁注** | 正文反复引用编号 | 文末「出处与延伸」一节集中给 |

#### 允许并鼓励

- **说清某个说法来自哪里**（这是可追溯性，不是书本导向）：
  > 例：「把性质拆成八条公理的写法在国内教材里更常见；拆成六条命名性质的写法见于一些英文教材。」
  > 例：「『特征值』也译作『本征值』，两种译法都通行。」
- **并列不同来源的视角**，让读者自己形成判断：
  > 例：「行列式有三种讲法：① 排列与逆序数的组合定义；② 公理化定义（多重线性 + 交错 + 归一）；③ 作为体积的缩放因子。本讲讲 ①，第 37 讲讲 ②③。」
- **在文末集中给出处**，格式：`书名（版本）+ 页码`，明确标「可选回查」。

#### 章节标题规范

- 标题只写**知识主题**，不写书名、不写「某书第 X 章」。
- 讲次编号用**本课程自己的连续序号**（01–38），不用「1A/3C/9D」这类**书内字母编号**。
  > 这条在 v1 里写反了（当时写「保留 3C 这类编号」）。字母编号并非本课程的结构，
  > 它直接来自某本教材的分节，一旦换书就对不上——已全部改掉。

#### 为什么这样改

1. 后续要并入更多书的内容（行列式入门、Bronstein、其他教材），**主题轴才能容纳多源**；章节轴一旦绑死一本书，第二本书进来就会打架。
2. 读者不需要为了看懂讲义先去买一本书。
3. 出处仍然保留 → 准确性可追溯，但"读讲义"与"读某本书"解耦。

**关于「第 10 版」的一个重要澄清**（差点误判）：

publ.lib.ru 将该书 1962 年版标为「**Издание 10-е стереотипное**」（第 10 版·定型），
但打开 PDF，封面内页印的是「**Издание девятое стереотипное**」（第 **9** 版·定型）。

两者都对，不是拿错书：**`стереотипное`（定型影印）指用第 9 版的印版重印**，
内容一字不改，版本号递增而书内页不更新。页数 610 与书商著录的 608 页（+2 封面）吻合，
可确认这就是**第 10 版**。所以：**内容等同于第 9 版，版本号是第 10 版。**

> [!important] 为什么中文版/英文版都称不上「第 10 版」
> 英文版只出到第 6 版（2015）；德文版才有第 10 版（Harri Deutsch 2016）。
> 而**俄文原著**的第 10 版就是 1962 年这一版 —— 这才是「Bronstein 第 10 版」最正统的所指。

#### 两版分工（互补，不是重复）

| | 俄文第 10 版 | 英文第 6 版 |

## 五、公式方案（三层，按代价从低到高）

决策树：

```
遇到一段数学内容
├─ 行内（夹在中文行里）
│   └─ L1 几何重建 → 人工校一遍（量不大，每讲 10–30 处）
├─ 显示块（独立成行）
│   ├─ 简单（无 ∑/矩阵/分式/根号） → L1 重建 + 加 $$ 包装
│   └─ 复杂（有 ∑上下限 / 矩阵 / 分式 / 根号 / 长推导）
│       ├─ L2 裁图 → FormulaRecognitionPipeline → LaTeX（首选）
│       │     └─ 识别结果人工验算；错则退 L3
│       └─ L3 裁图 → 存 png → `![](ch9/eq-09-2.png)`（兜底，保证不出错）
└─ 图/示意图 → 裁图，L3 处理
```

| 层 | 手段 | 已实测 | 适用 | 代价 |
|---|---|---|---|---|
| **L1** | PyMuPDF span 几何重建（字号判上下标、矢量线判上划线） | ✅ 已跑通（`\overline{w}`、`^{2}` 正确） | 行内公式为主 | 极低，纯 CPU，无模型 |
| **L2** | 裁区域 → `FormulaRecognitionPipeline` → LaTeX | ⚠️ **仅确认可导入，未测准确率** | 矩阵 / `∑` / 分式 | 中，需模型权重 |
| **L3** | 裁图存 png + `![]()` | ✅ 站点支持 | 兜底 + 真·图 | 低 |

### L1 实测：能做什么 / 不能做什么（跨 4 章抽样后如实记录）

在「09 矩阵」「17 不变子空间」「23 规范正交基」「37 行列式」四页上跑过，结论：

**✅ L1 可靠重建的**（正确率目测 ≥90%，且错了也是一眼能看出的人名/符号级差错）
```
Tv_{k}=A_{j,k}w_{j}．
V=V_{1}⊕· · · ⊕V_{m}，
⟨e_{j}, e_{k}⟩=
F^{n} 的标准基是一个规范正交组．
|w+z|^{2}+2 Re(wz)   （含 \overline）
```

**❌ L1 明确处理不了，必须交 L2/L3 的**
| 形态 | 实测错样 | 原因 |
|---|---|---|
| `∑` 带上下限 | `∑^{m}`（下限丢失、被当成上标） | 大算符的上下限在版面里是**另一行**，y 距离超出下标阈值 |
| 根号 / 分式 | `√^{1}`、`(b)√^{1},√^{1},…` | 根号是矢量路径 + 分式无基线关系 |
| 矩阵 | 整块塌成一行 | 括号是矢量/独立字形，行结构不成立 |
| 上标里再套括号 | `V_{alt}^{(}^{M}^{)}` | 括号单独成小字号 span，被误判为脚本 |

**⚠️ L1 需要人工兜底的两类**
- 限制记法 `T|_{V_k}` → 输出 `T|_{V}_{k}`（差一个括号，需人工并成 `T|_{V_k}`）
- 元音上方的**重音/横线**与 `\overline` 存在少量误判（如把网格线当上划线）

### 一个必须写进代码的坑（已踩）

Unicode 数学斜体的名称是 `MATHEMATICAL ITALIC SMALL K` —— **末位词是大写 `K`**。
按「取名称最后一个词」做映射会把所有小写字母变成大写（实测整页 `v_{k}` 全成 `V_{K}`）。
正确做法：看名称里是 `SMALL` 还是 `CAPITAL` 决定大小写。

### L1 的定位（重要，别高估）

L1 是**半自动草稿器**，不是产出器。它的三个真实价值：

1. 把**行内公式**的上下标/上划线救回来（这是 OCR 反而做不好的地方）
2. 告诉你**每一页的显示公式块在哪**（给出 bbox，供 L2 裁图）
3. 给出**可直接复用的中文正文**（文本层质量本身很好）

所以流程是：`L1 出草稿 → 人按讲稿骨架重写 → 显示块走 L2/L3 → KaTeX 自检`。
这也意味着**每讲都要人过一遍公式**，不能指望脚本一键出稿。

我**没有**### 关于 L2 的诚实说明

我**没有**验证它的实际识别准确率（模型权重尚未下载，跑一次要拉几百 MB）。所以实施方案的第一步就是**L2 校准实验**：

- 取 20 个已知答案的显示公式（矩阵、`∑`、分式、根号各 5）
- 跑 `FormulaRecognitionPipeline`，逐条比对
- **验收线：≥15/20 完全正确**才算 L2 可用；否则本课改为「L1 + L3 为主」，显示公式一律贴图

这条线必须先测，因为它决定整门课 40% 的工作量（贴图多 = 手工裁图多）。

### 输出规范化（L1/L2 都要过这一道）

1. Unicode 数学斜体 → ASCII：`𝑤→w`、`𝐴→A`（用 `unicodedata.name` 判定，勿硬编码）
2. 上标 `^{}` / 下标 `_{}` 必须显式
3. 矩阵 → `pmatrix` / `bmatrix` / `vmatrix`（**行列式**用 `vmatrix`，别混）
4. 多行等号对齐 → `aligned`，`&` 卡在 `=`
5. 编号 → `\tag{}`
6. 过一遍 KaTeX 渲染检查（§九·脚本 2）
