# 线性映射

> **这讲讲什么**：向量空间之间「保结构」的映射——为什么只需查两条（可加与齐次）、一批必须自己验的例子、以及全体线性映射 $\mathcal{L}(V,W)$ 自己也是一个向量空间
> **前置**：向量空间、子空间（01–03）；读到第三节后半会用一次「基」（05），但概念上不依赖它
> **一句话**：线性映射是**线性组合的搬运工**——先把向量组合再送过去，和先把向量送过去再组合，结果一样。

---

## 一、为什么需要它

前六讲我们一直在**一个**空间内部打转：向量、向量空间、子空间、张成、线性无关、基、维数。这些词回答的都是同一类问题——「这个空间里有什么」「哪些向量是多余的」。

但线性代数还有另一半，而且往往是更重要的那一半：**空间与空间之间怎么走**。

一个自然的想法立刻冒出来：一个空间到另一个空间的函数多得数不清（想想 $\mathbb{R}\to\mathbb{R}$ 上那些千奇百怪的曲线），总得挑出「讲道理」的那一类。什么叫讲道理？**保持结构**。

这就是整门课的转折点。前六讲造出了「向量空间」这个结构，从这一讲起，我们开始看**两个结构之间保持运算的映射**。这类映射在数学里有个通名——**同态**：群与群之间的同态保持群运算，环与环之间的同态保持加与乘，向量空间与向量空间之间的同态保持加法与标量乘法，而它在本课的名字就是**线性映射**。

于是关键问题变成：既然叫「保持结构」，那到底要保持多少条？

答案短得出人意料：**两条**。

原因是结构本身就只有两样东西。回顾 02 讲：一个向量空间 = 一个集合 + **加法** + **标量乘法** + 六条规矩。而六条规矩里的交换、结合、分配、单位律，全都是关于「这两种运算怎么配合」的说明；真正属于「运算」这个身份的，只有加法与标量乘法两个**原子操作**。

顺着这层观察往下推：

- 向量空间里任何一个用有限次运算写出来的式子，追根到底都是 $c_1v_1+\cdots+c_nv_n$ 这种**线性组合**；
- 如果加法与标量乘法这两步都被保住了，那么「先组合再送过去」和「先送过去再组合」必然处处一致；
- 一旦如此，零元、逆元、交换、结合、分配这些性质**自动跟着迁移**过去。

所以「保持结构」被压缩成两条要求（下一节正式写出）。这也顺便解释了一个常见困惑：为什么线性映射的定义里**没有**「$T(0)=0$」这一条？因为它不是独立要求，而是两条的**推论**（第三节会给两个证法）。

读完这一讲，你应该能回答：

1. 为什么判定线性只要查两条？这两条能不能合成一条？
2. 为什么 $x\mapsto x^2$ 和 $x\mapsto x+1$ 都不是线性映射，而它们「卡住」的地方并不相同？
3. 只满足其中一条、不满足另一条的函数长什么样？
4. 从 $V$ 到 $W$ 的**全体**线性映射，为什么自己也是一个向量空间？
5. 两个线性映射能「相乘」吗？为什么这个乘法不满足交换律？

## 二、定义与最小例子

### 定义：两条要求

设 $V$ 与 $W$ 都是同一个数域 $\mathbb{F}$ 上的向量空间。函数 $T:V\to W$ 称为**线性映射**，如果下面两条同时成立。

**① 可加性（additivity）**：对所有 $u,v\in V$，

$$\forall u,v\in V:\quad T(u+v)=Tu+Tv$$

**② 齐次性（homogeneity）**：对所有 $\lambda\in\mathbb{F}$ 和所有 $v\in V$，

$$\forall\lambda\in\mathbb{F},\ \forall v\in V:\quad T(\lambda v)=\lambda(Tv)$$

两条要读准的地方：

- 「对所有」就是**对所有**。要否定它，只需找到**一对** $u,v$ 或**一个** $\lambda,v$ 让等式失败；要证明它，则必须对任取的 $u,v,\lambda$ 都推出等式。
- 等式左右两边的加法**不是同一个加法**。$u+v$ 是 $V$ 里加的，$Tu+Tv$ 是 $W$ 里加的；同理 $\lambda v$ 是 $V$ 里的标量乘，$\lambda(Tv)$ 是 $W$ 里的。线性映射的职责，正是在两个空间各自的运算之间当翻译。
- 记号上，$T(v)$ 与 $Tv$ 混用，没有区别。写成 $Tv$ 是为了让 $Tv$ 看起来更像一个「被 $T$ 作用后得到的向量」。

> [!note] 「齐次」这个词的两种用法
> 这里的齐次性专指**一次**齐次：$T(\lambda v)=\lambda Tv$。
> 数学分析里说的「$k$ 次齐次函数」是另一个概念（$f(\lambda x)=\lambda^k f(x)$）。
> 两者只在 $k=1$ 时重合。看到「齐次」二字，先确认是哪一种。

### 两条其实可以合成一条

把可加性与齐次性打包，得到一个**等价**的说法：对所有 $\lambda,\mu\in\mathbb{F}$ 和所有 $u,v\in V$，

$$\forall\lambda,\mu\in\mathbb{F},\ \forall u,v\in V:\quad T(\lambda u+\mu v)=\lambda Tu+\mu Tv$$

两个方向的换算都很短：

- **两条 ⟹ 一条**：$T(\lambda u+\mu v)=T(\lambda u)+T(\mu v)=\lambda Tu+\mu Tv$。第一步用可加性，第二步用两次齐次性。
- **一条 ⟹ 两条**：取 $\lambda=\mu=1$，得 $T(u+v)=Tu+Tv$，即可加性；取 $\mu=0$，得 $T(\lambda u)=\lambda Tu$（用 $0\cdot Tv=0$），即齐次性。

> [!tip] 既然一条够用，为什么定义要写两条
> 因为**做题时一条更省事，找反例时两条更好用**。
> 判定线性：一次验完 $T(\lambda u+\mu v)=\lambda Tu+\mu Tv$ 最省笔。
> 否定线性：分别去撞「可加」和「齐次」这两道门，命中率更高——而且第五节会看到，**这两道门各自都能被单独撞破**，谁也替代不了谁。

### 记号：$\mathcal{L}(V,W)$ 与 $\mathcal{L}(V)$

把「线性映射」当成一类对象之后，立刻要对这类对象命名。

- 从 $V$ 到 $W$ 的**全体**线性映射构成的集合，记作 $\mathcal{L}(V,W)$；
- 从 $V$ 到 $V$ 的全体线性映射构成的集合，记作 $\mathcal{L}(V)$，也就是 $\mathcal{L}(V)=\mathcal{L}(V,V)$。

「$T\in\mathcal{L}(V,W)$」与「$T:V\to W$ 是线性映射」是同一句话，前者更省事，后面会一直用。

> [!important] 为什么要把 $V\to V$ 单独命名
> 因为「同一个空间到自身」的映射能**首尾相接**（复合），能谈「反复作用」「不变子空间」「特征值」——这些是整个第三部分的主题。
> 本课把 $V\to V$ 的线性映射叫**算子**。
> 有些教材把算子也叫「线性变换」，于是「线性变换」在不同语境下时宽时窄，读的时候留意一下定义域和值域是不是同一个空间。

### 八个最小例子（每个都该自己验一遍）

下面这些例子是「线性映射」这个概念的实物样本。**不要只是读过去**：挑两三个，拿两条要求动手验一遍，手感完全是另一回事。

| 名字 | 定义 | 住在哪 |
|---|---|---|
| 零映射 | $0\,v=0$ | $\mathcal{L}(V,W)$ |
| 恒等算子 | $Iv=v$ | $\mathcal{L}(V)$ |
| 微分映射 | $Dp=p'$ | $\mathcal{L}(\mathcal{P}(\mathbb{R}))$ |
| 积分映射 | $Tp=\int_0^1 p$ | $\mathcal{L}(\mathcal{P}(\mathbb{R}),\mathbb{R})$ |
| 与 $x^2$ 相乘 | $(Tp)(x)=x^2p(x)$ | $\mathcal{L}(\mathcal{P}(\mathbb{R}))$ |
| 后向移位 | $T(x_1,x_2,x_3,\dots)=(x_2,x_3,\dots)$ | $\mathcal{L}(\mathbb{F}^\infty)$ |
| 具体数值例 | $T(x,y,z)=(2x-y+3z,\ 7x+5y-6z)$ | $\mathcal{L}(\mathbb{R}^3,\mathbb{R}^2)$ |
| 多项式复合 | $(Tp)(x)=p(q(x))$，$q$ 是固定多项式 | $\mathcal{L}(\mathcal{P}(\mathbb{R}))$ |

> [!warning] 零映射里的两个 $0$ 不是同一个东西
> $0v=0$ 这条定义里，左边的 $0$ 是**函数**（从 $V$ 到 $W$ 的那个零线性映射），
> 右边的 $0$ 是 $W$ 中的**加法恒等元**（一个向量）。
> 同一个符号承担两种角色，只能靠上下文区分。
> 这与 01 讲的提醒是同一条：**判断一个 $0$ 是什么，看它在哪个空间里、配的是什么运算。**

**逐条验算三个代表。**

*后向移位。* 记 $x=(x_1,x_2,\dots)$、$y=(y_1,y_2,\dots)$：

$$T(x+y)=T(x_1+y_1,\ x_2+y_2,\dots)=(x_2+y_2,\ x_3+y_3,\dots)=(x_2,x_3,\dots)+(y_2,y_3,\dots)=Tx+Ty$$

$$T(\lambda x)=T(\lambda x_1,\lambda x_2,\dots)=(\lambda x_2,\lambda x_3,\dots)=\lambda(x_2,x_3,\dots)=\lambda Tx$$

两条都过。**这里的「扔掉第一个坐标」之所以不破坏线性，是因为它对所有位置一视同仁、且从不回头看。** 如果改成「把第一个坐标扔掉、再把剩下的每个都平方」，立刻就不线性了。

*与 $x^2$ 相乘。* 这里 $T$ 作用在多项式上，而两条要求要在**函数层面**验证。对任意 $p_1,p_2$ 和任意 $x$：

$$(T(p_1+p_2))(x)=x^2(p_1+p_2)(x)=x^2\big(p_1(x)+p_2(x)\big)=(Tp_1)(x)+(Tp_2)(x)$$

因为对每个 $x$ 都成立，所以两个多项式相等，即 $T(p_1+p_2)=Tp_1+Tp_2$。齐次性同理：$(T(\lambda p))(x)=x^2\lambda p(x)=\lambda(Tp)(x)$。

*具体数值例 $T(x,y,z)=(2x-y+3z,\ 7x+5y-6z)$。* 设 $u=(x,y,z)$、$v=(x',y',z')$：

$$\begin{aligned}T(u+v)&=T(x+x',\ y+y',\ z+z')\\&=\big(2(x+x')-(y+y')+3(z+z'),\ 7(x+x')+5(y+y')-6(z+z')\big)\\&=(2x-y+3z,\ 7x+5y-6z)+(2x'-y'+3z',\ 7x'+5y'-6z')\\&=Tu+Tv\end{aligned}$$

齐次性同样是一行：每个分量都恰好是 $x,y,z$ 的**一次齐次式**，所以 $\lambda$ 可以整体提出来。

> [!success] 从这三个验算里能提炼出一条判据
> 只要每个输出分量都是输入变量的**一次齐次表达式**（没有常数项、没有乘积项、没有平方项、没有绝对值、没有三角函数），
> 并且不出现「某个位置特殊对待」的规则，那么它多半就是线性映射。
> 第五节和第 3.2 小节会把这条判据反过来用：**带常数项的、带乘积项的，一律出局。**

### 一般形式：$\mathbb{F}^n\to\mathbb{F}^m$ 的线性映射长什么样

上面那个 $\mathbb{R}^3\to\mathbb{R}^2$ 的例子可以整体推广。取定一批标量 $A_{j,k}\in\mathbb{F}$（$j=1,\dots,m$；$k=1,\dots,n$），定义

$$T(x_1,\dots,x_n)=(A_{1,1}x_1+\cdots+A_{1,n}x_n,\ \dots,\ A_{m,1}x_1+\cdots+A_{m,n}x_n)$$

这就是从 $\mathbb{F}^n$ 到 $\mathbb{F}^m$ 的线性映射；而且**反过来，每个从 $\mathbb{F}^n$ 到 $\mathbb{F}^m$ 的线性映射都必然是这种形式**。把那些系数按位置摆成一张表，就是 09 讲的主角——**矩阵**。这里先记住结论：$\mathbb{F}^n\to\mathbb{F}^m$ 的线性映射，一个不多一个不少，全部由 $mn$ 个数决定。

### 三个「看着像线性其实不是」的

**一、$x\mapsto x^2$。** 两条全败。可加性：$T(1+2)=9$，而 $T(1)+T(2)=1+4=5$。齐次性：$T(2\cdot 3)=36$，而 $2T(3)=18$。平方把「先加再平方」和「先平方再加」彻底分开了。

**二、$x\mapsto\cos x$。** 有人会误以为余弦是线性的——毕竟它看起来那么规整。可加性一试就倒：取 $x=y=0$，左边 $\cos 0=1$，右边 $\cos 0+\cos 0=2$。齐次性也倒：$\cos 2x$ 一般不等于 $2\cos x$。

**三、带「低次杂项」的表达式。** 设 $b,c\in\mathbb{R}$，定义

$$T(x,y,z)=(2x-4y+3z+b,\ 6x+cxyz)$$

这个 $T$ 是线性的，**当且仅当 $b=c=0$**。

- $b\neq0$ 时出局：$T(0,0,0)=(b,0)\neq(0,0)$；
- $c\neq0$ 时出局：取 $v=(1,1,1)$、$\lambda=2$。左边 $T(2,2,2)$ 的第二个分量是 $12+8c$，右边 $2T(1,1,1)$ 的第二个分量是 $12+2c$，两者相等要求 $8c=2c$，即 $c=0$。

反过来，$b=c=0$ 时 $T(x,y,z)=(2x-4y+3z,\ 6x)$ 是每个分量都一次齐次的形式，确实线性。

> [!important] 这三例的教益
> 线性映射的「敌人」只有几种：**常数项**（把原点搬走）、**乘积项**（$xy$、$xyz$）、**非线性次幂**（$x^2$）、**特殊位置规则**。
> 判线性时先扫一遍有没有这几样；扫不出可疑项，再老老实实验两条。

## 三、几个必须自己算一遍的结论

### 3.1 线性映射把 $0$ 映到 $0$

**结论**：若 $T:V\to W$ 是线性映射，则 $T(0)=0$（左边的 $0\in V$，右边的 $0\in W$）。

**证明（用可加性）**：把 $V$ 中的零向量写成 $0+0$，再用可加性：

$$T(0)=T(0+0)=T(0)+T(0)$$

这是一个形如 $\alpha=\alpha+\alpha$ 的等式。在两边同时加上 $T(0)$ 的加法逆元：

$$T(0)+(-T(0))=\big(T(0)+T(0)\big)+(-T(0))\ \Longrightarrow\ 0=T(0)$$

右边用了结合律，得 $T(0)+\big(T(0)+(-T(0))\big)=T(0)+0=T(0)$。■

两行证明，值得记住的是其中的**套路**：把一个元素写成「两次自己」的和，再把多出来的那份消掉。这个套路在群论、环论里会被反复使用。

**另一个证法（用齐次性）**：任取 $v\in V$，取 $\lambda=0$：

$$T(0)=T(0\cdot v)=0\cdot Tv=0$$

> [!important] 由此得到一条非常有用的判据（必要条件）
> **两条要求中的任意一条，单独就已经蕴含 $T(0)=0$。**
> 所以只要发现 $T(0)\neq0$，就可以立刻宣布「不是线性映射」，后面两条根本不用验。
>
> 但反过来绝对不行：$T(0)=0$ 只是**必要条件**。$x\mapsto x^2$ 满足 $T(0)=0$，却并不线性；
> $(x,y)\mapsto xy$ 也满足，也不线性。**必要条件拦不住的东西，还得靠两条原判据去拦。**

顺带一条同样一行的结论：取 $\lambda=-1$，得

$$T(-v)=(-1)\,Tv=-Tv$$

也就是说线性映射自动把逆元送到逆元。

### 3.2 常数项的例子：$f(x)=mx+b$ 何时线性

设 $m,b\in\mathbb{R}$，$f:\mathbb{R}\to\mathbb{R}$ 定义为 $f(x)=mx+b$。**结论**：$f$ 是线性映射，当且仅当 $b=0$。

- $b=0$ 时，$f(x)=mx$。可加性与齐次性都是分配律的直接结果：$m(x+y)=mx+my$，$m(\lambda x)=\lambda(mx)$。✓
- $b\neq0$ 时，$f(0)=b\neq0$，与 3.1 冲突。✗

同一条理由说的是：$x\mapsto x+1$ 也不是线性映射，因为它把 $0$ 送到 $1$。几何上它是**平移**——而平移把原点搬走了，线性结构的地基（「以原点为基准做伸缩与叠加」）也就跟着塌了。

> [!warning] 一个必须点明的术语冲突
> 高中数学把 $y=mx+b$ 叫「一次函数」，有的地方还叫「线性函数」。
> 线性代数里的「线性」**只认 $b=0$ 的那一支**。
> 所以遇到「线性函数」四个字，先问一句：说的是哪个意义？
> 一个稳妥的习惯：不管在哪个语境，**先看它把 $0$ 送到哪**。

### 3.3 线性映射保持一切线性组合

**结论**：若 $T:V\to W$ 线性，$v_1,\dots,v_n\in V$，$c_1,\dots,c_n\in\mathbb{F}$，则

$$T(c_1v_1+\cdots+c_nv_n)=c_1Tv_1+\cdots+c_nTv_n$$

**证明（归纳）**：$n=1$ 就是齐次性。$n=2$ 时「先齐次、再可加」：

$$T(c_1v_1+c_2v_2)=T(c_1v_1)+T(c_2v_2)=c_1Tv_1+c_2Tv_2$$

一般情形对项数 $n$ 归纳：每添一项，先用一次可加性把它与前面的和拆开，再用一次齐次性把系数提出来。■

这条结论是整个第二部分的常用工具，值得配一句口头禅：

> **线性映射是「线性组合的搬运工」——系数一个不动，只把向量换掉。**

它也是下一小节那个引理的直接来源。

### 3.4 线性映射完全由基上的取值决定（线性映射引理）

这是 3.3 最重要的推论，也是后面所有「用矩阵表示线性映射」的合法性来源。

**引理**：设 $v_1,\dots,v_n$ 是 $V$ 的基，$w_1,\dots,w_n$ 是 $W$ 中**任意**给定的一组向量。那么存在**唯一**的线性映射 $T:V\to W$ 使得对每个 $k=1,\dots,n$ 都有 $Tv_k=w_k$。

注意引理里两个方向的力量：

- **存在性**：$w_1,\dots,w_n$ 可以**随便挑**，一定构造得出来一个线性映射；
- **唯一性**：构造出来的这个东西是**唯一**的，没有第二种选择。

**证明（存在性）**：因为 $v_1,\dots,v_n$ 是基，$V$ 中每个元素都能**唯一**地写成 $c_1v_1+\cdots+c_nv_n$（这就是基的定义）。于是可以定义

$$T(c_1v_1+\cdots+c_nv_n)=c_1w_1+\cdots+c_nw_n$$

先确认这是一个**函数**：上面那个写法唯一，所以同一个输入不会对应两个输出。再确认它把基送对了地方：取 $c_k=1$、其余 $c$ 全为 $0$，立刻得到 $Tv_k=w_k$。

最后确认它**线性**。设 $u=a_1v_1+\cdots+a_nv_n$、$v=c_1v_1+\cdots+c_nv_n$，则

$$\begin{aligned}T(u+v)&=T\big((a_1+c_1)v_1+\cdots+(a_n+c_n)v_n\big)\\&=(a_1+c_1)w_1+\cdots+(a_n+c_n)w_n\\&=(a_1w_1+\cdots+a_nw_n)+(c_1w_1+\cdots+c_nw_n)\\&=Tu+Tv\end{aligned}$$

齐次性同理：

$$T(\lambda v)=T(\lambda c_1v_1+\cdots+\lambda c_nv_n)=\lambda c_1w_1+\cdots+\lambda c_nw_n=\lambda Tv$$

于是 $T$ 确实是 $\mathcal{L}(V,W)$ 里的元素。

**证明（唯一性）**：设 $T$ 线性且 $Tv_k=w_k$（$k=1,\dots,n$）。任取 $c_1,\dots,c_n\in\mathbb{F}$。对每个 $k$，齐次性给出 $T(c_kv_k)=c_kw_k$；再用可加性把 $n$ 项并起来：

$$T(c_1v_1+\cdots+c_nv_n)=c_1w_1+\cdots+c_nw_n$$

因为 $v_1,\dots,v_n$ 是基，$V$ 中每个元素都是这种形式，所以 $T$ 在 $V$ 上处处被上式**唯一确定**。■

**手算一例。** 取 $V=\mathbb{F}^2$ 的标准基 $e_1=(1,0)$、$e_2=(0,1)$，指定

$$Te_1=(2,3),\qquad Te_2=(5,7)$$

于是对任意 $(x,y)=xe_1+ye_2$，由 3.3：

$$T(x,y)=x\,Te_1+y\,Te_2=x(2,3)+y(5,7)=(2x+5y,\ 3x+7y)$$

把这两个像并排摆成一张表

$$\begin{pmatrix}2&5\\3&7\end{pmatrix}$$

就是下一讲要正式定义的**矩阵**。这里已经能看出它是怎么来的：**矩阵的每一列，就是基向量被映到的地方。**

> [!important] 这条引理的分量
> 「线性映射」本来是无限自由的对象（一个函数），引理却把它压缩成**有限个数据**：基上取 $n$ 个值。
> - 想在两个空间之间造一个线性映射？只需在基上点几个值，唯一性保证不会造重。
> - 想知道线性映射在某处的值？只需知道它在基上的值，用 3.3 一步步算出来。
>
> 没有这条引理，「矩阵表示线性映射」就无从谈起。可以说，**矩阵的存在全靠这条引理。**

### 3.5 $\mathcal{L}(V,W)$ 上也能定义加法与标量乘法

设 $S,T\in\mathcal{L}(V,W)$，$\lambda\in\mathbb{F}$。定义

$$(S+T)(v)=Sv+Tv,\qquad (\lambda T)(v)=\lambda(Tv)\qquad(\forall v\in V)$$

这两个式子是**定义**，不是发现。两个函数本来没有「相加」这种默认操作，我们**选择**了逐点相加这种最自然的方式，并且接下来要负责证明这个选择没有把空间弄坏。

定义完必须验证一件事：$S+T$ 与 $\lambda T$ **仍然是线性映射**（否则 $\mathcal{L}(V,W)$ 连对加法都不封闭，后面的「是向量空间」就无从谈起）。

以 $S+T$ 的可加性为例：

$$\begin{aligned}(S+T)(u+v)&=S(u+v)+T(u+v)\\&=Su+Sv+Tu+Tv\\&=(Su+Tu)+(Sv+Tv)\\&=(S+T)u+(S+T)v\end{aligned}$$

- 第一步是定义；
- 第二步用的是 $S,T$ **各自**的可加性；
- 第三步调换了 $Sv$ 与 $Tu$ 的次序——**这里用的是 $W$ 中的加法交换律**。$\mathcal{L}(V,W)$ 作为一堆函数，本身并没有交换律，这一步是从 $W$ 借来的。

$S+T$ 的齐次性：

$$(S+T)(\lambda v)=S(\lambda v)+T(\lambda v)=\lambda Sv+\lambda Tv=\lambda(Sv+Tv)=\lambda(S+T)v$$

最后一步是在 $W$ 里提取公因子。$\lambda T$ 的验证更短：

$$(\lambda T)(u+v)=\lambda T(u+v)=\lambda(Tu+Tv)=\lambda Tu+\lambda Tv=(\lambda T)u+(\lambda T)v$$

$$(\lambda T)(\mu v)=\lambda T(\mu v)=\lambda\mu Tv=\mu(\lambda Tv)=\mu\big((\lambda T)v\big)$$

两条都过。所以加法与标量乘法在 $\mathcal{L}(V,W)$ 里是**封闭**的。

### 3.6 $\mathcal{L}(V,W)$ 是向量空间

**结论**：配上 3.5 定义的加法与标量乘法，$\mathcal{L}(V,W)$ 是一个向量空间。

证明的思路只有一句话：**要证两个函数相等，就证它们在每个 $v$ 上取值相等。** 一旦逐点看，$\mathcal{L}(V,W)$ 的每条性质都变成 $W$ 里已经成立的性质。逐条对一遍 02 讲的六条：

| 六条 | 在 $\mathcal{L}(V,W)$ 里怎么过 |
|---|---|
| ① 加法交换 | $(S+T)v=Sv+Tv=Tv+Sv=(T+S)v$，对每个 $v$ 成立，故 $S+T=T+S$ |
| ② 加法结合 | 同样逐点化归到 $W$ 的加法结合律 |
| ③ 加法恒等元 | 取**零映射**：$(T+0)v=Tv+0v=Tv+0=Tv$ |
| ④ 加法逆元 | $T$ 的逆元是 $(-1)T$：$\big(T+(-1)T\big)v=Tv-Tv=0$ |
| ⑤ 乘法恒等元 | $(1T)v=1(Tv)=Tv$ |
| ⑥ 两条分配律、标量结合律 | 逐点化归到 $W$ 的对应性质 |

零元是**零线性映射**，也就是把每个向量都映成 $0$ 的那个映射。

> [!important] 为什么这个结论值得单独占一节
> 它说明：**函数也可以是向量**。这正是 02 讲里函数空间 $\mathbb{F}^S$ 那个思想的延续——
> 只是这里挑出来的函数不是「任意函数」，而是「保持结构的函数」。
> 而且「保持结构的函数」这个集合居然自己就带着一个向量空间结构，这不是定义强加的，是逐点验证得来的。
> 后面几讲都住在这个空间里：零空间与值域是它的支点，矩阵是它的坐标，可逆性问的是它里面的元素能不能倒过来。

### 3.7 乘积：把两个线性映射接起来

设 $T\in\mathcal{L}(U,V)$、$S\in\mathcal{L}(V,W)$。定义**乘积** $ST\in\mathcal{L}(U,W)$ 为

$$(ST)(u)=S(Tu)\qquad(\forall u\in U)$$

它其实就是普通的函数复合 $S\circ T$。当两个函数都是线性的时候，习惯写 $ST$ 而不写 $S\circ T$——因为用乘法记号，下一条的分配律看起来就像数的运算一样自然。

三条必须注意的地方：

1. **读法是从右往左**：$u\ \xrightarrow{\ T\ }\ Tu\ \xrightarrow{\ S\ }\ S(Tu)$。先 $T$，后 $S$。
2. **只有形状对得上才有定义**：$T$ 必须把 $U$ 送进 $S$ 的定义域 $V$ 里。写 $ST$ 之前，先检查中间那个空间是不是同一个。
3. **$ST$ 仍是线性映射**，即 $ST\in\mathcal{L}(U,W)$：

$$(ST)(u+u')=S\big(T(u+u')\big)=S(Tu+Tu')=S(Tu)+S(Tu')=(ST)u+(ST)u'$$

（第一步用定义，第二步用 $T$ 的可加性，第三步用 $S$ 的可加性。）齐次性同理：$(ST)(\lambda u)=S(T(\lambda u))=S(\lambda Tu)=\lambda S(Tu)=\lambda(ST)u$。

### 3.8 乘积的三条代数性质

| 性质 | 写法 | 前提 |
|---|---|---|
| **可结合性** | $(T_1T_2)T_3=T_1(T_2T_3)$ | 每个乘积都有定义（$T_3$ 映进 $T_2$ 的定义域，$T_2$ 映进 $T_1$ 的定义域） |
| **恒等元** | $TI=IT=T$ | 左边的 $I$ 是 $V$ 上的恒等算子，右边的 $I$ 是 $W$ 上的恒等算子 |
| **分配性质** | $(S_1+S_2)T=S_1T+S_2T$ 且 $S(T_1+T_2)=ST_1+ST_2$ | $T,T_1,T_2\in\mathcal{L}(U,V)$，$S,S_1,S_2\in\mathcal{L}(V,W)$ |

> [!warning] $TI=IT=T$ 里的两个 $I$ 不是同一个算子
> 设 $T:V\to W$。
> - 左边的 $I$ 是 **$V$ 上**的恒等算子：先把 $v$ 留在 $V$，再送过去，所以 $TI=T$；
> - 右边的 $I$ 是 **$W$ 上**的恒等算子：先把 $v$ 送过去，再留在 $W$，所以 $IT=T$。
>
> 它们作用的空间不同，只是都叫「恒等算子」。写 $I$ 的时候心里要清楚它在哪个空间上。

### 3.9 乘法不满足交换律

即使 $ST$ 与 $TS$ **都有定义**，也**不一定**相等。

最经典的例子：取 $D$ 为微分映射、$T$ 为「与 $x^2$ 相乘」映射（两者都定义在 $\mathcal{P}(\mathbb{R})$ 上）。则对每个多项式 $p$，

$$(TD)p(x)=x^2p'(x)$$

$$(DT)p(x)=x^2p'(x)+2xp(x)$$

两者的差别出在 $2xp(x)$ 这一项上。取 $p(x)=1$ 一验：

$$(TD)1=0,\qquad (DT)1=2x$$

两者不等，所以 $TD\neq DT$。用一句话说清这件事：

> **先微分再乘 $x^2$，和先乘 $x^2$ 再微分，结果不一样。**

乘法不交换这件事不是「碰巧的例子」，而是普遍现象：只要 $V$ 的维数大于 $1$，$\mathcal{L}(V)$ 里就一定能找到两个算子不交换（见第六节）。这一点在讲到「可对角化」「可交换算子」时还会回来。

## 四、几何直观 / 记忆钩子

### 钩子 1：线性映射是「网格搬运工」

在 $\mathbb{R}^2$ 里想象一张均匀的正方形网格（每个小格边长相同）。线性映射把这张网格搬过去之后，得到的仍是一张**等距平行**的网格——小方格可能被拉长、压扁、剪切、旋转，甚至被压成一条线，但**同一方向上的间距处处相等，而且原点不动**。

对照两种失败：

- $x\mapsto x+1$ 是**平移**：网格还是均匀的，但原点被搬走了，整张网格「错位」——线性结构立刻失效。
- $x\mapsto x^2$：网格被拉得**不均匀**了，越远的地方间距越大——等距平行的性质没了。

一句话记：**均匀 + 原点不动**，是线性映射在几何上的两张面孔。

### 钩子 2：两条 = 一条 = 「组合与搬运可交换」

把 3.3 那条合成式读成一句话：

$$\text{先组合}\to\text{再搬运}\qquad\text{等于}\qquad\text{先搬运}\to\text{再组合}$$

用交换图的方式说：无论走「先加后映」还是「先映后加」，到达的都是同一个结果。这就是「线性」二字的全部含义。

### 钩子 3：为什么只需两条（本讲最该记住的一条）

把结构数一遍：

| 向量空间里的东西 | 是「原子操作」还是「配合规则」 |
|---|---|
| 加法、标量乘法 | **原子操作**（只有这两个） |
| 交换、结合、分配、单位律、零元、逆元 | 配合规则（都是关于这两个操作怎么协作的说明） |

于是：

> **保住了两个原子操作，就保住了它们的任何有限次组合；而空间里的向量表达式全都是这种组合。**

所以两条就够。别的一切都是推论或者由 $V,W$ 本身提供，不必额外要求。这也解释了为什么定义里没有「$T(0)=0$」。

如果非要一句话记住这件事：**线性映射的定义之所以这么短，是因为向量空间的结构本身就只剩这两样东西。**

### 钩子 4：先查原点，省钱

> **线性映射一定把 $0$ 送到 $0$。看到 $T(0)\neq 0$，立刻停下。**

这道检查极其廉价，却常常一口气排除掉一整类候选，省下后面所有验算。判定任何函数之前，先算 $T(0)$——这是本讲最划算的一个习惯。

### 钩子 5：一张速查对照表

| 函数 | 线性？ | 卡在哪 |
|---|---|---|
| $x\mapsto 2x$ | ✓ | 每个分量都是一次齐次式 |
| $x\mapsto x+1$ | ✗ | $T(0)=1\neq0$ |
| $x\mapsto x^2$ | ✗ | 可加、齐次**都**失败 |
| $x\mapsto\cos x$ | ✗ | 可加性失败 |
| $(x,y)\mapsto(2x+5y,\ 3x+7y)$ | ✓ | 一次齐次式 |
| $(x,y)\mapsto xy$ | ✗ | 出现乘积项 |
| $(x,y)\mapsto(x+1,\ y)$ | ✗ | 第一个分量带常数项 |
| $p\mapsto p'$ | ✓ | 求导的两条基本结论 |
| $p\mapsto p(3)$ | ✓ | 求值：$(p+q)(3)=p(3)+q(3)$ |

## 五、常见误区

> [!warning] 误区 1：把高中的「线性函数」当线性映射
> $y=mx+b$ 只在 $b=0$ 时才是线性映射。
> 判据一句话：**看它把 $0$ 送到哪。** 一旦 $f(0)\neq0$，立刻出局。
> 同理，$x\mapsto x+1$、$x\mapsto 2x+3$、$x\mapsto -x+7$ 全都不是线性映射。

> [!warning] 误区 2：以为 $T(0)=0$ 就说明 $T$ 线性
> 错。$T(0)=0$ 只是**必要条件**。
> 反例：$f(x)=x^2$ 满足 $f(0)=0$，却 $f(1+2)=9\neq5=f(1)+f(2)$；
> $(x,y)\mapsto xy$ 也满足，却 $T(2(1,1))=4\neq2=2T(1,1)$。
> **必要条件拦不住的，必须回到两条原判据。**

> [!warning] 误区 3：只查一条就下结论
> **可加性与齐次性互不蕴含**，各自都有反例。
>
> **只齐次、不可加**：定义 $\varphi:\mathbb{R}^2\to\mathbb{R}$ 为
> $$\varphi(x,y)=\begin{cases}\dfrac{x^2}{y},&y\neq0\\0,&y=0\end{cases}$$
> 对每个 $a\in\mathbb{R}$ 都有 $\varphi(av)=a\varphi(v)$：$a=0$ 时两边都是 $0$；$a\neq0$ 且 $y\neq0$ 时 $\dfrac{(ax)^2}{ay}=\dfrac{a^2x^2}{ay}=a\dfrac{x^2}{y}$；$y=0$ 时两边都是 $0$。
> 但它不保加法：
> $$\varphi\big((1,1)+(0,1)\big)=\varphi(1,2)=\tfrac12,\qquad \varphi(1,1)+\varphi(0,1)=1+0=1$$
> $\tfrac12\neq1$，可加性失败。
>
> **只可加、不齐次**：把 $\mathbb{C}$ 看作**复**向量空间，定义 $\varphi(z)=\overline{z}$（取共轭）。共轭是逐分量变号，所以
> $$\varphi(w+z)=\overline{w+z}=\overline{w}+\overline{z}=\varphi(w)+\varphi(z)$$
> 恒成立。但取 $\lambda=i$、$z=1$：
> $$\varphi(i\cdot 1)=\overline{i}=-i,\qquad i\,\varphi(1)=i\cdot1=i$$
> 两者不等，齐次性失败。
>
> 结论：**两条都要过**，或者干脆一次验那条合成式 $T(\lambda u+\mu v)=\lambda Tu+\mu Tv$。

> [!warning] 误区 4：以为线性映射到处都是
> 恰恰相反，**不线性才是常态**。$\sin$、$\log$、绝对值、$x^2$、$xy$、$\cos$ 全都不线性。
> 常见函数里真正线性的是少数：乘一个固定系数、求导、积分、求值、移位、取坐标分量。
> 线性代数之所以值得讲这么多，正是因为这少数几个**结构最好用**。

> [!warning] 误区 5：把 $ST$ 与 $TS$ 当成一回事
> 乘积记号里**次序不能换**，而且有两层麻烦：
> 1. **有没有定义**：$ST$ 有意义要求 $T$ 的值域落在 $S$ 的定义域内；$TS$ 有意义是另一回事，可能压根写不出来。
> 2. **相不相等**：即使两个都有意义，也通常不相等。$D$ 与「乘 $x^2$」就是现成的例子：$TD\neq DT$。

> [!warning] 误区 6：以为两个线性映射「相乘」就是逐点相乘
> 逐点相乘（$v\mapsto Sv\cdot Tv$）这件事在一般向量空间里**根本没有定义**——
> $W$ 里通常没有「两个向量相乘」这种运算（回想 02 讲：纯粹的向量空间只有加法与标量乘法）。
> 线性映射之间唯一通用的乘法是**复合** $ST$，而且对形状有要求。
> 这条和 01 讲的「别把标量乘法与两个向量相乘混为一谈」是同一件事的另一面。

## 六、拓展（可选）

这一节是选读，不影响后面几讲。看不完也没有损失。

**1. 一维空间上的算子只是「乘一个标量」。** 设 $\dim V=1$ 且 $T\in\mathcal{L}(V)$，则存在 $\lambda\in\mathbb{F}$，使得对所有 $v\in V$ 都有 $Tv=\lambda v$。

理由很短：取 $V$ 中非零向量 $v_0$，则每个 $v$ 都能写成 $v=cv_0$（一维空间里没有别的方向），于是 $Tv=c\,Tv_0$；而 $Tv_0$ 本身也在 $V$ 里，故可写成 $Tv_0=\lambda v_0$。代入得 $Tv=c\lambda v_0=\lambda(cv_0)=\lambda v$。

这说明：**一维情形没有任何花样**，$\mathcal{L}(V)$ 与 $\mathbb{F}$ 在结构上是一回事。花样要从二维开始。

**2. 「线性」是全局性质，不能一块一块地拼。** 设 $U$ 是 $V$ 的真子空间，$S\in\mathcal{L}(U,W)$ 且 $S\neq0$。定义

$$Tv=\begin{cases}Sv,&v\in U\\0,&v\in V\ \text{但}\ v\notin U\end{cases}$$

这个 $T$ **不是** $V$ 上的线性映射。取 $u\in U$ 使 $Su\neq0$，再取 $v\notin U$。那么 $u+v\notin U$（否则 $v=(u+v)-u\in U$，矛盾），于是

$$T(u+v)=0,\qquad Tu+Tv=Su+0=Su\neq0$$

可加性失败。教益是：**在子空间上表现良好，不能保证在整体上表现良好。**

**3. 从有限维到无限维，「映射空间」自己也无限维。** 若 $V$ 有限维且 $\dim V>0$，而 $W$ 是无限维的，则 $\mathcal{L}(V,W)$ 也是无限维的。直觉是：$W$ 里能找出无穷多个线性无关的向量，而把基向量映到它们上面能得到无穷多个线性无关的映射（证明不展开）。

**4. 维数大于 $1$ 时，乘法一定不交换。** 若 $\dim V>1$，则一定存在 $S,T\in\mathcal{L}(V)$ 使 $ST\neq TS$。3.9 的微分与乘 $x^2$ 只是这件事在无穷维空间上的一个具体化身。

**5. 多项式复合的两种次序，一个线性、一个不线性。** 前面例子里那个 $(Tp)(x)=p(q(x))$（$q$ 固定）是线性的。注意它的次序：**$q$ 在里、$p$ 在外**，所以 $T$ 对 $p$ 是线性的。反过来定义 $(Tp)(x)=q(p(x))$（也就是 $q\circ p$），就**一般不再线性**了：取 $q(x)=x^2$，则 $Tp=p^2$，而

$$T(p_1+p_2)=(p_1+p_2)^2=p_1^2+2p_1p_2+p_2^2\neq p_1^2+p_2^2=Tp_1+Tp_2$$

只有当 $q$ 是一次齐次式 $q(x)=ax$ 时，$Tp=q\circ p=ap$ 才对所有 $p$ 都线性。
**同一个「复合」动作，把哪个位置留作变量，结果天差地别。**

**6. 「可加但不齐次」的实函数确实存在，但不容易造。** 上面误区 3 里那个「只可加不齐次」的例子用的是复数与共轭。若要求在 $\mathbb{R}\to\mathbb{R}$ 上给出「可加但不线性」的函数，构造要用到远为高深的工具（需要把 $\mathbb{R}$ 看成 $\mathbb{Q}$ 上的向量空间并取其一组基），本课不展开。这里提一句，只为说明**两边难度并不对称**。

**7. 通往矩阵的门已经打开。** 3.4 的手算例子里，$Te_1=(2,3)$、$Te_2=(5,7)$ 被摆成了 $\begin{pmatrix}2&5\\3&7\end{pmatrix}$。这张表就是把线性映射「写下来」的方式，下一讲会把它讲透。

## 七、自测（先做，再看答案）

**1.** 判断下列 $T$ 是否线性映射，并说明卡在哪一条（都在 $\mathbb{R}$ 上的向量空间里讨论）：

① $T:\mathbb{R}^2\to\mathbb{R}^3$，$T(x,y)=(x+2y,\ 3x-y,\ 5x)$；

② $T:\mathbb{R}\to\mathbb{R}$，$T(x)=x^2+1$；

③ $T:\mathbb{R}^2\to\mathbb{R}$，$T(x,y)=xy$；

④ $T:\mathcal{P}(\mathbb{R})\to\mathcal{P}(\mathbb{R})$，$(Tp)(x)=p(x+1)$；

⑤ $T:\mathcal{P}(\mathbb{R})\to\mathbb{R}$，$Tp=p(3)$。

**2.** 用线性映射引理，写出 $\mathcal{L}(\mathbb{F}^2,\mathbb{F}^3)$ 中满足 $Te_1=(1,1,1)$、$Te_2=(2,0,3)$ 的那个映射的公式，并计算 $T(4,-5)$。

**3.** 只用齐次性证明 $T(0)=0$。再说明：为什么不能反过来用「$T(0)=0$」断定 $T$ 线性？（给一个反例）

**4.** 设 $T\in\mathcal{L}(U,V)$、$S\in\mathcal{L}(V,W)$。验证乘积 $ST$ 确实满足可加性与齐次性。

**5.** 取 $D$ 为微分映射、$T$ 为「与 $x^2$ 相乘」映射。分别算出 $(TD)p$ 与 $(DT)p$，并用 $p(x)=x$ 验证两者不等。

**6.** $T:\mathbb{R}^2\to\mathbb{R}^2$ 定义为 $T(x,y)=(x+1,\ y)$。它线性吗？把定义改成 $T(x,y)=(x,\ y)$ 之后呢？两者只差一个常数，结论为什么完全不同？

> [!success]- 答案（点开）
> **1.**
> ① **线性**。每个分量都是 $x,y$ 的一次齐次式：没有常数项、没有乘积项、没有特殊位置规则。
> 验算可加性：$T(u+v)$ 的第一个分量是 $(x+x')+2(y+y')=(x+2y)+(x'+2y')$，正是 $Tu+Tv$ 的第一个分量；其余分量同理。齐次性：把 $\lambda$ 从每个分量里整体提出来。
> ② **不线性**。$T(0)=1\neq0$，必要条件就不过。也可以直接撞可加性：$T(1+1)=5$，而 $T(1)+T(1)=2+2=4$。
> ③ **不线性**。齐次性失败：$T(2(1,1))=T(2,2)=4$，而 $2T(1,1)=2\cdot1=2$。
> ④ **线性**。逐点验证（这是关键，因为输入输出都是函数）：
> $$(T(p+q))(x)=(p+q)(x+1)=p(x+1)+q(x+1)=(Tp)(x)+(Tq)(x)$$
> 对每个 $x$ 成立，故 $T(p+q)=Tp+Tq$。齐次性同理：$(T(\lambda p))(x)=\lambda p(x+1)=\lambda(Tp)(x)$。
> ⑤ **线性**。求值就是最朴素的线性映射：$T(p+q)=(p+q)(3)=p(3)+q(3)=Tp+Tq$，$T(\lambda p)=(\lambda p)(3)=\lambda\,p(3)=\lambda Tp$。
> 「移位」与「求值」是函数空间上两个最典型的线性映射。
>
> **2.** 任意 $(x,y)=xe_1+ye_2$。由 3.3，
> $$T(x,y)=x\,Te_1+y\,Te_2=x(1,1,1)+y(2,0,3)=(x+2y,\ x,\ x+3y)$$
> 代入 $(4,-5)$：
> $$T(4,-5)=(4-10,\ 4,\ 4-15)=(-6,\ 4,\ -11)$$
>
> **3.** 取 $\lambda=0$（$v$ 任意）：$T(0)=T(0\cdot v)=0\cdot Tv=0$。
> 反过来不成立。反例 $f(x)=x^2$：$f(0)=0$，但 $f(1+2)=9\neq5=f(1)+f(2)$。
> 所以「$T(0)=0$」是**必要不充分**条件，只能用来快速否定，不能用来肯定。
>
> **4.** 可加性：
> $$(ST)(u+u')=S\big(T(u+u')\big)=S(Tu+Tu')=S(Tu)+S(Tu')=(ST)u+(ST)u'$$
> 齐次性：
> $$(ST)(\lambda u)=S\big(T(\lambda u)\big)=S(\lambda\,Tu)=\lambda\,S(Tu)=\lambda\,(ST)u$$
> 两处的关键分别是「$T$ 线性」和「$S$ 线性」：第一步脱去 $T$，第二步脱去 $S$。
>
> **5.** $(TD)p=T(Dp)=x^2p'(x)$；
> $$(DT)p=D(Tp)=\big(x^2p(x)\big)'=x^2p'(x)+2xp(x)$$
> 取 $p(x)=x$：$(TD)p=x^2\cdot1=x^2$，而 $(DT)p=x^2+2x\cdot x=3x^2$。
> $x^2\neq3x^2$，所以 $TD\neq DT$。两者恒相差 $2xp(x)$ 这一项。
>
> **6.** $T(x,y)=(x+1,\ y)$ **不线性**：$T(0,0)=(1,0)\neq(0,0)$。
> 改成 $T(x,y)=(x,\ y)$ 就是恒等算子，**线性**。
> 差别全在那个常数 $1$：它把原点搬到了 $(1,0)$，而线性映射必须把 $0$ 送到 $0$。
> 这说明「线性」不是描述函数外形的形容词，而是描述它与**加法、标量乘法**关系的性质——
> 外形上只差一点点的两个函数，在这一性质上可以完全不同。

## 八、复习卡

| 项 | 内容 |
|---|---|
| **线性映射** | $T:V\to W$ 满足两条：可加、齐次 |
| **可加性** | $T(u+v)=Tu+Tv$，对所有 $u,v\in V$ |
| **齐次性** | $T(\lambda v)=\lambda Tv$，对所有 $\lambda\in\mathbb{F}$、$v\in V$ |
| **等价的一条写法** | $T(\lambda u+\mu v)=\lambda Tu+\mu Tv$（取 $\lambda=\mu=1$ 得可加，取 $\mu=0$ 得齐次） |
| **为什么只需两条** | 向量空间只有加法与标量乘法两个原子操作；保住它们就保住了一切线性组合 |
| **$\mathcal{L}(V,W)$** | 从 $V$ 到 $W$ 的全体线性映射；$\mathcal{L}(V)=\mathcal{L}(V,V)$ |
| **算子** | 本课对 $V\to V$ 的线性映射的叫法 |
| **零映射** | $0v=0$；是 $\mathcal{L}(V,W)$ 中的加法恒等元 |
| **恒等算子** | $Iv=v$ |
| **微分** | $Dp=p'$；线性 ⟺ $(\lambda f)'=\lambda f'$ 与 $(f+g)'=f'+g'$ |
| **积分** | $Tp=\int_0^1 p$；线性 ⟺ 积分的两条基本结论 |
| **与 $x^2$ 相乘** | $(Tp)(x)=x^2p(x)$ |
| **后向移位** | $T(x_1,x_2,x_3,\dots)=(x_2,x_3,\dots)$ |
| **$\mathbb{F}^n\to\mathbb{F}^m$ 的一般形状** | 每个分量都是输入的一次齐次式，由 $mn$ 个系数 $A_{j,k}$ 决定 |
| **多项式复合** | $(Tp)(x)=p(q(x))$（$q$ 固定）是线性的；反过来 $q\circ p$ 一般不线性 |
| **$T(0)=0$** | 线性映射的必要条件；可加性或齐次性任一条单独即可推出 |
| **必要条件 ≠ 判据** | $x\mapsto x^2$、$(x,y)\mapsto xy$ 都满足 $T(0)=0$，都不线性 |
| **保持线性组合** | $T(c_1v_1+\cdots+c_nv_n)=c_1Tv_1+\cdots+c_nTv_n$ |
| **线性映射引理** | $v_1,\dots,v_n$ 是基时，基上的像可以任意指定，且唯一确定一个线性映射 |
| **$\mathcal{L}(V,W)$ 上的加法** | $(S+T)(v)=Sv+Tv$ |
| **$\mathcal{L}(V,W)$ 上的标量乘** | $(\lambda T)(v)=\lambda(Tv)$ |
| **$\mathcal{L}(V,W)$ 是向量空间** | 逐点验证六条；零元是零映射 |
| **乘积 $ST$** | $(ST)(u)=S(Tu)$，即复合；要求 $T$ 映进 $S$ 的定义域 |
| **乘积的性质** | 可结合、有恒等元 $TI=IT=T$、满足两条分配律 |
| **乘积不交换** | $TD\neq DT$：$(TD)p=x^2p'$，$(DT)p=x^2p'+2xp$ |
| **一维情形** | $\dim V=1$ 时 $T\in\mathcal{L}(V)$ 就是「乘一个标量」 |
| **判定顺序** | 先算 $T(0)$（不中即否）→ 再验可加 → 再验齐次，或一次验合成式 |

## 九、出处与延伸（可选，不影响阅读）

- **本讲内容来源**：定义与例子、$\mathcal{L}(V,W)$、线性映射引理、乘积及其代数性质，对应《线性代数应该这样学》（第 4 版，吴俊达、何阳 译）**3A 节「线性映射所成的向量空间」**，**印刷页码 p44–p49**（PDF 页 58–63）。该节末尾的习题 3A 是本节内容的配套练习，其中「只齐次不可加」「只可加不齐次」「子空间上定义、其余取 $0$」这几个反例都出自那里。
- **原文页码 ↔ 本讲小节对照**（仅供回查）：

  | 线性映射的定义、$\mathcal{L}(V,W)$ 记号、八例 | p44–p45 |
  | 线性映射引理及其证明 | p45–p46 |
  | $\mathcal{L}(V,W)$ 上的加法与标量乘、$\mathcal{L}(V,W)$ 是向量空间 | p46 |

- **术语别名**：
  | 本课用法 | 你可能见到的其他说法 |
  |---|---|
  | 线性映射 | 线性变换（linear transformation）、线性算子（linear operator） |
  | 算子（$V\to V$ 的线性映射） | 线性变换（不少教材在 $V\to V$ 时专指这个） |
  | 乘积 $ST$ | 复合 $S\circ T$ |
  | 恒等算子 $I$ | 单位算子、恒等映射、identity |
  | $\mathcal{L}(V,W)$ | $\operatorname{Hom}(V,W)$；$W=V$ 时常写作 $\operatorname{End}(V)$ |
  | 零映射 | 零算子 |
- **「同态」这个词**：在更一般的代数语境里，凡是「保持运算的映射」都叫**同态（homomorphism）**——群同态保持群运算，环同态保持加与乘，线性映射则是向量空间之间的同态。所以看到「同态」，翻译成本课的话就是「保持加法与标量乘法的映射」。与之配套的还有「同构」（可逆的同态）与「核」（被映成 $0$ 的部分），后者就是 08 讲的**零空间**。
- **权威查证**：想核对术语或某个结论的表述，可在 Bronstein《数学手册》（俄文第 10 版 1962 / 英文第 6 版 2015）中检索 "linear map / linear transformation"（德文 "lineare Abbildung"，俄文 "линейное отображение"）。
- **下一讲预告**：08「零空间与值域」把线性映射「切开」看——哪些向量被压成 $0$，哪些向量能被取到，两者的维数之间有一条等式。

> [!note] 一句提醒
> 「线性映射」这四个字在中文教材里常与「线性变换」混用，不影响内容。
> 真正需要警惕的只有一处：**「线性函数」在高中语境里指 $y=mx+b$，在本课语境里只指 $b=0$ 的那一支。**
> 遇到这个词，先问清楚是哪个意思，再往下算。
