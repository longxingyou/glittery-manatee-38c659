# 对偶

> **这讲讲什么**：把「向量」和「测量向量的规则」拆成两套对象——前者构成 $V$，后者构成 $V'$；并证明有限维时两者一样大、彼此有一部可以直接翻查的词典
> **前置**：05 讲（基）、06 讲（维数）、07 讲（线性映射）、08 讲（零空间、值域与线性映射基本定理）、09 讲（矩阵与矩阵乘法）
> **一句话**：$V'$ 是「所有把向量变成数的线性规则」组成的空间——它和 $V$ 一样大，但**箭头全部反过来**。

---

## 一、为什么需要它

### 从「数出第 $j$ 个坐标」这件小事说起

设 $v_1,\dots,v_n$ 是 $V$ 的基。那么每个 $v\in V$ 都能唯一地写成

$$v=c_1v_1+\cdots+c_nv_n$$

现在问一个很朴素的问题：**给定 $v$，$c_j$ 等于多少？**

你可能会说：解方程组。对，但解法有很多种，而这里想抓的不是算法，是**结构**。注意「取出第 $j$ 个系数」这件事本身是一个函数：

$$\varphi_j:V\to\mathbb{F},\qquad \varphi_j(v)=c_j$$

它吃进一个向量，吐出一个数。而且它是**线性**的——系数唯一，所以 $u+v$ 的第 $j$ 个系数正好是两者第 $j$ 个系数之和。

关键的一步就在这里：**把这个动作从「操作」升格为「对象」。** 一旦它是对象，就可以问：两个这样的规则能不能相加？能不能乘标量？它们自己构成一个什么空间？

答案是：能加、能乘、构成一个向量空间。这个空间就是本讲的主角——**对偶空间** $V'$。

### 你早就在用这些规则，只是没给它们名字

| 规则 | 写成 $\varphi(v)$ | 线性吗 |
|---|---|---|
| 取第 $j$ 个坐标 | $\varphi_j(x_1,\dots,x_n)=x_j$ | 是 |
| 加权求和 | $\varphi(x_1,\dots,x_n)=c_1x_1+\cdots+c_nx_n$ | 是 |
| 在一点求值 | $\varphi(p)=p(3)$ | 是 |
| 求导后再求值 | $\varphi(p)=3p''(5)+7p(4)$ | 是 |
| 积分 | $\varphi(p)=\displaystyle\int_0^1 p(x)\,dx$ | 是 |
| 矩阵的迹 | $\varphi(A)=\operatorname{tr}A$ | 是 |

这六条的共同点一句话能说完：**吃一个向量，吐一个数，且保持加法与标量乘法。** 你在解方程、在数值积分、在算平均值时，用的全是这类规则。本讲只是把它们摆到台面上，当作一等公民。

> [!important] 这一讲真正做的事：分家
> 以前「向量」既是对象又是被测量的东西，混在一起。现在分成两套：
> - $V$ 里的元素是**被测量的对象**（向量）；
> - $V'$ 里的元素是**测量的尺子**（线性泛函）。
>
> 尺子和被量的东西当然不是一回事。但尺子自己也能加、能乘——所以尺子也是一堆向量。
> **「把函数当向量」这件事，02 讲已经批准过一次；这一讲是它在映射上的第二次应用。**

### 没有这套语言会怎样

举一个具体的地方。解齐次线性方程组 $Ax=0$，$A$ 是 $m\times n$ 矩阵。你早就知道：解空间维数等于 $n-\operatorname{rank}A$。

可是为什么「每多一个独立方程，解空间就少一维」？这句话在矩阵语言里是**算出来的**，不是**看出来**的。而用对偶的语言，它变成一句结构性的陈述：

$$\dim U^0=\dim V-\dim U$$

这里 $U$ 是解空间，$U^0$ 是由那些「在 $U$ 上恒为零」的泛函（也就是方程的系数行）组成的空间。**方程组的行空间与解空间互为对偶的补**——这句话只有在本讲的语言里才说得出口。第三节会把它算清楚。

### 「对偶」这个词的味道

$V$ 与 $V'$ 维数相同，所以它们同构。但请注意一件事：**你没有办法在不选基的情况下，把某个具体的 $v$ 指定配给某个具体的 $\varphi$。** 想配对，就得先选基（$\varphi_j$ 配 $v_j$），换一组基，配对全变。

而 $V$ 与它的双重对偶 $V''$ 之间，却存在一个**完全不用选基**的同构。这个「差一点点」正是「对偶」这个词的分量所在——它是第六节的内容。

再往后，22 讲起的内积部分会给 $V$ 与 $V'$ 之间搭一条不依赖基的桥，那时 $V$ 与 $V'$ 才真正被「焊」在一起，而伴随映射 $T^*$ 就是在这个焊点上定义的（见 25 讲附近）。所以本讲是那条路的第一段。

## 二、定义与最小例子

### 定义：线性泛函

**线性泛函**：$V$ 上的线性泛函是从 $V$ 到 $\mathbb{F}$ 的线性映射。换言之，线性泛函是 $\mathcal{L}(V,\mathbb{F})$ 的元素。

展开写就是：$\varphi:V\to\mathbb{F}$ 满足

$$\varphi(u+v)=\varphi(u)+\varphi(v),\qquad \varphi(\lambda v)=\lambda\varphi(v)$$

对所有 $u,v\in V$、$\lambda\in\mathbb{F}$ 成立。

> [!note] 为什么这个定义短得可疑
> 因为 07 讲已经把「线性」讲透了，这里没有再增加任何新条件。
> 所谓新东西，只是**把到达空间定成了 $\mathbb{F}$**。而 $\mathbb{F}$ 是一维的，一维空间的东西特别少——
> 这个「少」正是后面所有漂亮结论的来源。

### 最小例子

**例 1**：$\varphi:\mathbb{R}^3\to\mathbb{R}$，$\varphi(x,y,z)=4x-5y+2z$。

验一下线性：$\varphi\big((x,y,z)+(x',y',z')\big)=4(x+x')-5(y+y')+2(z+z')=\varphi(x,y,z)+\varphi(x',y',z')$ ✓。标量乘同理。

**例 2**：固定 $(c_1,\dots,c_n)\in\mathbb{F}^n$，定义 $\varphi(x_1,\dots,x_n)=c_1x_1+\cdots+c_nx_n$。这是 $\mathbb{F}^n$ 上最一般的线性泛函——理由在 3.2：坐标泛函构成 $V'$ 的基，所以任何线性泛函都是它们的线性组合，形状只能是这个样子。

**例 3**：$\varphi:\mathcal{P}(\mathbb{R})\to\mathbb{R}$，$\varphi(p)=3p''(5)+7p(4)$。求导是线性的，求值是线性的，两者复合仍然线性。

**例 4**：$\varphi:\mathcal{P}(\mathbb{R})\to\mathbb{R}$，$\varphi(p)=\displaystyle\int_0^1 p(x)\,dx$。积分保持加法与标量乘。

**例 5（反例，值得先看一眼）**：$\varphi(x,y)=x+2y-1$ **不是**线性泛函。查第二条：$\varphi(0,0)=-1$，但线性映射必须把 $0$ 送到 $0$。差一个常数项就不行——这跟 07 讲「线性映射把零送到零」是同一条检验。

### 定义：对偶空间

**对偶空间**：$V$ 的对偶空间记作 $V'$，是 $V$ 上全体线性泛函所构成的向量空间。换言之，

$$V'=\mathcal{L}(V,\mathbb{F})$$

运算就是映射的加法与标量乘法：$(\varphi+\psi)(v)=\varphi(v)+\psi(v)$，$(\lambda\varphi)(v)=\lambda\varphi(v)$。零元是把每个 $v$ 都送到 $0$ 的那个泛函。

它确实是向量空间——这是 07 讲已经证过的结论（$\mathcal{L}(V,W)$ 总是向量空间）的一个特例，不需要重证。

> [!tip] 记号提醒
> 有的教材把对偶空间记作 $V^{*}$，对偶映射记作 $T^{*}$。
> 本课把星号 $*$ **留给伴随**，所以这里统一用撇号 $'$：$V'$、$T'$。
> 撇号在别的场合还表示导数，同一页里可能两种意思并存——看它挂在谁头上。

### 维数：$V'$ 和 $V$ 一样大

**命题**：设 $V$ 有限维，则 $V'$ 也有限维，且

$$\dim V'=\dim V$$

理由是 10 讲已经算过的一般公式：

$$\dim\mathcal{L}(V,W)=(\dim V)(\dim W)$$

取 $W=\mathbb{F}$，$\dim\mathbb{F}=1$，于是 $\dim V'=(\dim V)\cdot 1=\dim V$。

> [!important] 这一行等式值得停三秒
> $V'$ 里的元素是**函数**，$V$ 里的元素是**向量**，长得完全不像。
> 但它们维数相同，所以它们同构（10 讲：同维数的有限维空间必同构）。
> 也就是说：**「测量规则的空间」和「被测量的空间」在大小上是同一个尺度的东西。**
> 这不是巧合，而是有限维线性代数最结实的一根支柱。

### 定义：对偶基

**对偶基**：如果 $v_1,\dots,v_n$ 是 $V$ 的基，那么它们的**对偶基**是 $V'$ 中的元素 $\varphi_1,\dots,\varphi_n$ 构成的组，其中每个 $\varphi_j$ 是 $V$ 上满足下式的线性泛函：

$$\varphi_j(v_k)=\begin{cases}1,& k=j\\ 0,& k\neq j\end{cases}$$

用 $\delta_{jk}$ 简写右边，即 $\varphi_j(v_k)=\delta_{jk}$。

> [!note] 这个定义里藏着一个存在性问题
> 上式只规定了 $\varphi_j$ 在**基向量**上的取值，没有说它在别的向量上取什么。
> 凭什么这样的 $\varphi_j$ 一定存在，而且唯一？
>
> 答案是 07 讲的**线性映射引理**：在一组基上任意指定像，总有**唯一**的线性映射实现它。
> 所以「指定 $\varphi_j(v_k)=\delta_{jk}$」这句话已经把 $\varphi_j$ 完全钉死了——
> 对任意 $v=c_1v_1+\cdots+c_nv_n$，只能是
> $$\varphi_j(v)=c_1\delta_{j1}+\cdots+c_n\delta_{jn}=c_j$$
> **对偶基的 $\varphi_j$ 就是「取第 $j$ 个坐标」这个泛函。** 定义与直觉在这里合上了。

### 最小例子 1：$\mathbb{F}^n$ 的标准基

设 $e_1,\dots,e_n$ 是 $\mathbb{F}^n$ 的标准基，定义

$$\varphi_j(x_1,\dots,x_n)=x_j$$

那么 $\varphi_j(e_k)=\delta_{jk}$，所以 $\varphi_1,\dots,\varphi_n$ 就是标准基的对偶基。

换句话说：**$\mathbb{F}^n$ 的标准基的对偶基，就是把「取第 $j$ 个坐标」这件事本身。** 平平无奇，但它是所有计算的基准。

### 最小例子 2：一组斜基的对偶基（建议自己先算）

取 $V=\mathbb{R}^2$，基

$$v_1=(1,1),\qquad v_2=(1,-1)$$

求对偶基 $\varphi_1,\varphi_2$。

设 $\varphi_1(x,y)=ax+by$。条件 $\varphi_1(v_1)=1$、$\varphi_1(v_2)=0$ 给出

$$\begin{cases}a+b=1\\ a-b=0\end{cases}\ \Longrightarrow\ a=b=\tfrac12$$

$$\varphi_1(x,y)=\frac{x+y}{2}$$

同理设 $\varphi_2(x,y)=ax+by$，条件 $\varphi_2(v_1)=0$、$\varphi_2(v_2)=1$ 给出 $a+b=0$、$a-b=1$，解得 $a=\tfrac12$、$b=-\tfrac12$：

$$\varphi_2(x,y)=\frac{x-y}{2}$$

验算：取 $v=(3,1)$。按公式，坐标应当是 $\varphi_1(v)=2$、$\varphi_2(v)=1$。核对 $2(1,1)+1(1,-1)=(3,1)$ ✓。

> [!tip] 从这个例子读出三件事
> **① 对偶基依赖基的选取。** 换一组基，对偶基就换了两个完全不同的泛函。所以「$v$ 配哪个 $\varphi$」这件事没有内在答案。
> **② 系数里的 $\tfrac12$ 不是错误。** 斜基的「第 1 个坐标」必须「斜着读」，读出来自然是分数。
> **③ 计算套路固定。** 设待定系数，把 $\delta_{jk}$ 的条件代进去，解一个 $n$ 元线性方程组。
> 组数等于基的个数，也就是 $n$ 个未知数配 $n$ 个条件——永远可解且唯一，因为 $v_1,\dots,v_n$ 线性无关。

## 三、几个必须自己算一遍的结论

### 3.1 对偶基读出坐标

**命题**：设 $v_1,\dots,v_n$ 是 $V$ 的基，$\varphi_1,\dots,\varphi_n$ 是其对偶基。那么对每个 $v\in V$，

$$v=\varphi_1(v)v_1+\cdots+\varphi_n(v)v_n$$

**证明**：设 $v=c_1v_1+\cdots+c_nv_n$。两边同时作用 $\varphi_j$：

$$\varphi_j(v)=\varphi_j\Big(\sum_{k=1}^{n}c_kv_k\Big)=\sum_{k=1}^{n}c_k\varphi_j(v_k)=\sum_{k=1}^{n}c_k\delta_{jk}=c_j$$

把 $c_j=\varphi_j(v)$ 代回展开式即得。∎

> [!important] 这条等式的意义
> 它把「坐标」从**算法**变成了**公式**。以前求坐标要找基、解方程组；
> 现在坐标就是 $\varphi_j(v)$——一个确定的数，由泛函给出。
> **对偶基不是「另一组基」，它是「读坐标的卡尺」。**

### 3.2 对偶基确实是对偶空间的基

名字叫「对偶基」，得先证明它真的是基，否则这个名字是骗人的。

**证明分两步。**

**第一步：线性无关。** 设 $a_1,\dots,a_n\in\mathbb{F}$ 使得

$$a_1\varphi_1+\cdots+a_n\varphi_n=0$$

这里的 $0$ 是 $V'$ 的零元，即「把一切都送到 $0$」的泛函。把它作用在 $v_k$ 上：

$$\big(a_1\varphi_1+\cdots+a_n\varphi_n\big)(v_k)=a_k$$

左边是 $0(v_k)=0$，所以 $a_k=0$，对每个 $k$ 都成立。故线性无关。

**第二步：长度够。** 这个无关组的长度是 $n=\dim V=\dim V'$。由 05 讲「长度等于维数的无关组必是基」，$\varphi_1,\dots,\varphi_n$ 是 $V'$ 的基。∎

> [!note] 这个证明的技巧在哪
> 要证「一组泛函线性无关」，办法不是盯着泛函本身，而是**让它去咬基向量**。
> 每咬一口，$\sum a_k\varphi_k$ 就被压成单个 $a_k$。
> 泛函的价值就在于它能**一个数一个数地把信息榨出来**——这是本讲反复出现的动作。

### 3.3 对偶映射 $T'$

现在把「取对偶」推到映射上。

**定义**：设 $T\in\mathcal{L}(V,W)$。$T$ 的**对偶映射** $T'$ 是由下式定义的线性映射 $T'\in\mathcal{L}(W',V')$：对每个 $\varphi\in W'$，

$$T'(\varphi)=\varphi\circ T$$

> [!warning] 三个必须盯住的地方
> **① 方向反了。** $T:V\to W$，但 $T':W'\to V'$。出发空间与到达空间整个对调。
> **② $T'(\varphi)$ 是 $V$ 上的泛函，不是 $W$ 上的。** 因为 $\varphi\circ T$ 先吃 $v$、算出 $Tv\in W$，再由 $\varphi$ 变成数。
> **③ 输入是泛函，不是向量。** $T'(\varphi)$ 里的 $\varphi$ 属于 $W'$。这一点在第五节会被反复踩。

为什么 $T'(\varphi)=\varphi\circ T$ 一定是 $V$ 上的线性泛函？因为两个线性映射的复合还是线性的（07 讲）。$T'(\varphi)$ 从 $V$ 到 $\mathbb{F}$，且线性 ✓。

**$T'$ 自己是线性的**，这一点要单独确认（它现在是从 $W'$ 到 $V'$ 的映射，不能白拿结论）：

$$T'(\varphi+\psi)=(\varphi+\psi)\circ T=\varphi\circ T+\psi\circ T=T'(\varphi)+T'(\psi)$$

$$T'(\lambda\varphi)=(\lambda\varphi)\circ T=\lambda(\varphi\circ T)=\lambda T'(\varphi)$$

两步都用到了「映射的加法与标量乘法就是逐点相加、逐点乘」（07 讲）。✓

**例：微分映射的对偶映射。** 设 $D:\mathcal{P}(\mathbb{R})\to\mathcal{P}(\mathbb{R})$，$Dp=p'$。

- 取 $\varphi(p)=p(3)$。则 $\big(D'(\varphi)\big)(p)=\varphi(Dp)=\varphi(p')=p'(3)$。所以 $D'(\varphi)$ 是「先求导再在 $3$ 处取值」。
- 取 $\varphi(p)=\displaystyle\int_0^1 p$。则 $\big(D'(\varphi)\big)(p)=\varphi(p')=\displaystyle\int_0^1 p'=p(1)-p(0)$。所以 $D'(\varphi)$ 是「首尾之差」。

> [!tip] 这两个例子说明什么
> 「对偶」不是把一个抽象符号翻个面，它有具体内容：**把一个作用在输出上的测量，改成作用在输入上的测量。**
> 第二个例子尤其典型：$\int_0^1 p'=p(1)-p(0)$ 就是微积分基本定理。
> 换句话说，对偶映射把「积分」翻译成了「端点求差」。**翻译的方向由 $T$ 决定，不需要额外信息。**

### 3.4 对偶映射的代数性质

**命题**：设 $T\in\mathcal{L}(V,W)$，则

$$\text{(a)}\ (S+T)'=S'+T'\qquad \text{(b)}\ (\lambda T)'=\lambda T'\qquad \text{(c)}\ (ST)'=T'S'$$

其中 (a)(b) 对所有 $S\in\mathcal{L}(V,W)$ 成立，(c) 对所有使 $ST$ 有意义的 $S\in\mathcal{L}(W,U)$ 成立。

只证 (c)，因为它是唯一会出意外的一条。取 $\varphi\in U'$：

$$\begin{aligned}(ST)'(\varphi)&=\varphi\circ(ST)\\&=(\varphi\circ S)\circ T\\&=T'(\varphi\circ S)\\&=T'\big(S'(\varphi)\big)\\&=(T'S')(\varphi)\end{aligned}$$

第 1、3、4 个等号是 $T'$ 的定义，第 2 个等号是复合的结合律，最后一步是复合的定义。∎

> [!important] (c) 的顺序为什么反过来
> 左边 $ST$ 表示「先 $T$ 后 $S$」，而 $\varphi$ 挂在最外面：$v\mapsto Tv\mapsto S(Tv)\mapsto\varphi(S(Tv))$。
> 谁离 $\varphi$ 近，谁先被「对偶化」。所以 $S$ 先变成 $S'$，$T$ 后变成 $T'$。
> **写成口诀：映射复合，对偶反序。**
> 09 讲矩阵的 $(AB)^{\mathsf{T}}=B^{\mathsf{T}}A^{\mathsf{T}}$ 是同一件事的矩阵版——3.10 会把它对上号。

### 3.5 零化子

**定义**：对 $U\subseteq V$，$U$ 的**零化子**记作 $U^0$，定义为

$$U^0=\{\varphi\in V':\ \text{对每个}\ u\in U,\ \varphi(u)=0\}$$

一句话：**在 $U$ 上全部瞎掉的泛函的全体。**

**例**：设 $U$ 是 $\mathcal{P}(\mathbb{R})$ 中由 $x^2$ 的倍数构成的多项式全体。若 $\varphi(p)=p'(0)$，则 $p(x)=x^2q(x)$ 时 $p'(x)=2xq(x)+x^2q'(x)$，在 $0$ 处为 $0$，故 $\varphi\in U^0$。

**例（$\mathbb{R}^5$）**：取 $U=\operatorname{span}(e_1,e_2)=\{(x_1,x_2,0,0,0)\}$。若 $\varphi=c_3\varphi_3+c_4\varphi_4+c_5\varphi_5$（$\varphi_j$ 是坐标泛函），则对 $u=(x_1,x_2,0,0,0)$ 有 $\varphi(u)=c_3\cdot0+c_4\cdot0+c_5\cdot0=0$。反过来，若 $\varphi=c_1\varphi_1+\cdots+c_5\varphi_5\in U^0$，用 $e_1\in U$ 得 $0=\varphi(e_1)=c_1$，用 $e_2$ 得 $c_2=0$。所以

$$U^0=\operatorname{span}(\varphi_3,\varphi_4,\varphi_5)$$

维数是 $3$，而 $\dim V=5$、$\dim U=2$。

**命题**：$U^0$ 是 $V'$ 的子空间。

证明三句：零泛函在 $U$ 上处处为 $0$；若 $\varphi,\psi$ 在 $U$ 上为零则 $(\varphi+\psi)(u)=0+0=0$；标量乘同理。由 03 讲子空间的判据即得。∎

> [!warning] 注意 $U^0$ 住在哪个空间
> $U\subseteq V$，但 $U^0\subseteq V'$。**它不在 $V$ 里。**
> 记号上它只写一个上标 $0$，很容易被当成 $V$ 的某个子集——这是本讲最常见的误解之一，第五节详细讲。

### 3.6 零化子的维数

**命题**：设 $V$ 有限维，$U$ 是 $V$ 的子空间，则

$$\dim U^0=\dim V-\dim U$$

这条是整讲最有用的一句。先看一个立刻能验的例子：上面 $\mathbb{R}^5$ 里 $5-2=3$ ✓。

**证法一（用包含映射）。** 令 $i:U\to V$ 是**包含映射**，$i(u)=u$。（它和恒等映射 $I:U\to U$ 算出来的值一样，但到达空间不同：$I$ 落在 $U$ 里，$i$ 落在 $V$ 里。）于是 $i'\in\mathcal{L}(V',U')$。

先认两个事实：

- $\operatorname{null}i'=U^0$。因为 $i'(\varphi)=\varphi\circ i$ 就是 $\varphi$ 在 $U$ 上的限制，它为零正好意味着 $\varphi$ 在 $U$ 上处处为零。
- $\operatorname{range}i'=U'$。任取 $\psi\in U'$，要把 $\psi$ 扩充成 $V$ 上的泛函：取 $U$ 的基 $u_1,\dots,u_m$，扩成 $V$ 的基 $u_1,\dots,u_m,u_{m+1},\dots,u_n$（05 讲扩充定理），在基上规定 $\psi^+(u_k)=\psi(u_k)$（$k\le m$）、$\psi^+(u_k)=0$（$k>m$），由线性映射引理得到 $\psi^+\in V'$，且 $i'(\psi^+)=\psi$。

把 08 讲的线性映射基本定理用在 $i'$ 上：

$$\dim\operatorname{range}i'+\dim\operatorname{null}i'=\dim V'$$

代入：$\dim U'+\dim U^0=\dim V$，再用 $\dim U'=\dim U$（第二节的「$\dim V'=\dim V$」对 $U$ 用一次）、$\dim V'=\dim V$，得

$$\dim U+\dim U^0=\dim V\ \Longrightarrow\ \dim U^0=\dim V-\dim U$$

∎

**证法二（直接造基）。** 取 $U$ 的基 $u_1,\dots,u_m$，扩成 $V$ 的基 $u_1,\dots,u_m,u_{m+1},\dots,u_n$，取对偶基 $\varphi_1,\dots,\varphi_n$。断言：

$$U^0=\operatorname{span}(\varphi_{m+1},\dots,\varphi_n)$$

包含 $\supseteq$：若 $r>m$、$k\le m$，则 $\varphi_r(u_k)=\delta_{rk}=0$，而 $u_1,\dots,u_m$ 张成 $U$，故 $\varphi_r$ 在 $U$ 上处处为 $0$。

包含 $\subseteq$：设 $\varphi\in U^0$，写成 $\varphi=a_1\varphi_1+\cdots+a_n\varphi_n$（对偶基是 $V'$ 的基，3.2 已证）。用 $u_k\in U$（$k\le m$）去咬：$0=\varphi(u_k)=a_k$。故 $a_1=\cdots=a_m=0$，$\varphi$ 只由 $\varphi_{m+1},\dots,\varphi_n$ 组成。

两边合起来，且 $\varphi_{m+1},\dots,\varphi_n$ 线性无关（它是对偶基的一段），于是 $\dim U^0=n-m=\dim V-\dim U$。∎

> [!tip] 两条证法各值什么
> 证法二给了你**具体的基**，可以拿去算；它同时说明了「$U^0$ 就是那些与 $U$ 的基向量正交的坐标泛函」。
> 证法一更短，而且它示范了一个通用套路：**把关于子空间的问题，变成一个映射的零空间问题，然后套基本定理。**
> 这个套路在本讲后半会反复用，值得单独记住。

### 3.7 零化子的两个极端

**命题**：设 $V$ 有限维，$U$ 是 $V$ 的子空间，则

$$\text{(a)}\ U^0=\{0\}\iff U=V\qquad \text{(b)}\ U^0=V'\iff U=\{0\}$$

两条都由 3.6 一眼得出：(a) $\dim U^0=0\iff\dim U=\dim V\iff U=V$（03 讲：同维数的子空间相等）；(b) $\dim U^0=\dim V\iff\dim U=0\iff U=\{0\}$。

这两条读起来很顺：**$U$ 越大，能「瞎掉」的泛函越少**；$U$ 大到全空间时，只有零泛函能全瞎；$U$ 小到只剩零时，所有泛函都瞎（因为任何线性泛函都把 $0$ 送到 $0$）。

> [!note] 这两条为什么有用
> 它们把「$U=V$」这种**集合相等**的判断，换成了「$U^0=\{0\}$」这种**泛函条件**。
> 有时候后者好验证得多——3.9 就是这么用的。

### 3.8 对偶映射的零空间与值域

**命题**：设 $V,W$ 有限维，$T\in\mathcal{L}(V,W)$，则

$$\text{(a)}\ \operatorname{null}T'=(\operatorname{range}T)^0\qquad \text{(b)}\ \operatorname{range}T'=(\operatorname{null}T)^0\qquad \text{(c)}\ \dim\operatorname{range}T'=\dim\operatorname{range}T$$

**(a) 的证明**是双向包含，只有两行。

设 $\varphi\in\operatorname{null}T'$，即 $0=T'(\varphi)=\varphi\circ T$。那么对每个 $v\in V$，$0=(\varphi\circ T)(v)=\varphi(Tv)$，也就是 $\varphi$ 在 $\operatorname{range}T$ 上处处为 $0$，故 $\varphi\in(\operatorname{range}T)^0$。

反过来，若 $\varphi\in(\operatorname{range}T)^0$，则对每个 $v$ 有 $\varphi(Tv)=0$，即 $\varphi\circ T=0$，也就是 $T'(\varphi)=0$。∎

**(c) 的证明**：把 08 讲基本定理用在 $T'$ 上（$T':W'\to V'$）：

$$\dim\operatorname{range}T'=\dim W'-\dim\operatorname{null}T'=\dim W-\dim(\operatorname{range}T)^0=\dim W-\big(\dim W-\dim\operatorname{range}T\big)=\dim\operatorname{range}T$$

第一个等号用基本定理，第二个用 $\dim W'=\dim W$ 与 (a)，第三个用 3.6。∎

**(b) 的证明**：先设 $\varphi=T'(\psi)$。若 $v\in\operatorname{null}T$，则

$$\varphi(v)=(T'(\psi))(v)=(\psi\circ T)(v)=\psi(Tv)=\psi(0)=0$$

故 $\varphi\in(\operatorname{null}T)^0$，即 $\operatorname{range}T'\subseteq(\operatorname{null}T)^0$。再比维数：由 (c) 与 08 讲基本定理、3.6，

$$\dim\operatorname{range}T'=\dim\operatorname{range}T=\dim V-\dim\operatorname{null}T=\dim(\operatorname{null}T)^0$$

同维数加包含关系，得相等。∎

> [!important] 这两条要连起来读
> (a) 说：**在像上瞎掉 = 被 $T'$ 吃掉。**
> (b) 说：**$T'$ 的像 = 在核上瞎掉的那些泛函。**
>
> 换成一句话：$T$ 的核与像，分别对应 $T'$ 的像与核——**位置对调了**。
> 这就是「对偶」这个词最直白的一次体现：$T$ 的两种「坏处」（核非零、像不满）在对偶侧交换了身份。

**推论（维数）**：$\dim\operatorname{null}T'=\dim\operatorname{null}T+\dim W-\dim V$。

由 (a) 与 3.6：$\dim\operatorname{null}T'=\dim W-\dim\operatorname{range}T$，再用基本定理把 $\dim\operatorname{range}T$ 换成 $\dim V-\dim\operatorname{null}T$ 即得。

> [!tip] 这个式子看着像会出负数，其实不会
> 右边含 $-\dim V$，初次见到容易担心「$\dim W<\dim V$ 时岂不是负的」。
> 代入基本定理立刻看清它其实是个**恒等式**，始终非负：
> $$\dim\operatorname{null}T'=\dim W-\dim\operatorname{range}T$$
> 而 $\dim\operatorname{range}T\le\dim W$ 恒成立（值域是 $W$ 的子空间），所以右边 $\ge0$。
> 换个角度：若 $\dim W<\dim V$，则 $T$ 本来就**不可能**是单射——
> 基本定理给出 $\dim\operatorname{null}T=\dim V-\dim\operatorname{range}T\ge\dim V-\dim W>0$，
> 正好把这个差额补了回来。**没有边界情形需要特殊处理。**

### 3.9 单射与满射的互换

**命题**：设 $V,W$ 有限维，$T\in\mathcal{L}(V,W)$，则

$$T\ \text{是满射}\iff T'\ \text{是单射}\qquad T\ \text{是单射}\iff T'\ \text{是满射}$$

前一条的证明是一串等价：

$$\begin{aligned}T\ \text{满射}&\iff\operatorname{range}T=W\\&\iff(\operatorname{range}T)^0=\{0\}\\&\iff\operatorname{null}T'=\{0\}\\&\iff T'\ \text{单射}\end{aligned}$$

第二个等价用 3.7(a)，第三个用 3.8(a)。后一条同理：$T$ 单射 $\iff\operatorname{null}T=\{0\}\iff(\operatorname{null}T)^0=V'\iff\operatorname{range}T'=V'\iff T'$ 满射（用 3.7(b) 与 3.8(b)）。

> [!tip] 这两条有什么实际用处
> 有时直接验 $T$ 是满射很难（要说明 $W$ 里每个向量都有原像），但验 $T'$ 是单射很容易（只要解 $\varphi\circ T=0$）。
> 反之亦然。**四条性质两两配对，你总能挑好算的那一头下手。**

### 3.10 对偶映射的矩阵就是转置

现在把 09 讲的矩阵接上。设 $v_1,\dots,v_n$ 是 $V$ 的基、$w_1,\dots,w_m$ 是 $W$ 的基，$\varphi_1,\dots,\varphi_n$ 与 $\psi_1,\dots,\psi_m$ 是各自的对偶基。于是可以算两个矩阵：$\mathcal{M}(T)$（关于 $v$、$w$）与 $\mathcal{M}(T')$（关于 $\psi$、$\varphi$）。

**命题**：

$$\mathcal{M}(T')=\big(\mathcal{M}(T)\big)^{\mathsf{T}}$$

注意尺寸自动对上：$\mathcal{M}(T)$ 是 $m\times n$，$\mathcal{M}(T')$ 是 $n\times m$。

**证明**：记 $A=\mathcal{M}(T)$、$C=\mathcal{M}(T')$。按定义，$C$ 的第 $j$ 列是 $T'(\psi_j)$ 关于 $\varphi_1,\dots,\varphi_n$ 的系数：

$$T'(\psi_j)=\sum_{r=1}^{n}C_{r,j}\,\varphi_r$$

把两边作用到 $v_k$ 上（左边 $T'(\psi_j)=\psi_j\circ T$）：

$$(\psi_j\circ T)(v_k)=\sum_{r=1}^{n}C_{r,j}\,\varphi_r(v_k)=C_{k,j}$$

换个算法再算同一个数。由 $A=\mathcal{M}(T)$ 的定义，$Tv_k=\displaystyle\sum_{r=1}^{m}A_{r,k}w_r$，于是

$$(\psi_j\circ T)(v_k)=\psi_j(Tv_k)=\psi_j\Big(\sum_{r=1}^{m}A_{r,k}w_r\Big)=\sum_{r=1}^{m}A_{r,k}\,\psi_j(w_r)=A_{j,k}$$

两个结果都等于 $(\psi_j\circ T)(v_k)$，故 $C_{k,j}=A_{j,k}$ 对一切 $j,k$ 成立，即 $C=A^{\mathsf{T}}$。∎

> [!important] 这个证明的骨架只有一句话
> **$C_{k,j}$ 和 $A_{j,k}$ 是同一个数，只是从两条不同的路算出来的。**
> 一条路走 $\mathcal{M}(T')$ 的定义，另一条走「先 $T$ 后 $\psi_j$」。
> 两条路的交点，就是转置关系的来源。

**具体算一个。** 设 $T:\mathbb{R}^3\to\mathbb{R}^2$，$T(x,y,z)=(4x+5y+6z,\ 7x+8y+9z)$。关于标准基，

$$A=\begin{pmatrix}4&5&6\\7&8&9\end{pmatrix}$$

所以 $\mathcal{M}(T')=A^{\mathsf{T}}=\begin{pmatrix}4&7\\5&8\\6&9\end{pmatrix}$。核对一个元素：$\varphi_1$ 是 $\mathbb{R}^2$ 的第一个坐标泛函，那么

$$T'(\varphi_1)(x,y,z)=\varphi_1(4x+5y+6z,\ 7x+8y+9z)=4x+5y+6z$$

也就是 $T'(\varphi_1)=4\psi_1+5\psi_2+6\psi_3$——系数 $(4,5,6)$ 正是 $A$ 的**第一行**，也是 $A^{\mathsf{T}}$ 的**第一列** ✓。

### 3.11 副产品：列秩等于行秩

有了 3.10，09 讲的「列秩等于行秩」可以有一个几乎不用算的证明。设 $A\in\mathbb{F}^{m,n}$，定义 $T:\mathbb{F}^{n,1}\to\mathbb{F}^{m,1}$ 为 $Tx=Ax$，则 $\mathcal{M}(T)=A$。于是

$$\begin{aligned}A\ \text{的列秩}&=\dim\operatorname{range}T\\&=\dim\operatorname{range}T'\\&=\mathcal{M}(T')\ \text{的列秩}\\&=A^{\mathsf{T}}\ \text{的列秩}\\&=A\ \text{的行秩}\end{aligned}$$

第二个等号是 3.8(c)，第四个是 3.10。转置把行变成列，所以「$A^{\mathsf{T}}$ 的列秩」就是「$A$ 的行秩」。∎

> [!note] 这件事漂亮在哪
> 列秩等于行秩，单看矩阵是看不出来的——它像是某种奇迹。
> 但对偶给了一个结构性解释：**行空间是列空间的对偶侧的东西**，
> 而「$T$ 与 $T'$ 值域同维」把两侧的维数钉在了一起。
> 这就是为什么这个结论对**任何**矩阵都成立，跟元素取值毫无关系。

## 四、几何直观 / 记忆钩子

### 泛函的等值线

在 $\mathbb{R}^2$ 上取 $\varphi(x,y)=2x+y$。它把整个平面压到一条数轴上：$\varphi(1,0)=2$、$\varphi(0,1)=1$、$\varphi(1,1)=3$。

现在看「$\varphi$ 等于同一个数」的那些点：

- $\varphi=0$：直线 $2x+y=0$，过原点；
- $\varphi=1$：直线 $2x+y=1$，不过原点；
- $\varphi=3$：直线 $2x+y=3$。

**这三条线互相平行，而 $\varphi$ 的数值就是「第几条」。** 换句话说，一个泛函把平面切成了一族平行直线，并给每条线编了号。

| 几何对象 | 代数身份 |
|---|---|
| 一族平行直线 | 泛函 $\varphi$ 的等值线族 |
| 其中过原点那条 | $\operatorname{null}\varphi$（$\varphi$ 的核） |
| 两条线之间的「间隔」 | 值差除以 $\varphi$ 在法向上的变化率 |
| 直线的方向 | 由 $\varphi$ 决定，与 $\varphi$ 的系数正交 |

> [!tip] 这个图像为什么值得记
> 它把「一个泛函 = 一张试卷」讲通了：每个向量答题，$\varphi$ 给分。
> 得零分的那批向量构成一张过原点的平面（核）；得 $1$ 分的那批构成它的一个平移。
>
> 顺带核对维数：$\dim\operatorname{range}\varphi=1$（自测第 5 题：非零泛函必满射），
> 由 08 讲基本定理得 $\dim\operatorname{null}\varphi=n-1$；再用 3.6 于 $U=\operatorname{null}\varphi$，得
> $$\dim(\operatorname{null}\varphi)^0=n-(n-1)=1$$
> 而 $(\operatorname{null}\varphi)^0=\operatorname{span}(\varphi)$——**「只差一个尺度」的那一个泛函**。
> 这就解释了为什么「一张等值线族」与「一个泛函」是同一件事。

### 零化子 = 「看不见的维数」

$U^0$ 的定义是「在 $U$ 上全部瞎掉」。那么 $U$ 越大，能瞎掉的泛函越少——这正是 $\dim U^0=\dim V-\dim U$ 的几何读法：

$$(\text{瞎掉的泛函数}) = (\text{总维数}) - (\text{被测量的维数})$$

就像量一个 $3$ 维物体，你能取的独立读数最多 $3$ 个；如果你只量其中一张平面（$2$ 维），那剩下的 $1$ 个自由度就是「你没法用这些读数区分的方向」。

### 记忆钩子

> **基是骨架，对偶基是卡尺。**
> 骨架定方向，卡尺定读数。换骨架，卡尺跟着换。
>
> **对偶把箭头反过来，把数字留下来。**
> $T:V\to W$ 变成 $T':W'\to V'$；复合 $ST$ 变成 $T'S'$；矩阵 $A$ 变成 $A^{\mathsf{T}}$。
>
> **核与像换位。**
> $\operatorname{null}T'=(\operatorname{range}T)^0$、$\operatorname{range}T'=(\operatorname{null}T)^0$；
> 单射对满射，满射对单射。

## 五、常见误区

> [!warning] 误区 1：把 $V$ 与 $V'$ 当成同一个空间，随手把 $\varphi$ 和 $v$ 相加
> $\varphi\in V'$ 是函数，$v\in V$ 是向量。$\varphi+v$ 没有定义，$\varphi\cdot v$ 也没有。
> 唯一有定义的「混合运算」是**求值**：$\varphi(v)\in\mathbb{F}$，结果是个数。
>
> 为什么容易错：在 $\mathbb{R}^n$ 里二者都能写成一列 $n$ 个数，看起来一样。
> $c=(c_1,\dots,c_n)$ 与 $\varphi(x)=c_1x_1+\cdots+c_nx_n$ 确实一一对应——
> 但这是**借着标准基**做的配对，不是「它们本来是一个东西」。换一组基，这层对应就散了。

> [!warning] 误区 2：把 $T'$ 当成 $T$ 的转置
> $T'$ 是**映射**：$T'\in\mathcal{L}(W',V')$，输入是 $W$ 上的泛函。
> 转置是**矩阵**层面的事，而且它只在两侧都取对偶基时才成立（3.10）。
>
> 具体错法：算出 $\mathcal{M}(T)$ 是 $3\times2$，就说「$T'$ 是那个 $2\times3$ 的矩阵」。
> 少了一句「关于哪两组基」——**矩阵从来不能脱离基单独说话**（09 讲）。

> [!warning] 误区 3：以为 $U^0$ 是 $V$ 的子空间，或者以为它就是正交补
> $U^0\subseteq V'$，$U\subseteq V$，两者住在不同空间，不能比较包含，也不能相加。
>
> 对比一下 $\mathbb{R}^3$ 中的平面 $U=\{(x,y,z):x+y+z=0\}$：
> - $U^0=\operatorname{span}(\varphi)$，其中 $\varphi(x,y,z)=x+y+z$——它住在 $(\mathbb{R}^3)'$ 里；
> - 正交补 $U^{\perp}=\operatorname{span}\big((1,1,1)\big)$——它住在 $\mathbb{R}^3$ 里。
>
> 两者维数都是 $1$，长得也像，但**只有先有内积，才能把它们对应起来**。
> 在纯对偶的理论里，$U^0$ 与 $U^{\perp}$ 是两样东西。

> [!warning] 误区 4：以为 $V\cong V'$ 是「自然」的
> 维数相同确实给出同构，但这个同构**必须选基**。换基，对偶基全换（第二节的斜基例子）。
> 所以「$v$ 对应哪个 $\varphi$」没有内在答案。
>
> 对比：$V\cong V''$ 有一个**不需要选基**的同构（第六节）。这就是为什么数学上把 $V''$ 叫作「自然」的那个。
> 顺带一个推论式的检验：如果你写下的 $V\to V'$ 同构在换基之后变了，那它就不是自然的。

> [!warning] 误区 5：把单射与满射的对偶方向记反
> 正确的是：
> $$T\ \text{满射}\iff T'\ \text{单射},\qquad T\ \text{单射}\iff T'\ \text{满射}$$
> 也就是说，**$T$ 与 $T'$ 的性质是交叉的**，不是平行的。
>
> 记法：$T$ 的「像不满」在对偶侧变成「核非零」。像不满 ↔ 核非零，正是 $\operatorname{range}T'=(\operatorname{null}T)^0$ 与 $\operatorname{null}T'=(\operatorname{range}T)^0$ 这两条的直接后果。

> [!warning] 误区 6：把 $\dim U^0=\dim V-\dim U$ 到处乱用
> 这条的证明用了两次「有限维」：$\dim V'=\dim V$（第二节）与线性映射基本定理（08 讲）。
> 无限维时 $V'$ 可能比 $V$「大得多」，这个等式不成立。
> 本讲所有维数结论都默认有限维——这不是省事，是必要条件。

## 六、拓展（可跳过）

### 双重对偶：不用选基的同构

设 $V''=(V')'$，叫 $V$ 的**双重对偶空间**。定义

$$\Lambda:V\to V'',\qquad (\Lambda v)(\varphi)=\varphi(v)$$

注意这个定义长什么样：$\Lambda v$ 是 $V''$ 的元素，也就是说它**是一个作用在泛函上的泛函**。它做什么？把 $\varphi$ 送去 $\varphi(v)$——**把「测量」这件事本身当成被测量的对象。**

$\Lambda$ 是线性的：$(\Lambda(u+v))(\varphi)=\varphi(u+v)=\varphi(u)+\varphi(v)=(\Lambda u)(\varphi)+(\Lambda v)(\varphi)$。

$\Lambda$ 是单射。设 $\Lambda v=0$，即对**所有** $\varphi\in V'$ 有 $\varphi(v)=0$。若 $v\neq0$，把它扩成基 $v=v_1,v_2,\dots,v_n$，取对偶基的第一个 $\varphi_1$，则 $\varphi_1(v)=1\neq0$，矛盾。故 $v=0$。

有限维时 $\dim V''=\dim V'=\dim V$，单射即为同构。所以

$$V\cong V''\qquad(\text{不需要选任何基})$$

> [!important] 「自然」在这里的确切含义
> $\Lambda$ 的公式里**没有出现任何基**：$(\Lambda v)(\varphi)=\varphi(v)$，只用了求值。
> 所以换基不改变 $\Lambda$。
>
> 而 $V\to V'$ 的同构没有这种写法——你能写出的每一个都需要先挑一组基。
> 这就是「自然同构」与「恰好同构」的区别。这一区分在微分几何、表示论里是基础语言。

### 商空间的对偶就是零化子

设 $U\subseteq V$，$\pi:V\to V/U$ 是商映射（11 讲）。则 $\pi'\in\mathcal{L}\big((V/U)',V'\big)$，并且可以证明

$$\pi'\ \text{是单射，且}\ \operatorname{range}\pi'=U^0$$

于是 $\pi'$ 是 $(V/U)'$ 到 $U^0$ 的同构。读法：**「商掉 $U$ 之后还能问的问题」，正好就是「在 $U$ 上瞎掉的那些泛函」。** 两边都是由「$U$ 之外的那部分信息」构成的。

这个同构同样不需要选基，而且连有限维都不要求。

### 一组泛函的零空间交集

设 $\varphi_1,\dots,\varphi_m\in V'$ 线性无关，则

$$\dim\big(\operatorname{null}\varphi_1\cap\cdots\cap\operatorname{null}\varphi_m\big)=\dim V-m$$

这是 3.6 的一个化身，但要用 3.9 才落得干脆。定义

$$\Gamma:V\to\mathbb{F}^m,\qquad \Gamma(v)=\big(\varphi_1(v),\dots,\varphi_m(v)\big)$$

$\Gamma$ 显然线性，而且 $\operatorname{null}\Gamma$ 恰好就是那个交集。

断言 $\Gamma$ 是满射。按 3.9，只需证 $\Gamma'$ 是单射。取 $\mathbb{F}^m$ 的标准基的对偶基 $\psi_1,\dots,\psi_m$，则

$$\big(\Gamma'(\psi_j)\big)(v)=\psi_j(\Gamma v)=\varphi_j(v)$$

即 $\Gamma'(\psi_j)=\varphi_j$。于是 $\Gamma'$ 把 $(\mathbb{F}^m)'$ 的一组基送到 $V'$ 中一个**线性无关组**（$\varphi_1,\dots,\varphi_m$ 线性无关是假设）——这正说明 $\Gamma'$ 是单射。

于是 $\Gamma$ 满射，由 08 讲基本定理，

$$\dim\big(\operatorname{null}\varphi_1\cap\cdots\cap\operatorname{null}\varphi_m\big)=\dim\operatorname{null}\Gamma=\dim V-\dim\operatorname{range}\Gamma=\dim V-m$$

∎

**这就是「每多一个独立方程，解空间少一维」的严格版本。** 齐次方程组 $Ax=0$ 的每一行给一个泛函，行向量线性无关的条数就是 $\operatorname{rank}A$，于是解空间维数 $=n-\operatorname{rank}A$。第一节提出的那个问题，到这里有了答案。

## 七、自测（先做，再看答案）

**1.** 判断下列哪些是线性泛函，不是的说出哪条性质坏了：

(a) $\varphi(x,y)=x+2y-1$；(b) $\varphi(p)=p(0)p(1)$；(c) $\varphi(A)=\operatorname{tr}(A)$（$A$ 为 $2\times2$ 矩阵）；(d) $\varphi(x,y)=|x|$。

**2.** 设 $V=\mathbb{R}^3$，基 $v_1=(1,0,1)$、$v_2=(0,1,1)$、$v_3=(0,0,1)$。求它的对偶基，并写出 $\varphi_1,\varphi_2,\varphi_3$ 的显式公式。

**3.** 设 $U=\operatorname{span}\big((1,1,0),(0,1,1)\big)\subseteq\mathbb{R}^3$。求 $U^0$，并用维数公式核对。

**4.** 设 $T:\mathbb{R}^2\to\mathbb{R}^2$，$T(x,y)=(x+2y,\ 3x+4y)$。设 $\varphi_1,\varphi_2$ 是 $\mathbb{R}^2$ 标准基的对偶基。(a) 写出 $\mathcal{M}(T')$；(b) 把 $T'(\varphi_1)$、$T'(\varphi_2)$ 写成 $\varphi_1,\varphi_2$ 的线性组合，核对与 (a) 是否一致。

**5.** 设 $\varphi$ 是 $V$ 上的线性泛函且 $\varphi\neq0$。证明 $\varphi$ 是满射。（提示：先想 $\operatorname{range}\varphi$ 是 $\mathbb{F}$ 的什么。）

> [!success]- 答案（点开）
> **1.** (a) 不是。$\varphi(0,0)=-1\neq0$，线性映射必须把零送到零。
> (b) 不是。$\varphi(2p)=p(0)p(1)\cdot4\neq2\varphi(p)$——它是二次的。
> (c) 是。迹对矩阵加法与标量乘都线性。
> (d) 不是。$\varphi\big((-1)(1,0)\big)=\varphi(-1,0)=1$，而 $(-1)\varphi(1,0)=-1$，标量乘坏了。
>
> **2.** 设 $\varphi_j(x,y,z)$ 待定。由第三节 3.1 的公式，把 $(x,y,z)$ 写成基的线性组合：
> $$(x,y,z)=x\cdot(1,0,1)+y\cdot(0,1,1)+(z-x-y)\cdot(0,0,1)$$
> 系数依次是 $x$、$y$、$z-x-y$，所以
> $$\varphi_1(x,y,z)=x,\quad \varphi_2(x,y,z)=y,\quad \varphi_3(x,y,z)=z-x-y$$
> 核对：$\varphi_3(v_3)=1-0-0=1$ ✓；$\varphi_3(v_1)=1-1-0=0$ ✓；$\varphi_3(v_2)=1-0-1=0$ ✓。
> （也可设 $ax+by+cz$ 解三个方程，结果相同。）
>
> **3.** 设 $\varphi(x,y,z)=ax+by+cz$。要求在 $(1,1,0)$ 与 $(0,1,1)$ 上为零：
> $$a+b=0,\qquad b+c=0$$
> 取 $b=t$，则 $a=-t$、$c=-t$，即 $\varphi=t(-x+y-z)$。故
> $$U^0=\operatorname{span}(\varphi),\qquad \varphi(x,y,z)=-x+y-z$$
> 核对维数：$\dim U=2$（两向量不共线），$\dim U^0=1=3-2$ ✓。
>
> **4.** (a) $A=\mathcal{M}(T)=\begin{pmatrix}1&2\\3&4\end{pmatrix}$，故
> $$\mathcal{M}(T')=A^{\mathsf{T}}=\begin{pmatrix}1&3\\2&4\end{pmatrix}$$
> (b) $T'(\varphi_1)(x,y)=\varphi_1(x+2y,\ 3x+4y)=x+2y=\varphi_1(x,y)+2\varphi_2(x,y)$；
> $T'(\varphi_2)(x,y)=3x+4y=3\varphi_1(x,y)+4\varphi_2(x,y)$。
> 所以系数依次是 $(1,2)$ 与 $(3,4)$，正是 $\mathcal{M}(T')$ 的两列 ✓。
> （注意：这两列与 $A$ 的两**行**相同，这就是转置。）
>
> **5.** $\operatorname{range}\varphi$ 是 $\mathbb{F}$ 的子空间。而 $\mathbb{F}$ 的子空间只有两个：$\{0\}$ 与 $\mathbb{F}$ 全体。
> 若 $\operatorname{range}\varphi=\{0\}$，则 $\varphi$ 把一切都送到 $0$，即 $\varphi=0$，与假设矛盾。
> 故 $\operatorname{range}\varphi=\mathbb{F}$，$\varphi$ 是满射。∎
> 顺带一个结论：**$\mathbb{F}$ 上的非零线性泛函都是满的**，所以它的核必然是 $n-1$ 维的（3.6）。

## 八、复习卡

| 项 | 内容 |
|---|---|
| **线性泛函** | $V$ 上从 $V$ 到 $\mathbb{F}$ 的线性映射，即 $\mathcal{L}(V,\mathbb{F})$ 的元素 |
| **对偶空间** | $V'=\mathcal{L}(V,\mathbb{F})$，运算逐点做 |
| **维数相等** | 有限维时 $\dim V'=\dim V$ |
| **对偶基** | $\varphi_j(v_k)=\delta_{jk}$；存在唯一由线性映射引理保证 |
| **对偶基读坐标** | $v=\varphi_1(v)v_1+\cdots+\varphi_n(v)v_n$ |
| **对偶基是基** | 用 $v_k$ 去咬可证线性无关；长度 $=\dim V'$ |
| **对偶映射** | $T'(\varphi)=\varphi\circ T$，$T'\in\mathcal{L}(W',V')$，方向相反 |
| **复合反序** | $(ST)'=T'S'$；另有 $(S+T)'=S'+T'$、$(\lambda T)'=\lambda T'$ |
| **零化子** | $U^0=\{\varphi\in V':\varphi\ \text{在}\ U\ \text{上恒为}\ 0\}\subseteq V'$ |
| **零化子是子空间** | 是 $V'$ 的子空间 |
| **零化子维数** | $\dim U^0=\dim V-\dim U$（有限维） |
| **两个极端** | $U^0=\{0\}\iff U=V$；$U^0=V'\iff U=\{0\}$ |
| **对偶的核与像** | $\operatorname{null}T'=(\operatorname{range}T)^0$；$\operatorname{range}T'=(\operatorname{null}T)^0$ |
| **同维** | $\dim\operatorname{range}T'=\dim\operatorname{range}T$ |
| **单射满射互换** | $T$ 满 $\iff T'$ 单；$T$ 单 $\iff T'$ 满 |
| **矩阵转置** | $\mathcal{M}(T')=\mathcal{M}(T)^{\mathsf{T}}$（两侧取对偶基） |
| **副产品** | 列秩 $=$ 行秩 |
| **双重对偶** | $\Lambda:V\to V''$，$(\Lambda v)(\varphi)=\varphi(v)$，不需选基的同构（有限维） |
| **不自然 vs 自然** | $V\cong V'$ 需选基；$V\cong V''$ 不需要 |

- **另一个角度**：把线性泛函看成「一张试卷」的讲法，在数值分析与优化里非常常见——有限元里的「试探函数 / 检验函数」就是 $V$ 与 $V'$ 各取一套；线性规划里的对偶问题、拉格朗日乘子，都是「用一组成员资格测量约束」的同一思想。这些方向已经超出线性代数的范围，但本讲的结构是它们的骨架。
- **权威查证**：Bronstein《数学手册》俄文第 10 版（1962）与英文第 6 版（2015）均可检索 "dual space / Dualraum / сопряжённое пространство"，可复核对偶空间、零化子、转置映射的定义与记号。
- **术语别名**：线性泛函 = linear functional；对偶空间 = dual space（也叫共轭空间）；对偶映射 = dual map，也叫转置映射（transpose map）；零化子 = annihilator；双重对偶 = double dual / bidual；对偶基 = dual basis。称谓不同不影响内容。
