## 读者也是调用方

一个好的 API 让调用者预测结果，一篇好文章也一样。标题建立承诺，开头定义输入，结构展示路径，结尾返回结果。

含糊的段落通常像一个参数过多的函数：它同时承担背景、论点、例子和转折。拆分之后，思想的类型才会显现。

```txt
claim(context) -> evidence -> implication
```

编辑不是修饰句子，而是在删除隐藏的副作用。
