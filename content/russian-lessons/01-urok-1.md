# Урок 1 · Пе́рвый уро́к — Здра́вствуйте!

> **主题**：俄语字母与发音规则 · 问候与告别 · 自我介绍 · 指认与方位
> **写给**：只认得字母、刚开始学俄语的你。本课不要求你背语法术语，只要求你「能听懂课堂指令 + 能张口套用句型 + 能读准每一个词」。

## 一、这一课到底学什么

课本开头的那段话是全书固定格式，先记住这几个关键词，以后每一课你都能自己看懂：

**В э́том уроке вы…** —「在这一课里您（将）……」

| 俄语 | 中文 |
|---|---|
| познако́митесь с ру́сским алфави́том | 认识俄语字母表 |
| нау́читесь здоро́ваться и проща́ться | 学会问候与告别 |
| нау́читесь знако́миться | 学会结识、自我介绍 |
| узна́ете, как сказа́ть, где нахо́дятся предме́ты и́ли ли́ца | 学会说物品或人在哪里 |
| узна́ете, как указа́ть на лицо́ и́ли предме́т | 学会指认人或物 |

> [!tip] 三个词的区别
> **нау́читесь** = 学会（一项技能）　**узна́ете** = 得知、了解到（一条信息）　**познако́митесь** = 认识、熟悉（一个对象）
> 课本用它们区分「练会的」「知道的」「认识的」，你在别的课里还会反复见到。

**学完这一课，你能做的事**（课本末尾的原话）：

| 功能 | 句子 |
|---|---|
| 打招呼 | Здра́вствуйте!　Приве́т! |
| 问名字 | Как вас зову́т?　Как тебя́ зову́т? |
| 报名字 | Меня́ зову́т… |
| 告别 | До свида́ния!　Пока́! |
| 说位置 | тут, там, вот, до́ма |
| 指认 | Э́то кот.　Вот па́спорт. |

## 二、课堂指令语 —— 认得出这些词，你就能自己用书

俄语教材的练习题全部用**命令式**（「请听」「请写」）开头。下面这些词在每一课都会重复出现，**不需要你会变位，只需要你看见就认得出**。

### 1. 动作指令

| 俄语 | 中文 | 课本原句（节选） |
|---|---|---|
| Слу́шайте | 听 | Слу́шайте и повторя́йте. 听并跟读。 |
| Повторя́йте | 重复、跟读 | Слу́шайте, повторя́йте, чита́йте. |
| Чита́йте | 读 | Чита́йте сле́ва напра́во. 从左往右读。 |
| Прочита́йте | 朗读（读完） | Прочита́йте микроте́кст. 朗读短文。 |
| Пиши́те | 写 | Пиши́те э́ти бу́квы. 写这些字母。 |
| Напиши́те | 写下 | Напиши́те э́ти слоги́ в тетра́ди. |
| Отве́тьте | 请回答（完成体，一次） | Зада́йте вопро́сы и отве́тьте на них. |
| Отвеча́йте | 请回答（未完成体，一般） | |
| Скажи́те | 说 | Скажи́те, что вы ви́дите. |
| Посмотри́те | 看 | Посмотри́те на клавиату́ру. |
| Соста́вьте | 编、造 | Соста́вьте анало́гичные диало́ги. |
| Поста́вьте ударе́ние | 标重音 | Поста́вьте ударе́ние в слова́х. |
| Отме́тьте | 标记、勾选 | Слу́шайте и отме́тьте то, что слы́шите. |
| Соедини́те | 连线 | Прочита́йте слоги́ и соедини́те оди́нковые. |
| Познако́мьтесь | 认识一下 | Познако́мьтесь друг с дру́гом. |
| Реши́те | 解决、完成 | Реши́те кроссво́рд. |

> [!warning] 三个「像」的动词，别混
> **слу́шайте**（听，用耳朵）→ 听录音用这个
> **слы́шите**（听得见，是「听得到」的能力）→ `то, что слы́шите` = 你听到的内容
> **смотри́те / посмотри́те**（看，用眼睛）
> 课本最常出现的一句是 `Слу́шайте и отме́тьте то, что слы́шите.` = 听，并勾出你听到的。

## 三、核心句型 —— 背下来就能直接开口

### 1. 问候与告别

| 俄语 | 中文 | 用法 |
|---|---|---|
| Здра́вствуйте! | 您好！ | 正式，或对多人 |
| Приве́т! | 嗨！ | 非正式，对熟人 |
| До́брое у́тро! | 早上好！ | |
| До́брый день! | 白天好！ | |
| До свида́ния! | 再见！ | 通用 |
| Пока́! | 拜拜！ | 非正式 |
| До за́втра! | 明天见！ | |
| До встре́чи! | 回头见！ | |

### 2. 自我介绍（本课最核心的对话）

```
— Здра́вствуйте! Как вас зову́т?
— Здра́вствуйте! Меня́ зову́т Кристиа́н.
— О́чень прия́тно.
— О́чень прия́тно.
```

**三个可变槽位**：

| 问 | 正式 / 对多人 | Как вас зову́т? |
|---|---|---|
| | 非正式 / 对一人 | Как тебя́ зову́т? |
| 答 | | Меня́ зову́т … |
| 回问 | 正式 | А вас? |
| | 非正式 | А тебя́? |

> [!important] 三个初学者必踩的坑
> 1. **Меня́ зову́т…** 字面是「人们叫我……」，动词永远用 **зову́т**，不要按中文说成 «Я зову́т»。
> 2. **О́чень прия́тно** 是固定短语，两个人**都**说这句，不变形、不加词。
> 3. **Как вас зову́т?** 问的是名字；**Кто вы?** 问的是身份（老师？学生？）。别用错。

### 3. 说身份

| 俄语 | 中文 |
|---|---|
| Я преподава́тель. | 我是教师。（男/女同形也可） |
| Я студе́нт. | 我是大学生。（男） |
| Я студе́нтка. | 我是大学生。（女） |
| А кто вы? | 那您是？ |
| Э́то Дун Лэ. | 这是董乐。 |

> [!note] 俄语现在时**没有**「是」
> 中文说「我是学生」，俄语直接 `Я студе́нт.`，中间不加任何词。这是俄语最重要的习惯之一。

### 4. 指认与方位

| 俄语 | 中文 | 区别 |
|---|---|---|
| Э́то … | 这是…… | 判断、指认 |
| Вот … | 喏，这就是…… | 把东西递到对方面前 |
| Тут … | 这里…… | 说话人所在之处 |
| Там … | 那里…… | 离说话人较远 |
| До́ма | 在家 | 副词，不是「在房子里」 |

课本 mikroтекст（短文）：

> Вот дом. Э́то ко́мната. Тут окно́. Там стол и стул. Тут кот. Кот до́ма.
> 这是房子。这是房间。这儿是窗户。那儿是桌子和椅子。这儿有只猫。猫在家。

上课常用的问题：

| 问句 | 中文 |
|---|---|
| Кто э́то? | 这是谁？（人） |
| Что э́то? | 这是什么？（物） |
| Где …? | ……在哪里？ |

> [!tip] Кто 还是 Что？
> 问「人」用 **Кто**，问「物」用 **Что**。判断标准不是「有没有生命」，而是俄语里是否算「有生命名词」——本课你先记：**人 → кто，其他 → что**。

## 四、关键语法

### 1. 音节与重音（Слог и ударе́ние）

- **音节数 = 元音数**。`кот`（1 个元音）→ 1 音节；`ма́ма`（2 个元音）→ 2 音节。
- 每个词**只有一个**重读音节，读得又长又清楚；其余音节弱化。
- 重读元音我们用**高亮**标出（本资料中所有单词表都是如此）。

### 2. 元音弱化：非重读的 о → [а]（Реду́кция）

这是俄语听力的第一道坎：**写的是 о，读的是 [а]**。

| 写法 | 实际读音 | 中文 |
|---|---|---|
| он | [он] | 他（重读，读 о） |
| она́ | [ана́] | 她 |
| вода́ | [вада́] | 水 |
| молоко́ | [малако́] | 牛奶 |
| Москва́ | [масква́] | 莫斯科 |
| э́то | [э́та] | 这是 |

> [!important] 规律
> **о 在重音上读 [о]，不在重音上读 [а]。** 所以 `молоко́` 三个 о 里，只有最后一个读 [о]，前两个都读 [а]。
> 记忆口诀：**看清重音，再决定 о 读什么。**

### 3. 清浊辅音与「词末清化」（Оглуше́ние）

**成对的清浊辅音**（6 对，必须背）：

| 浊（带声带振动） | б | в | г | д | ж | з |
|---|---|---|---|---|---|---|
| **清**（不振动） | п | ф | к | т | ш | с |

**永远浊的**（没有清音对手）：й, л, м, н, р
**永远清的**：х, ц, ч, щ

**规律：浊辅音在词末要读成对应的清辅音。**

| 写 | 读 | 中文 |
|---|---|---|
| го́род | [го́рат] | 城市（д → [т]） |
| клуб | [клуп] | 俱乐部（б → [п]） |
| флаг | [флак] | 旗（г → [к]） |
| моро́з | [маро́с] | 严寒（з → [с]） |
| Ива́нов | [Ива́ноф] | 伊万诺夫（в → [ф]） |
| автобу́с | [афтобу́с] | 公共汽车（вт → [фт]） |

> [!warning] 这条规则必须从第一课就养成
> `Ива́нов` 读 [Ива́ноф]，`го́род` 读 [го́рат]。**你按字母念，俄国人会觉得别扭；你按规则念，才是对的。**

### 4. 语调结构 ИК-1 / ИК-2 / ИК-3 / ИК-4

俄语不问「用哪个疑问词」，而问「语调往哪儿走」。课本叫 ИК（интонацио́нная констру́кция，语调结构）。

| 类型 | 用途 | 调型 | 例子 |
|---|---|---|---|
| **ИК-1** | 陈述句 | 末尾**平稳下降** | Э́то дом. 这是房子。 |
| **ИК-2** | 特疑问句（有疑问词：кто / что / где / как） | 疑问词重读，末尾**下降** | Кто э́то?　Где студе́нты?　Как вас зову́т? |
| **ИК-3** | 一般疑问句（没有疑问词） | 末尾**上升** | Э́то дом? 这是房子吗？ |
| **ИК-4** | 对比、省略式追问 | 语调**上升后保持** | А э́то? 那这个呢？　А вас? 您呢？ |

> [!tip] 最好用的判断法
> 看**有没有疑问词**：有（кто/что/где/как）→ **ИК-2**，末尾降；
> 没有，只是把陈述句变问句 → **ИК-3**，末尾升。
> `А вас?`、`А тебя́?`、`А э́то?` 这种「那你呢」用 **ИК-4**。

### 5. Вы 和 ты

| | вы | ты |
|---|---|---|
| 用于 | 长辈、陌生人、上级；也指「你们」 | 熟人、同龄朋友、孩子 |
| 例 | Как **вас** зову́т? | Как **тебя́** зову́т? |

> [!important] 一个 вы 两种意思
> **вы** 既是「您」（尊称单数），也是「你们」（复数）。课本专门标出：уважи́тельное Вы（尊称的您）／мно́жественное вы（复数的你们）／неформа́льное ты（非正式的 ты）。
> 对老师、对陌生人，**永远先用 вы**。

## 五、要记的特例

这些是「按规则推不出来、必须单独记住」的点。

| 特例 | 说明 |
|---|---|
| **Здра́вствуйте** | 第一个 **в 不发音**，读 [здра́ствуйт'и]。这是俄语最高频的词，务必一次记对。 |
| **ъ 和 ь** | 33 个字母里这 2 个**本身不发音**。ъ（твёрдый знак 硬音符）、ь（мя́гкий знак 软音符）。它们只影响前面辅音的读法。 |
| **Что** | 读 **[што]**，不读 [что]。课堂指令里到处都是这个词（что вы ви́дите）。 |
| **До свида́ния** | 口语中读 [дасвида́ния]，до 的 о 弱化成 [а]。 |
| **О́чень прия́тно** | 双方**都**说，是固定的礼貌回合，不要说成 «Спаси́бо»。 |
| **Ё 永远是重音** | 只要词里有 ё，重音一定在 ё 上，绝不会在别处。所以 ё 上的重音可以不用标。 |
| **Меня́ зову́т** | 动词固定为 зову́т，不随主语变化。 |
| **Тетра́дь** | 以 ь 结尾却属**阴性**名词。名词的性一般看词尾：辅音结尾多为阳性，-а/-я 多为阴性，-о/-е 多为中性；тетра́дь（还有 день, ночь, рубль…）是这条规律的常见例外。 |
| **Кто э́то? / Что э́то?** | 连读时 э́то 的 э 被前词影响，听感接近 [кто‿э́та]。先记「э́то 永远读 [э́та]」即可。 |

## 六、单词表

> **排序**：同一分区内按**俄语字母表顺序**排列。
> **重音**：重读元音已用**高亮**标出。
> 带「□」的是**认得即可**的词（国际通用词、认读练习词），不要求主动使用。

### 6.1 问候与告别 · Приве́тствие и проща́ние

| 俄语 | 中文 | 类比 / 拓展 / 分辨 |
|---|---|---|
| **До́брое у́тро!** | 早上好！ | 只有 у́тро 用 -ое（中性）；день 和 ве́чер 用 **-ый**：До́брый день! / До́брый ве́чер! |
| **До́брый день!** | 白天好！ | 俄罗斯人白天见面最常用这一句，比 Здра́вствуйте 更暖 |
| **До за́втра!** | 明天见！ | **за́втра** = 明天。同结构：До встре́чи! |
| **До свида́ния!** | 再见！ | 最通用；正式场合首选 |
| **До встре́чи!** | 回头见！ | **встре́ча** = 见面、相遇 |
| **Здра́вствуйте!** | 您好！ | 对多人、对长辈、对陌生人。词中第一个 **в 不发音** |
| **Пока́!** | 拜拜！ | 非正式，对朋友。与 Приве́т! 配成一对 |

> [!note] 类比：见面 / 告别各有一「正式—随意」两档
> 见面：**Здра́вствуйте!**（正式）｜**Приве́т!**（随意）
> 告别：**До свида́ния!**（正式）｜**Пока́!**（随意）
> 记住这个对称，就不会在正式场合说错。

### 6.2 认识与自我介绍 · Знако́мство

| 俄语 | 中文 | 类比 / 拓展 / 分辨 |
|---|---|---|
| **А вас?** | 您呢？ | 正式。非正式说 **А тебя́?** |
| **вы** | 您；你们 | 一个词两种用途，看语境 |
| **и́мя** | 名字 | 中性名词。问名字却不用 и́мя，而用 зову́т |
| **кто** | 谁 | 问人。问物用 **что** |
| **Меня́ зову́т…** | 我叫…… | 字面「人们叫我……」。动词固定 зову́т |
| **О́чень прия́тно** | 很高兴（认识） | 固定礼貌回合，双方都说 |
| **он** | 他 | 对应 **она́** 她 |
| **она́** | 她 | 读 [ана́]，о 弱化 |
| **преподава́тель** | 教师 | 阳/阴同形，男女都能用 |
| **студе́нт** | 大学生（男） | 女学生用 **студе́нтка** |
| **студе́нтка** | 大学生（女） | 加 -ка 构成阴性，是俄语常见构词法 |
| **тебя́** | 你（第四格） | Как тебя́ зову́т? 中的形式 |
| **ты** | 你 | 对熟人才用 |
| **э́то** | 这是；这个 | 读 [э́та] |
| **я** | 我 | 现在时句子里常省略也成立 |

> [!tip] 构词小拓展：-ка 变阴性
> **студе́нт → студе́нтка**（大学生）
> **преподава́тель → преподава́тельница**（女教师，本课未出现，但规律相同）
> 以后你还会见到 **-ка / -ница** 这套「把阳性变阴性」的尾巴。

### 6.3 指认与方位 · Указа́ние и ме́сто

| 俄语 | 中文 | 类比 / 拓展 / 分辨 |
|---|---|---|
| **вот** | 喏，这就是 | 强调「就在这儿给你看」；比 э́то 更有展示感 |
| **до́ма** | 在家 | 副词。对比：**дом** 是「房子」这个建筑物 |
| **там** | 那里 | 离说话人远 |
| **тут** | 这里 | 就在说话人身边。口语常说，书面可用 **здесь** |
| **дом** | 房子 | 单音节，不标重音。**до́ма** 是它的副词形式 |

> 1. **重音常在末尾的音节**：вода́, голова́, коро́ва, луна́, молоко́, нога́, окно́, рука́ —— 这一组可以打包记。

> 3. **ва́за / ро́за / фа́ра** —— 三个「-аза/-ара」型词，重音都在第一音节。

## 六、日常用语与易混辨析 ★

> 本节素材取自官方课件（Урок 1）与《大众俄语40课》的入门单元，补充课本正文之外、但你**天天都会用**的表达。
> 用词已与其余各课比对，**只收本课首次出现**的词（спаси́бо / пожа́луйста / извини́те 等礼貌用语在 Урок 2 才正式登场，这里不抢收）。

### 6.1 日常用语

| 俄语 | 中文 | 使用场景 |
|---|---|---|
| **Здра́вствуйте!** | 您好！ | 对长辈、陌生人、多人；进教室、进商店都用它 |
| **Здра́вствуй!** | 你好！ | 对**一个人**、关系较近时。注意：少了 -те，就只对一个人 |
| **Приве́т!** | 嗨！ | 只对朋友、同龄人 |
| **До́брое у́тро!** | 早上好！ | 约到中午前 |
| **До́брый день!** | 日安！ | 白天最常用，比 Здра́вствуйте 更暖 |
| **До́брый ве́чер!** | 晚上好！ | 傍晚见面时 |
| **До свида́ния!** | 再见！ | 最通用，任何场合都对 |
| **До за́втра!** | 明天见！ | 当天还会再见的场合 |
| **До встре́чи!** | 回头见！ | 约好还会见面 |
| **Пока́!** | 拜拜！ | 只对熟人 |
| **О́чень прия́тно!** | 很高兴（认识您）！ | 被介绍之后的固定应答 |
| **Как вас зову́т?** | 您叫什么名字？ | 正式 |
| **Меня́ зову́т…** | 我叫…… | 报名字 |
| **А вас?** | 您呢？ | 回问对方 |
| **Кто э́то?** | 这是谁？ | 问人 |
| **Что э́то?** | 这是什么？ | 问物 |
| **Где…?** | ……在哪儿？ | 找人或找东西 |
| **Хорошо́!** | 好！行！ | 答应、认可 |
| **Да.** / **Нет.** | 是／不是 | 最基础的两个回答 |

> [!tip] 打招呼的「时间梯度」
> **До́брое у́тро!**（早）→ **До́брый день!**（白天）→ **До́брый ве́чер!**（晚）
> 三个词里只有 у́тро 配 **-ое**（中性），день 和 ве́чер 都配 **-ый**（阳性）——
> 因为 у́тро 是中性名词，день、ве́чер 是阳性名词。**形容词跟着名词的性走**，这是俄语的第一条铁律。

### 6.2 易混辨析

**① Здра́вствуйте! 还是 Здра́вствуй! —— 看人数**

| | 用 | 说明 |
|---|---|---|
| 对一个人（平辈/熟人） | **Здра́вствуй!** | 词尾没有 -те |
| 对一个人（长辈/陌生人）、对多人 | **Здра́вствуйте!** | 词尾有 **-те**，是复数/敬称标记 |

> [!warning] 这是「命令式 -те」的同一条规律
> 你在第二节见过 `Скажи́те` / `Пиши́те` —— 那些 **-те** 也是这个作用：**对多人或表示客气**。
> 所以 Здра́вствуй → Здра́вствуйте，和 Скажи́ → Скажи́те 是**同一个变化**。认准这个 -те，一课顶三课。

**② Приве́т! 和 Здра́вствуйте! 不能混用**

| | 语域 | 对谁 | 场合 |
|---|---|---|---|
| **Здра́вствуйте!** | 正式/中性 | 长辈、老师、陌生人、任何多人 | 教室、商店、办公室 |
| **Приве́т!** | 随意 | 朋友、同龄人 | 私下 |
| **Пока́!** | 随意 | 朋友 | 私下，对应 Приве́т! |
| **До свида́ния!** | 正式/中性 | 任何人 | 对应 Здра́вствуйте! |

> [!note] 见面/告别各有「正式—随意」两档，成对记
> 见面：**Здра́вствуйте!**（正式）｜**Приве́т!**（随意）
> 告别：**До свида́ния!**（正式）｜**Пока́!**（随意）
> 记住这个对称，就不会在正式场合说错。

**③ Э́то … / Вот … / Тут … / Там … —— 四个「指」不是一回事**

| 词 | 意思 | 什么时候用 |
|---|---|---|
| **Э́то …** | 这是…… | 判断「是什么」，最常用 |
| **Вот …** | 喏，这就是…… | 把东西**递到对方面前**，有展示感 |
| **Тут …** | 这里…… | 就在**说话人身边** |
| **Там …** | 那里…… | 离说话人**较远** |

```
— Что э́то?        这是什么？
— Э́то дом.         这是房子。
— Вот ваш па́спорт.  喏，您的护照。
— Где кот?          猫在哪儿？
— Кот там.          猫在那儿。
— Кот до́ма.         猫在家。
```

**④ 说身份：Кто вы? 不是「你是谁」**

`Кто вы?` 问的是**身份、职业**（老师？学生？），回答用 `Я студе́нт.`。
问**名字**要用 `Как вас зову́т?`。这两个问句初学者最容易搞混。

| 问 | 答 |
|---|---|
| **Как вас зову́т?** | Меня́ зову́т И́ра. |
| **Кто вы?** | Я студе́нт. / Я преподава́тель. |

**⑤ 俄语现在时没有「是」**

| ✗ 错误 | ✓ 正确 | 原因 |
|---|---|---|
| Я есть студе́нт. | **Я студе́нт.** | 俄语现在时不用系动词 |
| Э́то есть дом. | **Э́то дом.** | 同上 |
| Я зову́т Ива́н. | **Меня́ зову́т Ива́н.** | зову́т 是固定形式，主语是 меня́ |

**⑥ 读音易混：э́то 听起来像 [э́та]**

`э́то` 的实际读音是 **[э́та]**（非重读的 о 弱化成 [а]），不是 [э́то]。
所以听到俄国人说 [э́та] 时，**那就是 э́то**，不要以为听到了另一个词。

合上资料，试着回答：

1. 「您好」和「嗨」分别怎么说？哪个对老师用？
2. 「你叫什么名字」正式/非正式两种问法？

5. `го́род`、`Ива́нов` 词末读什么音？
6. 有疑问词的问句用 ИК-几？没有疑问词的问句用 ИК-几？
7. 下列词哪些是单音节（因此不标重音）？`стол　луна́　суп　кот　окно́　торт`

> [!success]- 答案要点

> 2. Как вас зову́т?（正式）／Как тебя́ зову́т?（非正式）
