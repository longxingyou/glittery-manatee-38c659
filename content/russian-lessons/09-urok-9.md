# Урок 9 · Девя́тый уро́к — Добро́ пожа́ловать в Росси́ю!

> **主题**：第二格（属格）· у кого́ есть / нет · отку́да（из + 第二格）· чей?（谁的）· 几点钟 · 多少钱 · 几号 · 运动动词的完成体前缀
> **写给**：只认得字母、刚开始学俄语的你。
> 本课的主题是**第二格**——俄语里用得最多的一个格。

## 一、这一课到底学什么

**В э́том уро́ке вы…** —「在这一课里您（将）……」

| 俄语 | 中文 |
|---|---|
| узна́ете, как сказа́ть, что у вас есть и чего́ у вас нет | 学会说有什么、没有什么 |
| узна́ете, как сказа́ть, кому́ принадлежи́т та и́ли друга́я вещь | 学会说东西属于谁 |
| узна́ете, как сказа́ть, отку́да вы прие́хали | 学会说你从哪里来 |
| нау́читесь спра́шивать и отвеча́ть, ско́лько вре́мени | 学会问和答「几点钟」 |
| нау́читесь спра́шивать, что ско́лько сто́ит | 学会问「多少钱」 |
| нау́читесь спра́шивать, како́е сего́дня число́ | 学会问「今天几号」 |
| узна́ете бо́льше о Росси́и, ру́сских города́х и тради́циях | 了解更多俄罗斯、城市和传统 |

课本末尾的「**Тепе́рь вы мо́жете**」：

| 功能 | 例句 |
|---|---|
| 说有什么、没有什么 | **У меня́ есть кот. У меня́ нет ко́шки.** |
| 问和说多少钱 | **Ско́лько сто́ит э́тот самова́р? — Он сто́ит две ты́сячи рубле́й.** |
| 说从哪里来 | **Я прие́хал из Кита́я.** |
| 问和说几点钟 | **Кото́рый сейча́с час? — Сейча́с пять часо́в.** |
| 讲自己平常的一天 | **Я встаю́ в 8 часо́в утра́. Я ложу́сь в 11 ве́чера. Я сплю 9 часо́в.** |
| 说东西是谁的 | **Чей э́то па́спорт? — Э́то па́спорт Алекса́ндра.** |
| 说日期 | **Како́е сего́дня число́? — Сего́дня пе́рвое января́.** |
| 讲俄罗斯城市 | **Владивосто́к нахо́дится на восто́ке Росси́и.** |
| 说一生中做了多久某事 | **Мы рабо́таем 11 лет.** |

> [!success] 本课的关口：第二格来了
> Урок 4 学了第六格（在哪儿），Урок 7 学了第四格（去哪儿），Урок 8 学了第五格（季节）。
> **Урок 9 开始学第二格**——俄语里**用途最广**的格。
> 中文里「**没有**书」「**书的**封面」「**从**中国**来**」「三**本书**」，俄语**都用第二格**。
> **一句话**：第二格表示「**所属、缺失、来源、数量**」。
> `У меня́ **нет бра́та**.`（没有兄弟 — 缺失）
> `Э́то кни́га **бра́та**.`（兄弟的书 — 所属）
> `Я из **Кита́я**.`（从中国来 — 来源）
> `три **кни́ги**`（三本书 — 数量）

## 三、核心句型

### 1. у кого́ есть / нет（本课主干）

```
Это Кристиа́н. Это Кла́ус.
У Кристиа́на есть кот Фёдор. У него́ нет кота́.

Это Хуани́та. У Хуани́ты есть брат.
Это Саку́ра. У неё нет бра́та.
```

**核心公式**：

| 肯定 | 否定 |
|---|---|
| **У + 第二格 + есть + 第一格** | **У + 第二格 + нет + 第二格** |
| У меня́ **есть** брат. | У меня́ **нет** бра́та. |
| У Ива́на **есть** велосипе́д. | У Ива́на **нет** велосипе́да. |
| У А́нны **есть** маши́на. | У А́нны **нет** маши́ны. |

> [!important] ★★ есть 和 нет 后面用不同的格
> **у кого́ есть + 第一格**（有什么 — 主语是那个东西）
> **у кого́ нет + 第二格**（没有什么 — 被否定的东西用第二格）
> ```
> У меня́ есть брат.        （有兄弟 —— брат 第一格）
> У меня́ нет бра́та.        （没有兄弟 —— бра́та 第二格）
> ```
> **这是本课最核心的一条**：
> **有** → 第一格；**没有** → 第二格。
> **нет 永远要求第二格**。这一点要变成条件反射。

**人称代词的第二格（у кого́）**：

| 第一格 | у + 第二格 | 中文 |
|---|---|---|
| я | **у меня́** | 我有 |
| ты | **у тебя́** | 你有 |
| он | **у него́** | 他有 |
| она́ | **у неё** | 她有 |
| оно́ | **у него́** | 它有 |
| мы | **у нас** | 我们有 |
| вы | **у вас** | 您/你们有 |
| они́ | **у них** | 他们有 |

> [!important] ★★ у него́ / у неё / у них 多一个 н
> 第三人称代词在**前置词后面要加 н-**：
> `у **него́**`（不是 «у его́»）、`у **неё**`（不是 «у её»）、`у **них**`（不是 «у их»）
> **原因**：历史音变。原来它是 «у йего́»，у 和 е 之间加了连接音 н。
> **同类**：`к нему́`（向他）、`от него́`（从他）、`с ним`（和他）
> **不是**第三人称的代词不加：`у меня́`、`у тебя́`、`у нас`、`у вас` —— 都是原来就有的形式。

**名词的第二格变化**：

| 第一格词尾 | 第二格词尾 | 例 |
|---|---|---|
| **阳性** 硬辅音 | **-а** | брат → бра́т**а**；велосипе́д → велосипе́д**а** |
| **阳性** -й / -ь | **-я** | Андре́й → Андре́**я**；слова́рь → слова́р**я** |
| **阴性** -а | **-ы** | ма́ма → ма́м**ы**；маши́на → маши́н**ы** |
| **阴性** -я | **-и** 或 **-ы** | Таня → Та́н**и**；семья́ → семьи́ |
| **阴性** -ь | **-и** | тетра́дь → тетра́д**и** |
| **中性** -о | **-а** | письмо́ → письма́ |
| **中性** -е | **-я** | мо́ре → мо́ря |

**课本给的对照表（У КОГО? №2）**：

| 第一格 | 第二格 | 说明 |
|---|---|---|
| Ива́н | у Ива́н**а** | 硬辅音 + а |
| Андре́й | у Андре́**я** | -й → -я |
| преподава́тель | у преподава́тел**я** | -ь → -я |
| А́нна | у А́нн**ы** | -а → -ы |
| Та́ня | у Та́н**и** | -я → -и |
| подру́га | у подру́г**и** | га → ги |
| ша́пка | у ша́пк**и** | ка → ки |

> [!warning] ★★ 拼写规则又来了：г/к/х 后写 и
> **-а 结尾的名词，第二格本来是 -ы**，但**г、к、х 后面不能写 ы**，所以改成 **-и**：
> `подру́га → подру́ги`（不是 «подру́гы»）
> `ша́пка → ша́пки`（不是 «ша́пкы»）
> **这条规则你已经见过三次了**：
> Урок 2（жи/ши 写 и）、Урок 3（复数 -и 而不是 -ы）、Урок 6（形容词 -ий 而不是 -ый）。
> **现在它出现在第二格里——这是贯穿全书的同一条规则。**

**特殊变化的形式（课本专门列出）**：

| 第一格 | 第二格（у кого́） | 中文 |
|---|---|---|
| **мать** | у **ма́тери** | 母亲 |
| **дочь** | у **до́чери** | 女儿 |
| **оте́ц** | у **отца́** | 父亲 |
| **де́ньги** | нет **де́нег** | 钱 |
| **вре́мя** | нет **вре́мени** | 时间 |

> [!important] ★★ 五个必须单独记的第二格
> **мать → у ма́тери**（-ерь 型）
> **дочь → у до́чери**（同上）
> **оте́ц → у отца́**（去掉 е，加 а；ц 后不写 ы）
> **де́ньги → де́нег**（这是**复数第二格**！去掉 ьги，加 ег）
> **вре́мя → вре́мени**（-мя 结尾的中性名词，加 -ени）
> **课本的对话**：
> `— У тебя́ есть де́ньги? — У меня́ нет **де́нег**.`
> `— У тебя́ есть вре́мя? — У меня́ нет **вре́мени**.`
> **注意**：`де́ньги` 和 `вре́мя` 都是**要单独背的**，不能靠规则推。

### 2. Это X + 第二格（所属）—— 与 чей?

```
Чей э́то слова́рь? — Э́то слова́рь Ива́на.
Чья э́то кни́га? — Э́то кни́га Серге́я.
Чьё э́то письмо́? — Э́то письмо́ Ве́ры.
Чьи э́то тетра́ди? — Э́то тетра́ди На́сти.
```

**公式**：**Чей / Чья / Чьё / Чьи + э́то + 名词？**

| 疑问词 | 用于 | 例 |
|---|---|---|
| **Чей** | 阳性 | **Чей** э́то слова́рь? |
| **Чья** | 阴性 | **Чья** э́то кни́га? |
| **Чьё** | 中性 | **Чьё** э́то письмо́? |
| **Чьи** | 复数 | **Чьи** э́то тетра́ди? |

**回答**：**Э́то + 名词 + 所有者（第二格）**

| 俄语 | 中文 |
|---|---|
| Э́то слова́рь **Ива́на**. | 这是伊万的词典。 |
| Э́то кни́га **Серге́я**. | 这是谢尔盖的书。 |
| Э́то письмо́ **Ве́ры**. | 这是薇拉的信。 |
| Э́то тетра́ди **На́сти**. | 这是娜斯佳的本子。 |

> [!important] ★★ 中文「的」＝ 俄语第二格（无 «的» 字）
> 中文说「伊万**的**词典」，俄语**不加任何词**，直接把人名变第二格：
> `слова́рь **Ива́на**` —— 字面就是「伊万（的）词典」
> ❌ 不要说 «слова́рь **Ива́на**» 里再加个 «свой» 或 «его»。
> ✅ 正确：`Э́то слова́рь Ива́на.`
> **对比「他的」**：如果所有者是代词，则**代词不变格**：
> `Э́то **его́** слова́рь.` 这是他的词典。（его́ 不变）
> `Э́то **её** кни́га.` 这是她的书。（её 不变）
> `Э́то **их** дом.` 这是他们的房子。（их 不变）
> **注意**：这里的 его́/её/их 是**物主代词**（他的/她的/他们的），
> **不加 н-**！加 н- 的是 `у него́` 那种情况（前置词后）。
> `Э́то **его́** слова́рь.`（他的词典，不加 н）
> `У **него́** есть слова́рь.`（他有词典，加 н）

### 3. отку́да? —— 从哪里来

```
— Я из Росси́и, из Москвы́. А отку́да вы?
— Я из То́кио, из Япо́нии.
— Я из Ве́ны, из А́встрии.
```

**公式**：**из + 第二格**（从……里面来）

| 第一格 | из + 第二格 | 中文 |
|---|---|---|
| Петербу́рг | из Петербу́рг**а** | 从彼得堡 |
| Су́здаль | из Су́здал**я** | 从苏兹达尔 |
| Москва́ | из Москв**ы́** | 从莫斯科 |
| Тверь | из Твер**и** | 从特维尔 |
| Кита́й | из Кита́**я** | 从中国 |
| Япо́ния | из Япо́н**ии** | 从日本 |
| Росси́я | из Росси́**и** | 从俄罗斯 |

**运动动词 + отку́да**：

| 俄语 | 中文 |
|---|---|
| Они́ **прие́хали из** Петербу́рга. | 他们从彼得堡来了。 |
| Они́ **прие́хали из** Су́здаля. | 他们从苏兹达尔来了。 |
| Она́ **пришла́ из** шко́лы. | 她从学校来了（走来的）。 |
| Он **пришёл из** теа́тра. | 他从剧院来了（走来的）。 |
| Он **пришёл из** музе́я. | 他从博物馆来了。 |

> [!important] ★★ куда́ / где / отку́да 三件套（本课最重要的表）
> **课本 p198 的表**：
> | | **КУДА́?** | **ГДЕ?** | **ОТКУ́ДА?** |
> |---|---|---|---|
> | 动词 | ходи́л, е́здил | был | пришёл, прие́хал |
> | 前置词 | **в / на** | **в / на** | **из / с** |
> | 格 | **№4** | **№6** | **№2** |
> | 例 | ходи́л **в** магази́н | был **в** магази́не | пришёл **из** магази́на |
> | 例 | е́здил **на** рабо́ту | был **на** рабо́те | прие́хал **с** рабо́ты |
> **关键对应**：
> **в ↔ из**（在……里面 ↔ 从……里面）
> **на ↔ с**（在……上/活动 ↔ 从那上面/活动下来）
> `в магази́н` → `в магази́не` → `из магази́на`
> `на рабо́ту` → `на рабо́те` → `с рабо́ты`
> **注意 с 的搭配**：`на рабо́те` 的对应是 **с рабо́ты**（不是 «из рабо́ты»）！
> **这是最容易错的地方**：**必须记住哪个词用 в/из，哪个词用 на/с。**
> Урок 4 你已经背过 в / на 的分工，现在**记住它们的反向前置词**：
> **в → из**、**на → с**。

**常见场所的三格对照**：

| 场所 | куда́（№4） | где（№6） | отку́да（№2） |
|---|---|---|---|
| магази́н | в магази́н | в магази́не | из магази́на |
| университе́т | в университе́т | в университе́те | из университе́та |
| рабо́та | на рабо́ту | на рабо́те | **с рабо́ты** |
| по́чта | на по́чту | на по́чте | **с по́чты** |
| стадио́н | на стадио́н | на стадио́не | **со стадио́на** |
| рестора́н | в рестора́н | в рестора́не | из рестора́на |
| кафе́ | в кафе́ | в кафе́ | из кафе́ |
| му́зей | в музе́й | в музе́е | из музе́я |
| зоопа́рк | в зоопа́рк | в зоопа́рке | из зоопа́рка |
| библиоте́ка | в библиоте́ку | в библиоте́ке | из библиоте́ки |
| шко́ла | в шко́лу | в шко́ле | из шко́лы |
| теа́тр | в теа́тр | в теа́тре | из теа́тра |
| Сиби́рь | в Сиби́рь | в Сиби́ри | из Сиби́ри |
| дом | домо́й | до́ма | **из до́ма** |

> [!warning] ★★ с 的两种形式：с / со
> `на стадио́не` → **со стадио́на**（不是 «с стадио́на»）
> **原因**：с 后面遇到**两个辅音开头**的词（ст-、сн-、шк-…），要加 **о** 便于发音。
> 同类：**со стола́**、**со шко́лы**、**со сцены**
> 而 **с рабо́ты**（р 是一个辅音）、**с по́чты**（п 是一个辅音）—— 直接用 с。
> **规律**：**с + 辅音丛 → со**。这条和 Урок 4 学的 **в / во**、**о / об / обо** 是同一类现象。

### 4. 几点钟？Ско́лько вре́мени?

```
— Ни́на Ива́новна, скажи́те, пожа́луйста, ско́лько вре́мени сейча́с в Росси́и?
— Сейча́с в Москве́ 19 часо́в.
— А во Владивосто́ке уже́ 2 часа́ но́чи.
— В Барсело́не сейча́с 17 часо́в.
— У нас то́же 17 часо́в.
— А у нас о́чень по́здно. Уже́ час но́чи.
```

**两种问法**：

| 俄语 | 中文 |
|---|---|
| **Ско́лько вре́мени?** | 几点了？ |
| **Кото́рый час?** | 几点了？（同义） |

**回答公式**：**数字 + час / часа́ / часо́в**

| 数量 | 形式 | 例 |
|---|---|---|
| **1** | **час** | 1 час |
| **2, 3, 4** | **часа́** | 2 часа́, 3 часа́, 4 часа́ |
| **5–12** | **часо́в** | 5 часо́в, 19 часо́в |

> [!important] ★★ 1 / 2-4 / 5+ 的三分法（本课核心规律）
> 俄语的**名词在数字后面要变形**，分三组：
> | 尾数 | 形式 | 例 |
> |---|---|---|
> | **1**（除 11） | **单数第一格** | 1 **час**, 1 **рубль**, 1 **кни́га** |
> | **2, 3, 4**（除 12-14） | **单数第二格** | 2 **часа́**, 3 **рубля́**, 2 **кни́ги** |
> | **0, 5–20** | **复数第二格** | 5 **часо́в**, 5 **рубле́й**, 5 **книг** |
> **注意「特殊尾数」**：
> **11 小时 → 11 часо́в**（不是 «11 час»！）
> **12, 13, 14 → 也按复数第二格**：12 часо́в、14 рубле́й
> **21 → 21 час**（按尾数 1）
> **22 → 22 часа́**（按尾数 2）
> **课本的对照**：
> `1 (оди́н) рубль. 2, 3, 4 рубля́.` ／ `1 (одна́) кни́га. 2 (две) кни́ги.`
> `1 (одно́) письмо́. 2, (два) письма́. 3, 4 письма́.`
> **注意 «письмо́ → письма́»** 也是第二格（中性 -о → -а）。

**分钟**：同样三分法

| 数量 | 形式 |
|---|---|
| 1 | **мину́та** |
| 2, 3, 4 | **мину́ты** |
| 5+ | **мину́т** |

> [!tip] 「1 点 1 分」怎么说
> `1 час 1 мину́та`
> `2, 3, 4 часа́ 2 (две), 3, 4 мину́ты`
> `5... часо́в 5... мину́т`
> **注意「2 分钟」用 две**（不是 два），因为 мину́та 是阴性。

**「在几点」用 в + 第四格**：

| 俄语 | 中文 |
|---|---|
| **в час** | 在 1 点 |
| **в 2, 3, 4 часа́** | 在 2、3、4 点 |
| **в 5, 6, 7... часо́в** | 在 5、6、7 点 |

> [!important] ★ 注意 «в час» 和 «час» 的区别
> `Я встаю́ **в 7 часо́в**.`（我在 7 点起床 —— «в» 表示时间点）
> `Я сплю **7 часо́в**.`（我睡 7 小时 —— 没有 «в»，表示时长）
> **这一个前置词的差别极大**：
> **в + 时间 = 几点（时刻）**；**无前置词 = 多久（时长）**
> `Я рабо́таю **в 9 часо́в**.` 我 9 点上班。
> `Я рабо́таю **9 часо́в**.` 我工作 9 小时。

### 5. у́тром / днём / ве́чером / но́чью（复习 + 本课扩展）

课本给了两组形式：

| 副词（什么时候） | 名词第二格（几点……的） | 中文 |
|---|---|---|
| **у́тром** | **утра́** | 早上 / 凌晨 |
| **днём** | **дня** | 白天 / 下午 |
| **ве́чером** | **ве́чера** | 晚上 |
| **но́чью** | **но́чи** | 夜里 |

**用法对比**：

| 说法 | 例 | 中文 |
|---|---|---|
| 副词形式 | **У́тром** в 10 часо́в. | 早上 10 点。 |
| 名词第二格 | В 10 часо́в **утра́**. | 早上 10 点。（10 点「属于」早晨） |
| 副词形式 | **Ве́чером** в 8 часо́в. | 晚上 8 点。 |
| 名词第二格 | В 8 часо́в **ве́чера**. | 晚上 8 点。 |

> [!important] ★★ 「в + 数字 + 第二格」的用法
> `В 10 часо́в **утра́**.` ＝ `У́тром в 10 часо́в.`（早上 10 点）
> `В 11 часо́в **ве́чера**.`（晚上 11 点）
> `В 2 часа́ **но́чи**.`（凌晨 2 点）
> **规律**：**в + 钟点 + 时段名词的第二格**，用来**精确指明是哪个时段的那一点**。
> `в 10 часо́в` 单独说可能是早上也可能是晚上 → 加上 **утра́ / ве́чера / дня / но́чи** 就明确了。
> **注意**：第一组（у́тром / днём / ве́чером / но́чью）是**第五格变来的副词**（Урок 8 学过第五格），
> 第二组（утра́ / дня / ве́чера / но́чи）是**第二格**。
> **同一批词，两种格，两种用场** —— 这是本课最精妙的一处。

### 6. 多少钱？Ско́лько сто́ит?

```
— Ско́лько сто́ит капучи́но?
— Капучи́но сто́ит 240 рубле́й.
— А ско́лько сто́ят две бу́лочки?
— Две бу́лочки сто́ят 130 рубле́й.
```

**公式**：

| 单数（一个东西） | 复数（多个东西） |
|---|---|
| **Ско́лько сто́ит + 第一格？** | **Ско́лько сто́ят + 第一格？** |
| Капучи́но сто́ит 240 рубле́й. | Две бу́лочки сто́ят 130 рубле́й. |

> [!important] ★ сто́ит 还是 сто́ят
> **сто́ит** 用于**单数主语**：`Капучи́но **сто́ит** 240 рубле́й.`
> **сто́ят** 用于**复数主语**：`Две бу́лочки **сто́ят** 130 рубле́й.`
> **注意**：价格里的 рубль 用**第二格**（рубле́й / рубля́）—— 这是第 4 节点讲的数字规则。

**货币：卢布的三分法**：

| 数量 | 形式 | 例 |
|---|---|---|
| 1 | **рубль** | 1 рубль |
| 2, 3, 4 | **рубля́** | 2, 3, 4 рубля́ |
| 5+ | **рубле́й** | 50 рубле́й, 100 рубле́й |

**大数字**：

| 俄语 | 中文 |
|---|---|
| **1000 — одна́ ты́сяча рубле́й** | 1000 卢布 |
| **2000 — две ты́сячи рубле́й** | 2000 卢布 |
| **3000 — три ты́сячи рубле́й** | 3000 卢布 |
| **4000 — четы́ре ты́сячи рубле́й** | 4000 卢布 |
| **5000 — пять ты́сяч рубле́й** | 5000 卢布 |
| **6000 — шесть ты́сяч рубле́й** | 6000 卢布 |

> [!important] ★ ты́сяча 也遵守三分法
> **1 → одна́ ты́сяча**（单数第一格）
> **2, 3, 4 → две / три / четы́ре ты́сячи**（单数第二格！注意 -и）
> **5+ → пять / шесть ты́сяч**（复数第二格）
> **注意 «две ты́сячи»**：ты́сяча 是阴性，所以用 **две**（不是 два），
> 而且第二格是 **ты́сячи**（-а → -и，因为 ч 后不写 ы）。
> **这又是那条拼写规则：ч 后写 и。**

> [!success] ⭐ 俄罗斯纸币上的名人（课本 p194–p195——文化知识）
> 课本用纸币讲俄罗斯历史，很有意思：
> | 面额 | 图案 |
> |---|---|
> | **50 рубле́й** | **Санкт-Петербу́рг**（彼得堡） |
> | **100 рубле́й** | **Большо́й теа́тр**（大剧院，在莫斯科） |
> | **200 рубле́й** | **Севасто́поль** + 古城 **Херсоне́с** |
> | **500 рубле́й** | **Пётр Пе́рвый**（彼得大帝）+ **Арха́нгельск** + **Солове́цкий монасты́рь** |
> | **1000 рубле́й** | **Яросла́в Мудрый**（智者雅罗斯拉夫）+ **Яросла́вль** + **Яросла́вский кремль** |

### 7. 几号？Како́е сего́дня число́?

```
— Како́е сего́дня число́?
— Сего́дня пе́рвое января́.
— Сего́дня девя́тое ма́рта.
```

**公式**：**Како́е сего́дня число́? — Сего́дня + 序数词（中性）+ 月份（第二格）**

| 俄语 | 中文 |
|---|---|
| **пе́рвое января́** | 1 月 1 日 |
| **второ́е февраля́** | 2 月 2 日 |
| **девя́тое ма́рта** | 3 月 9 日 |
| **два́дцать пе́рвое июля́** | 7 月 21 日 |

> [!important] ★★ 日期里两个词都变
> **① 序数词用中性**（因为 число́ 是中性）：
> `пе́рв**ое** января́`（不是 «пе́рвый»）
> `девя́т**ое** ма́рта`
> **② 月份用第二格**（表示「几月的」）：
> `января́`（不是 «янва́рь»）、`февраля́`、`ма́рта`、`апре́ля`、`ма́я`、`ию́ня`、
> `ию́ля`、`а́вгуста`、`сентября́`、`октября́`、`ноября́`、`декабря́`
> **这就是本课最重要的「所属」关系**：日期 = 「**一月的**第一个（天）」。

**序数词 11–30**：

| 数字 | 序数词 | 中文 |
|---|---|---|
| 11 | **оди́ннадцатый** | 第十一 |
| 12 | **двена́дцатый** | 第十二 |
| 13 | **трина́дцатый** | 第十三 |
| 14 | **четы́рнадцатый** | 第十四 |
| 15 | **пятна́дцатый** | 第十五 |
| 16 | **шестна́дцатый** | 第十六 |
| 17 | **семна́дцатый** | 第十七 |
| 18 | **восемна́дцатый** | 第十八 |
| 19 | **девятна́дцатый** | 第十九 |
| 20 | **двадца́тый** | 第二十 |
| 21 | **два́дцать пе́рвый** | 第二十一 |
| 22 | **два́дцать второ́й** | 第二十二 |
| 23 | **два́дцать тре́тий** | 第二十三 |
| 30 | **тридца́тый** | 第三十 |

> [!tip] 11–19 的构词规律
> **-надцать** = 「在十之上」（古斯拉夫语的 «на десять»「在十上面」）
> один + надцать → **оди́ннадцатый**
> две + надцать → **двена́дцатый**
> три + надцать → **трина́дцатый**
> **注意 11-19 的序数词里都保留 -надцат-**，而 20 是 **двадца́тый**（没有 над-）。
> **20 和 30 的构词不同**：два́дцать → двадца́тый、три́дцать → тридца́тый。

**「几号」的写法**：

| 写法 | 读法 |
|---|---|
| **10.10** | деся́тое октября́ |
| **02.04** | второ́е апре́ля |
| **01.01** | пе́рвое января́ |
| **14.08** | четы́рнадцатое а́вгуста |
| **30.12** | тридца́тое декабря́ |

> [!warning] ★ 俄语日期是「日.月.年」
> **俄语和中文一样**：**日在前，月在后**（10.10 = 10 月 10 日）
> **但和美式英语相反**（美式 10.10 = 10 月 10 日，但 04.02 美式是 4 月 2 日、俄式是 2 月 4 日）。
> **注意 01.01 和 10.10 这类对称日期**不容易混，但 **02.04 和 04.02** 完全不同。
> 用俄语写日期时，**牢记日月顺序**。

### 8. 运动动词 + 前缀（本课的新语法）

**课本用「瓦夏去商店」的例子讲清了前缀系统**：

```
Ва́ся пошёл в магази́н, шёл в магази́н 10 мину́т,
пришёл в магази́н, был в магази́не полчаса́,
пошёл домо́й из магази́на, шёл домо́й 10 мину́т,
пришёл домо́й. Он сейча́с до́ма и пи́шет карти́ну.
```

| 动词 | 意思 | 对应 |
|---|---|---|
| **идти́** | 走（过程） | шёл в магази́н 10 мину́т 走了 10 分钟 |
| **пойти́** | 出发（起点） | **пошёл** в магази́н 出发去商店 |
| **прийти́** | 到达（终点） | **пришёл** в магази́н 走到了商店 |

**长途版（去喀山）**：

```
Ва́ся пое́хал в Каза́нь, е́хал в Каза́нь 12 часо́в,
прие́хал в Каза́нь, был в Каза́ни три дня на вы́ставке,
пое́хал в Москву́ из Каза́ни, е́хал в Москву́ 12 часо́в,
прие́хал в Москву́. Он сейча́с в Москве́.
```

| 动词 | 意思 | 对应 |
|---|---|---|
| **е́хать** | 乘车（过程） | е́хал 12 часо́в 开了 12 小时 |
| **пое́хать** | 出发 | **пое́хал** в Каза́нь 出发去喀山 |
| **прие́хать** | 到达 | **прие́хал** в Каза́нь 到了喀山 |

> [!important] ★★ по- 出发，при- 到达（一对前缀）
> **по-** = **开始动作**（出发）
> **при-** = **动作完成、到达终点**
> ```
> пошёл в магази́н → шёл 10 мину́т → пришёл в магази́н
> 出发去商店        → 走了 10 分钟  → 到了商店
> ```
> **这是本课最有画面感的一组**：
> 一个动作被拆成「**出发—过程—到达**」三段，
> 分别用 **по- + идти́**、**идти́**、**при- + идти́** 表示。
> **课本的四个核心动词**：
> | 不定式 | 过去时 | 意思 |
> |---|---|---|
> | **идти́** | шёл / шла / шли | 走（过程） |
> | **пойти́** | пошёл / пошла́ / пошли́ | 出发走 |
> | **прийти́** | пришёл / пришла́ / пришли́ | 走到 |
> | **е́хать** | е́хал / е́хала / е́хали | 乘车（过程） |
> | **пое́хать** | пое́хал / пое́хала / пое́хали | 出发乘车 |
> | **прие́хать** | прие́хал / прие́хала / прие́хали | 乘车到达 |

> [!note] 前缀运动动词的方向
> **по-** → 出发（开始）
> **при-** → 到达（来）
> **у-** → 离开（去）
> **в-**（во-）→ 进入
> **вы-** → 出去
> **до-** → 到达（勉强到达）
> **пере-** → 穿过、越过
> 课本的附录用图片给出这张表，本课只需掌握 **по-** 和 **при-** 这一对。

### 9. 一昼夜的动词：встава́ть / ложи́ться / убира́ть

```
Я обычно встаю́ в 7 часо́в и ложу́сь спать в 23 часа́.
```

**встава́ть 的变位**：

| я | ты | он/она́ | мы | вы | они́ |
|---|---|---|---|---|---|
| встаю́ | встаёшь | встаёт | встаём | встаёте | встаю́т |

**ложи́ться 的变位**：

| я | ты | он/она́ | мы | вы | они́ |
|---|---|---|---|---|---|
| ложу́сь | ложи́шься | ложи́тся | ложи́мся | ложи́тесь | ложа́тся |

**убира́ть 的变位**：

| я | ты | он/она́ | мы | вы | они́ |
|---|---|---|---|---|---|
| убира́ю | убира́ешь | убира́ет | убира́ем | убира́ете | убира́ют |

> [!important] ★ ложи́ться 的两个难点
> **① 带 -ся**：所有形式后面都有 **-ся / -сь**（元音后是 -сь，辅音后是 -ся）
> `ложу́**сь**`、`ложи́шь**ся**`、`ложи́т**ся**`
> **② 词尾音变**：**г → ж**（ложи́ть → **лож**у́сь），和 Урок 3 的 «я ло**ж**у́сь» 同一个音变。
> **③ «ложи́ться спать» 是固定搭配**：「躺下睡觉」
> `Я ложу́сь **спать** в 11 ве́чера.` 我晚上 11 点上床睡觉。

> [!success] ⭐ 课本的「一生有多长」数据（文化 + 语言）
> 课本用信息图表说**人一生中各花多少年**，正好练 «сколько лет»：
> | 活动 | 俄语 | 时间 |
> |---|---|---|
> | 我们工作 | мы рабо́таем | **11 лет** |
> | 我们休息 | мы отдыха́ем | 9 лет |
> | 我们睡觉 | мы спим | **2, 3, 4 го́да**（约 25 лет！） |
> | 我们学习 | мы у́чимся | 3 го́да |
> | 我们做家务 | мы убира́ем | 4 го́да |
> | 我们看足球 | мы смо́трим футбо́л | 8 ме́сяцев |
> | 我们看电视 | мы смо́трим телеви́зор | 9 лет |
> | 我们上网 | мы сиди́м в Интерне́те | 9 лет |
> **注意 «лет» 和 «го́да» 的区别**——就是第 4 节的三分法：
> `11 лет`（尾数 1 但 11 用 лет）、`2, 3, 4 го́да`、`5+ лет`
> **这个图表本身也是很好的口语素材**：你能用它说「我一生中睡了多少年」。

### 1. ★★ 第二格的完整变化表

| 词性 | 第一格结尾 | 第二格结尾 | 例 |
|---|---|---|---|
| **阳性** | 硬辅音 | **-а** | брат → бра́та；стол → стола́ |
| **阳性** | -й | **-я** | Андре́й → Андре́я；музе́й → музе́я |
| **阳性** | -ь | **-я** | слова́рь → слова́ря；преподава́тель → преподава́теля |
| **阴性** | -а | **-ы**（г/к/х 后 -и） | А́нна → А́нны；ша́пка → ша́пки |
| **阴性** | -я | **-и** | Та́ня → Та́ни；семья́ → семьи́ |
| **阴性** | -ь | **-и** | тетра́дь → тетра́ди；площа́дь → пло́щади |
| **中性** | -о | **-а** | письмо́ → письма́；окно́ → окна́ |
| **中性** | -е | **-я** | мо́ре → мо́ря；зда́ние → зда́ния |
| **中性** | -мя | **-мени** | вре́мя → вре́мени；и́мя → и́мени |

> [!important] ★★ 中性 -о → -а：和阴性 -а → -ы 别混
> `письмо́ → письма́`（中性，第二格 -а）
> `ма́ма → ма́мы`（阴性，第二格 -ы）
> **两个都是 -а 结尾的词，第二格完全不同**：
> **中性 -о 变成 -а**；**阴性 -а 变成 -ы**。
> **判断方法**：先看第一格是 **-о** 还是 **-а**。
> `окно́` 是中性 → `окна́`
> `шко́ла` 是阴性 → `шко́лы`

### 2. ★★ 第二格的四大用途（本课核心）

| 用途 | 结构 | 例 |
|---|---|---|
| **① 否定不存在** | нет + 第二格 | У меня́ **нет бра́та**. |
| **② 所属** | 名词 + 所有者第二格 | Э́то кни́га **бра́та**. |
| **③ 来源** | из / с / от + 第二格 | Я **из Кита́я**. |
| **④ 数量** | 2-4 单数第二格；5+ 复数第二格 | два **часа́**；пять **часо́в** |

> [!success] ★★ 这四个用途把本课的全部语法串起来了
> 第二格在俄语里的角色是**「不完整的、附属的、来源的」**：
> **否定**（没有→缺失）→ `нет + №2`
> **所属**（谁的→附属）→ `名词 + №2`
> **来源**（从哪来→起点）→ `из/с/от + №2`
> **数量**（几个→部分）→ `2-4 / 5+ + №2`
> **中文的对应**：「**没**有」「**的**」「**从**」「**几**个」——中文也用了四个不同的词，
> 俄语则统一用**一个格**。
> **记住这四大用途，第二格就通了。**

### 3. у кого́ / кому́ / кого́ —— 别混了

| 问题 | 格 | 例 |
|---|---|---|
| **У кого́?** 谁有？ | 第二格 + у | **У меня́** есть слова́рь. |
| **Кому́?** 给谁？（第三格） | 第三格 | Я звоню́ **бра́ту**. |
| **Кого́?** 看见谁？（第四格） | 第四格 | Я ви́жу **бра́та**. |

> [!warning] ★ 第二格和第四格的「动物名词」同形（阳性）
> **阳性动物名词**（人和动物）的**第四格 = 第二格**：
> `Я ви́жу **бра́та**.`（我看**兄弟** —— 第四格，但形式和第二格 бра́та 一样）
> `У меня́ нет **бра́та**.`（我没有**兄弟** —— 第二格）
> **同一个形式，不同的格**——靠**动词**区分：
> **нет** 后面是第二格；**ви́жу / зна́ю** 后面是第四格。
> `Я зна́ю **э́того студе́нта**.`（我认识这个学生，第四格）
> `У **э́того студе́нта** есть кни́га.`（这个学生有书，第二格）
> **非动物名词**的第四格 = 第一格：`Я ви́жу **дом**.`（≠ 第二格 до́ма）

### 4. 数字 + 名词的三分法（完整表）

| 尾数 | 格 | 阳性 | 阴性 | 中性 |
|---|---|---|---|---|
| **1** | 第一格单数 | 1 час | 1 кни́га | 1 письмо́ |
| **2, 3, 4** | 第二格单数 | 2 часа́ | 2 кни́ги | 2 письма́ |
| **5–20** | 第二格复数 | 5 часо́в | 5 книг | 5 пи́сем |
| **11** | 第二格复数 | 11 часо́в | 11 книг | 11 пи́сем |
| **12–14** | 第二格复数 | 12 часо́в | 12 книг | 12 пи́сем |
| **21** | 第一格单数 | 21 час | 21 кни́га | 21 письмо́ |
| **22** | 第二格单数 | 22 часа́ | 22 кни́ги | 22 письма́ |

> [!important] ★★ 数词后面名词的格——本课最实用的一条
> **口诀**：
> **1 → 一（单数第一格）**
> **2, 3, 4 → 二（单数第二格）**
> **5 以上 → 多（复数第二格）**
> **特殊：11–14 一律用复数第二格**（即使尾数是 1、2、3、4）
> `11 часо́в`（不是 «11 час»）
> `12 часо́в`
> `14 рубле́й`（不是 «14 рубля́»）
> **简单记**：**11 到 14 是「例外区」，全部按 5+ 处理。**
> **注意 «два / две»**：阳性中性用 **два**，阴性用 **две**
> `два часа́`（час 阳性）／`две мину́ты`（мину́та 阴性）／`две ты́сячи`（ты́сяча 阴性）

### 5. 前置词 в / на / из / с 的配对（本课复习重点）

| | 起点（отку́да） | 过程（куда́） | 终点所在（где） |
|---|---|---|---|
| **в / из** | **из** + №2 | **в** + №4 | **в** + №6 |
| **на / с** | **с** + №2 | **на** + №4 | **на** + №6 |

**课本的表格（要填的练习）**：

| 场所 | куда́（№4） | где（№6） | отку́да（№2） |
|---|---|---|---|
| **рестора́н** | в рестора́н | в рестора́не | из рестора́на |
| **музе́й** | в музе́й | в музе́е | из музе́я |
| **кафе́** | в кафе́ | в кафе́ | из кафе́ |
| **зоопа́рк** | в зоопа́рк | в зоопа́рке | из зоопа́рка |
| **Сиби́рь** | в Сиби́рь | в Сиби́ри | из Сиби́ри |
| **по́чта** | на по́чту | на по́чте | **с по́чты** |
| **стадио́н** | на стадио́н | на стадио́не | **со стадио́на** |

> [!warning] ★★ в / из 和 на / с 必须配对，不能混
> ❌ 错：`пришёл **из** рабо́ты`（рабо́та 用 на，所以要用 с）
> ✅ 对：`пришёл **с** рабо́ты`
> ❌ 错：`пришёл **с** магази́на`（магази́н 用 в）
> ✅ 对：`пришёл **из** магази́на`
> **记法**：**背 Урок 4 那张 в/на 表时，就一起记它的反向前置词**：
> **в 的对面是 из**；**на 的对面是 с**。

### 6. 运动动词前缀的完整对照

| 前缀 | 意思 | идти́ 系列 | е́хать 系列 |
|---|---|---|---|
| **（无）** | 过程 | идти́（шёл） | е́хать（е́хал） |
| **по-** | 出发 | пойти́（пошёл） | пое́хать（пое́хал） |
| **при-** | 到达 | прийти́（пришёл） | прие́хать（прие́хал） |
| **у-** | 离开 | уйти́（ушёл） | уе́хать（уе́хал） |
| **в- / во-** | 进入 | войти́（вошёл） | въе́хать |
| **вы-** | 出去 | вы́йти（вы́шел） | вы́ехать |
| **до-** | 抵达 | дойти́（дошёл） | дое́хать |
| **пере-** | 穿过 | перейти́（перешёл） | перее́хать |

> [!important] ★ по- 和 при- 是本课必须掌握的一对
> **пошёл → пришёл**：出发 → 到达
> `Ва́ся **пошёл** в магази́н.` 瓦夏出发去商店了。
> `Ва́ся **пришёл** в магази́н.` 瓦夏到了商店。
> **注意 пришёл 的形式**：**при- + шёл**，前面加了 при-。
> **阴性 пришла́**（重音在末尾）、**复数 пришли́**（重音在末尾）
> 课本的例子：`Она́ **пришла́** из шко́лы.`／`Он **пришёл** из теа́тра.`
> **这两个词是本课最实用的新动词。**

### 7. убира́ть（打扫）—— + что 第四格

| 俄语 | 中文 |
|---|---|
| **убира́ть кварти́ру** | 打扫房间 |
| **убира́ть ко́мнату** | 打扫屋子 |
| **убира́ть дом** | 打扫房子 |

> [!tip] убира́ть + 第四格（直接宾语）
> `Я убира́ю **кварти́ру**.` 我打扫房间。
> **阴性 -а → -у**（第四格）：кварти́ра → кварти́ру、ко́мната → ко́мнату
> **阳性不变**：дом → дом
> **规律同 Урок 7**（куда́ 的第四格）。

## 五、要记的特例

| 特例 | 说明 |
|---|---|
| **мать → у ма́тери** | ★★ 特殊第二格 |
| **дочь → у до́чери** | ★★ 特殊第二格 |
| **оте́ц → у отца́** | ★ 去掉 е |
| **де́ньги → нет де́нег** | ★ 复数第二格 |

| **и́мя → и́мени** | 同类 |
| **подру́га → подру́ги** | ★ г 后写 и |
| **ша́пка → ша́пки** | ★ к 后写 и |
| **у него́ / у неё / у них** | ★ 加 н |
| **его́ / её / их**（物主） | ★ 不加 н |
| **2, 3, 4 + 单数第二格** | ★★ часа́, рубля́, кни́ги |
| **5+ + 复数第二格** | ★★ часо́в, рубле́й, книг |
| **11–14 用复数第二格** | ★★ 11 часо́в |
| **ты́сяча → две ты́сячи** | ★ ч 后写 и |
| **в + 钟点 = 时刻** | в 7 часо́в（7 点） |
| **无前置词 = 时长** | 7 часо́в（7 小时） |
| **утра́ / дня / ве́чера / но́чи** | ★ 第二格，配 «в … часо́в» |
| **у́тром / днём / ве́чером / но́чью** | 副词（第五格来） |
| **из ↔ в**；**с ↔ на** | ★★ 必须配对 |
| **со стадио́на / с рабо́ты** | ★ со 用于辅音丛前 |
| **прийти́ → пришёл / пришла́** | ★ 阴性重音移后 |
| **ложи́ться → ложу́сь** | ★ г → ж |
| **Дата: пе́рвое января́** | ★ 序数词中性 + 月份第二格 |
| **девя́тое ма́рта** | 3 月 9 日 |
| **Како́е сего́дня число́?** | 今天几号 |
| **Ско́лько сто́ит / сто́ят** | ★★ 单数 / 复数 |

> [!warning] ★★ 四个最常错的地方
> **① есть 用第一格，нет 用第二格**
> ❌ `У меня́ нет брат.` ✅ `У меня́ нет **бра́та**.`
> **② в/из 与 на/с 必须配对**
> ❌ `из рабо́ты` ✅ `**с** рабо́ты`
> **③ 11–14 用复数第二格**
> ❌ `11 час` ✅ `11 **часо́в**`
> **④ «в 7 часо́в» 和 «7 часо́в»**
> `Я встаю́ **в** 7 часо́в.`（7 点起床）
> `Я сплю 7 часо́в.`（睡 7 小时）

### 6.2 易混辨析

**① есть vs нет**（本课第一辨析）

| | 格 | 例 |
|---|---|---|
| **есть** | 第一格 | У меня́ есть **брат**. |
| **нет** | **第二格** | У меня́ нет **бра́та**. |

**② у него́ vs его́**

| 形式 | 用途 | 例 |
|---|---|---|
| **у него́** | 「他有」（前置词 у + 第二格，**加 н**） | **У него́** есть слова́рь. |
| **его́** | 「他的」（物主代词，**不加 н**） | Э́то **его́** слова́рь. |

**③ из vs с**（本课第二辨析）

| 前置词 | 配对 | 例 |
|---|---|---|
| **из** | 配 **в** | **из** магази́на（в магази́н） |
| **с** | 配 **на** | **с** рабо́ты（на рабо́ту） |

❌ 错：`из рабо́ты`、`с магази́на`
✅ 对：`**с** рабо́ты`、`**из** магази́на`

**④ сто́ит vs сто́ят**

| 主语 | 动词 | 例 |
|---|---|---|
| 单数 | **сто́ит** | Капучи́но **сто́ит** 240 рубле́й. |
| 复数 | **сто́ят** | Две бу́лочки **сто́ят** 130 рубле́й. |

**⑤ в + 钟点 vs 单纯钟点**

| 说法 | 意思 |
|---|---|
| **в** 7 часо́в | 在 7 点（时刻） |
| 7 часо́в | 7 小时（时长） |
| **в** 10 часо́в **утра́** | 早上 10 点 |
| **в** 11 часо́в **ве́чера** | 晚上 11 点 |

**⑥ у́тром vs утра́**

| 形式 | 词性 | 例 |
|---|---|---|
| **у́тром** | 副词（第五格来） | **У́тром** я встаю́ ра́но. |
| **утра́** | 第二格名词 | В 7 часо́в **утра́**. |

| 学校 | в шко́лу | в шко́ле | из шко́лы |
| 家（回） | домо́й | до́ма | из до́ма |

> [!success] ⭐ 用「三格」讲清楚一件事
> 课本让你「详细讲今天去了哪儿、在哪儿」。模板：
> ```
> Сего́дня у́тром я пошёл(шла) в ______.
> Я был(а́) там ______ часо́в.
> Пото́м я пришёл(шла) из ______.
> Ве́чером я был(а́) на ______.
> ```
> **注意每一句的格**：
> **пошёл в** + №4（去哪儿）
> **был в / на** + №6（在哪儿）
> **пришёл из / с** + №2（从哪儿来）
> **同一件事的三个视角，三个格。**

> [!note] 两个「古典」俄语文化点
> **① Да́ча 与 са́мовар**：课本在 Урок 8 已讲过图拉（Ту́ла）。本课的纸币也讲了
> **Солове́цкий монасты́рь**（索洛维茨基修道院，在白海）和 **Яросла́вский кремль**（雅罗斯拉夫尔克里姆林宫）。
> **② «Како́е сего́дня число́?»** 这个问法里的 **число́** 是「（月中的）日、号」，
> 也可以问 **«Како́е сего́дня число́?»** 或更口语的 **«Како́й сего́дня день?»**
> 注意 **день неде́ли**（星期几）和 **число́**（几号）是两回事：
> `Како́й сего́дня день?` 今天星期几？（回答：понеде́льник）
> `Како́е сего́дня число́?` 今天几号？（回答：пе́рвое января́）

### 10. 读音辨析：第二格里最容易读错的四个词

第二格用得最多，而它偏偏带出几个「写出来是一个样、读出来另一个样」的高频词。
这几处课本不标读音，但你要是一路按字母读，别人会听成别的词。

#### ① `кого́` / `чего́` / `ничего́` → г 读 `[в]`

| 写法 | 读作 | 中文 |
|---|---|---|
| **кого́** | `[каво́]` | 谁（第二格） |
| **чего́** | `[чиво́]` | 什么（第二格） |
| **ничего́** | `[ничиво́]` | 什么也（不）；没关系 |
| **сего́дня** | `[сиво́дня]` | 今天 |

> ✅ `У кого́ есть соба́ка?` 谁有狗？（读 `[у каво́]`）
> ✅ `Чего́ у вас нет?` 您没有什么？（读 `[чиво́]`）
> ❌ 不要读成 «ко-го»（两个音分开）——**го 合成 [во]**。

#### ② `-ого` / `-его` 词尾同样读 `[ово]` / `[ево]`

第二格最常出现的词尾就是这两个，所以本课它特别多：

| 写法 | 读作 | 中文 |
|---|---|---|
| **ва́шего** | `[ва́шева]` | 您的（第二格） |
| **ру́сского** | `[ру́скава]` | 俄罗斯的（第二格） |
| **си́него** | `[си́нева]` | 蓝的（第二格） |

> **一句话**：凡是 `-ого` / `-его` 结尾，г 都读 [в]。
> 这条规律在 Урок 7 的读音辨析里已经讲过，这里再遇到就当复习。

#### ③ `-тся` / `-ться` → 读 `[ца]`

第二格的句子常用反身动词，所以这一类在你眼前出现得很频繁：

| 写法 | 读作 | 中文 |
|---|---|---|
| **называ́ется** | `[называ́еца]` | 叫作 |
| **нахо́дится** | `[нахо́дица]` | 位于 |
| **у́чится** | `[у́чица]` | 学习（他/她） |

#### ④ 数词里的软音：`пять` / `де́вять` / `де́сять`

> **-ть 词尾的 ь 只让 т 变软，读 `[т']`，不要读成一个独立的音**。

| 写法 | 读作 | 注意 |
|---|---|---|
| **пять** | `[п'ат']` | 5，不是 «пять-ть» |
| **де́вять** | `[д'э́в'ит']` | 9 |
| **де́сять** | `[д'э́с'ит']` | 10 |
| **ско́лько** | `[ско́лька]` | 多少（重音在 о́） |

> [!warning] 数量词后面接第二格，别把两个坑叠一起
> `пять` / `де́вять` / `де́сять` 后面的名词用**第二格复数**（Урок 9 核心规则）：
> ✅ `пять книг` 五本书　`де́сять рубле́й` 十卢布
> ❌ 不说 «пять кни́га»
> 读音坑 + 语法坑撞在一起时，先想语法，再读准词尾。

> [!tip] 为什么 `-го` 会读成 `[во]`
> 这是俄语里古老的音变：г 在弱化位置（非重读、词尾）摩擦性增强，听起来就是 [в]。
> 同一现象还出现在 **`его́` `[ево́]`**、**`сего́дня` `[сиво́дня]`**。
> 你不需要背音变理论，**记住 `-ого/-его`、`его́`、`сего́дня` 这三类就够用**。

#### ⑤ 数字 + 名词：第二格最大的实用场景（通用语法补充）

第二格用得最多的地方，其实是**数词后面的名词**。

> ⚠️ **来源说明**：Э У9 课本正文里没有专门的「数词+第二格」完整表
> （只有 `Како́е сего́дня число́?` p185 这类零散例句）。
> 下面这张表是**通用语法补充**，不是课本原文 —— 但它是第二格最核心的用法，
> 学第二格必须掌握，所以列在这里。

| 数词后的形式 | 名词用第几格 | 例 |
|---|---|---|
| **1**（оди́н / одна́ / одно́） | **第一格单数** | `оди́н дом`、`одна́ кни́га` |
| **2–4** | **第二格单数** | `два до́ма`、`три кни́ги` |
| **5–20** | **第二格复数** | `пять домо́в`、`шесть книг` |
| **21, 31, 41…** | 看末位 → 第一格单数 | `два́дцать оди́н дом` |
| **22–24** | 看末位 → 第二格单数 | `два́дцать два до́ма` |

> [!warning] ★★ 这条规则中文里完全没有
> 中文「五个房子」和「两个房子」都用「房子」，形式不变。
> 俄语必须：
> - `два до́ма`（2 → 第二格**单数** `до́ма`）
> - `пять домо́в`（5 → 第二格**复数** `домо́в`）
>
> **2–4 用单数第二格，5 以上用复数第二格** —— 这个分界线在 **4 和 5 之间**，
> 不在 1 和 2 之间。这是最容易记错的地方。

#### ⑥ 数词的读音陷阱：重音会跑

俄语数词的重音不规则，而且**会随格变化**：

| 数词 | 第一格 | 与名词连用时 |
|---|---|---|
| **два** | `[два]` | `два до́ма` `[два до́ма]` |
| **три** | `[три]` | `три до́ма` |
| **четы́ре** | `[чит'ы́ри]` | 重音在 ы́ |
| **пять** | `[п'ат']` | 重音固定 |
| **во́семь** | `[во́с'им']` | 重音在 во́ |
| **де́вять** | `[д'е́в'ит']` | 重音在 де́ |
| **со́рок** | `[со́рак]` | 重音在 со́，**不是 сорок** |
| **сто** | `[сто]` | 单音节 |

> [!tip] `со́рок` 是个特殊的词
> 40 说 `со́рок`，而 50 说 `пятьдеся́т`，90 说 `девяно́сто`。
> **40、90、100 的重音都在第一个音节上**，而且构词不规则
> （`со́рок` 来自古语「一捆四十张皮子」）。
> 这三个数词历史上就与众不同，所以不用找规律，单独记。

#### ⑦ 时间表达：几号（课本 p185 有）＋ 几点、多大年纪（通用补充）

第二格在时间表达里出现极多。课本 У9 直接出现的只有「几号」
（`Како́е сего́дня число́?` p185），其余为**通用语法补充**：

| 问法 | 结构 | 例 |
|---|---|---|
| **几点？** `Ско́лько вре́мени?` | `час` / `два часа́` / `пять часо́в` | 也是 2–4 单数、5+ 复数 |
| **几号？** `Како́е число́?` | **序数词第二格** | `пе́рвое ма́я`、`второ́го ма́я` |
| **多大？** `Ско́лько вам лет?` | `год` → `го́да` → `лет` | `два го́да`、`пять лет` |
| **在几点？** `В кото́ром часу́?` | **第六格** | `в два часа́` |

> [!important] ★ `год` 的特殊变化
> | 数 | 形式 | 例 |
> |---|---|---|
> | 1 | **год** | `оди́н год` |
> | 2–4 | **го́да** | `два го́да` |
> | 5–20 | **лет** | `пять лет` |
>
> ★ **`лет` 不是 `год` 的复数第二格**（那应该是 `годо́в`）！
> `лет` 来自古俄语 `лѣто`（年、夏），是**补充式**。
> `пять лет` 是「五年」，而 `пять годо́в` 在现代俄语里几乎不用。
>
> 但注意：`в … году́`（在某年，第六格）用的是 `год`，不是 `лет`。
> `в 2024 году́` ✅

#### ⑧ 为什么第二格这么「重」

> 统计上，**第二格是俄语使用频率最高的格**（约 30%）。
> 原因很简单：它承担了太多功能：

| 功能 | 例 |
|---|---|
| 所属（谁的） | `кни́га бра́та`（哥哥的书） |
| 否定（没有） | `нет вре́мени`（没时间） |
| 数量（多少） | `пять домо́в` |
| 日期（几号） | `пе́рвого ма́я` |
| 来源（从哪） | `из Москвы́`（从莫斯科） |
| 比较（比什么） | `бо́льше э́того`（比这个大） |

> [!tip] 一句话总结
> 你可以把第二格理解为俄语的「**万能后备格**」——
> 凡是「不明确属于前五个格」的关系，几乎都落到第二格。
> 所以**第二格没学透，后面每一课都会卡**。

### 11. 练习册强化：国家 → 国民 → 语言（一张表解决）

> **来源**：《Я пишу по-русски》（Элементарный уровень）第 9 课 ЗАДАНИЕ 4，
> 课本正文没有这张表，但它和本课「第二格/从哪来/说哪种语言」直接相关，
> 而且是**中国学习者最常用的一类词**，故补在此。

这张表一次给你四样东西：**国家名 → 男人 → 女人 → 一群人 → 说哪种语言**。
记住一行的四个形式，比分开记四个词省力得多。

| 国家 | 他（阳） | 她（阴） | 他们（复） | 说…语 |
|---|---|---|---|---|
| Росси́я 俄罗斯 | ру́сский | ру́сская | ру́сские | по-ру́сски |
| Украи́на 乌克兰 | украи́нец | украи́нка | украи́нцы | по-украи́нски |
| Кита́й 中国 | кита́ец | китая́нка | кита́йцы | по-кита́йски |
| Коре́я 韩国 | коре́ец | корея́нка | коре́йцы | по-коре́йски |
| Япо́ния 日本 | япо́нец | япо́нка | япо́нцы | по-япо́нски |
| Вьетна́м 越南 | вьетна́мец | вьетна́мка | вьетна́мцы | по-вьетна́мски |
| Аме́рика 美国 | америка́нец | америка́нка | америка́нцы | по-англи́йски ★ |
| Испа́ния 西班牙 | испа́нец | испа́нка | испа́нцы | по-испа́нски |
| Ита́лия 意大利 | италья́нец | италья́нка | италья́нцы | по-италья́нски |
| А́нглия 英国 | англича́нин | англича́нка | англича́не | по-англи́йски |
| Фра́нция 法国 | францу́з | францу́женка | францу́зы | по-францу́зски |
| Герма́ния 德国 | не́мец | не́мка | не́мцы | по-неме́цки |
| Ту́рция 土耳其 | ту́рок | турча́нка | ту́рки | по-туре́цки |

> [!important] ★★ 三个必须注意的不规则点
> **① 美国的语言不是 «по-американски»** —— 是 **по-англи́йски**（说英语）。
> 注意表格里 `Аме́рика` 和 `А́нглия` 的「说…语」两列是**同一个词**。
>
> **② 阳性名词的后缀决定复数**，三种模式：
> - **-ец → -цы**（кита́ец → кита́йцы、япо́нец → япо́нцы、америка́нец → америка́нцы）
> - **-анин → -ане**（англича́нин → англича́не、但单数阴性是 англича́нка）
> - **辅音结尾 → 加 -ы/-и**（францу́з → францу́зы、не́мец → не́мцы、ту́рок → ту́рки）
>
> **③ 阴性形式要单独记**，不能靠规则推：
> `францу́з → францу́женка`（不是 «францу́зка»）、`ту́рок → турча́нка`、
> `кита́ец → китая́нка`（不是 «кита́йка»）。

> [!warning] 「俄国人」用 ру́сский，不是 «росси́йский»
> | 词 | 含义 | 用法 |
> |---|---|---|
> | **ру́сский** | 俄罗斯族的、俄语的 | `Он ру́сский.` 他是俄罗斯人。`по-ру́сски` 用俄语 |
> | **росси́йский** | 俄罗斯**国家的**（国籍/国属） | `росси́йский флаг` 俄罗斯国旗、`росси́йский университе́т` |
> **说「我是俄罗斯人」用 `Я ру́сский`**，不用 «Я росси́йский»。
> `росси́йский` 只能修饰事物/机构，不能指人。

#### 怎么用这张表造句（对应本课语法）

**① 说「他是哪国人」**（第一格）：
> `Он кита́ец.` 他是中国人。 / `Она́ китая́нка.` 她是中国人。
> `Они́ кита́йцы.` 他们是中国人。

**② 说「住在哪」**（第六格，本课已学）：
> `Он живёт в Кита́е.` 他住在中国。
> `Она́ живёт в Росси́и.` 她住在俄罗斯。（`-ия → -ии`）

**③ 说「从哪来」**（第二格，本课核心）：
> `Я из Кита́я.` 我来自中国。
> `Он и́з Япо́нии.` 他来自日本。（`-ия → -ии`）

**④ 说「会说什么语言」**（本课已学 `говори́ть по-…`）：
> `Я говорю́ по-кита́йски и немно́го по-ру́сски.`
> 我说中文，也会一点俄语。

> [!tip] 「母语」怎么说
> **родно́й язы́к**（母语）—— 练习册原句：
> `Их родно́й язы́к ру́сский.` 他们的母语是俄语。
> `Они́ хорошо́ говоря́т по-ру́сски, потому́ что э́то их родно́й язы́к.`
> 他们俄语说得好，因为这是他们的母语。
> ├ 注意 `родно́й` 是形容词，要跟名词一致：`родно́й язы́к` / `родна́я страна́`（祖国）。

> [!note] 练习册原题（可以自己练）
> **ЗАДАНИЕ 4 6)**：给一组人名+国家，写出「他们住哪、他们是什么人、母语是什么」。
>
> 例：`О́лег, О́ля, Росси́я` →
> `О́лег и О́ля живу́т в Росси́и. О́лег — ру́сский, О́ля — ру́сская.`
> `Их родно́й язы́к ру́сский. Они́ хорошо́ говоря́т по-ру́сски.`
>
> 你可以照这个模式练：
> `Лю Кун, Ван Лин, Кита́й` → ?
> `Ким И Сан, Ми Нам, Коре́я` → ?
> `Та́ро, Ю́ка, Япо́ния` → ?

12. 「2 小时」和「5 小时」分别怎么说？「11 小时」呢？
13. 「在 7 点起床」和「睡 7 小时」分别怎么说？差在哪里？
14. 「早上 7 点」有哪两种说法？
15. 「2000 卢布」怎么说？为什么用 `две`？为什么 `ты́сячи` 是 `-и`？
16. `сто́ит` 和 `сто́ят` 怎么区分？
17. 「今天 1 月 1 日」怎么说？为什么序数词用中性、月份用第二格？
18. `пошёл` 和 `пришёл` 有什么区别？
19. `ложи́ться` 的 я 形式是什么？为什么？
20. 「在莫斯科附近」「离东京不远」「在海边」分别怎么说？

> [!success]- 答案要点
> 1. **есть + 第一格**（有什么）；**нет + 第二格**（没有什么）。
> 2. `У меня́ **есть брат**.`（第一格）／`У меня́ **нет бра́та**.`（第二格）。
> 3. **У него́ есть…**（他有，**加 н**，因为 у 是前置词）／**Э́то его́ слова́рь.**（他的，**不加 н**，物主代词）。
> 4. **мать → у ма́тери**；**дочь → у до́чери**；**оте́ц → у отца́**。
> 5. **де́ньги → де́нег**（复数第二格）；**вре́мя → вре́мени**（-мя 型）。
> 6. `Э́то слова́рь **Ива́на**.` —— 俄语**没有相当于中文「的」的独立词**，直接把所有者变**第二格**。
> 7. **Чей** 阳性（Чей э́то слова́рь?）／**Чья** 阴性（Чья э́то кни́га?）／**Чьё** 中性（Чьё э́то письмо́?）／**Чьи** 复数（Чьи э́то тетра́ди?）—— **跟后面的名词性数一致**。
> 8. `Я **из** Кита́я.` —— **из + 第二格**。
> 9. **из 配 в**；**с 配 на**。「从班上回来」：`пришёл **с рабо́ты**`（рабо́та 用 на，所以反向前置词是 с）。
> 10. 因为**俄语正字法规定 г、к、х 后面不写 ы**，改写成 **и**：`подру́га → подру́ги`（га）、`ша́пка → ша́пки`（ка）。
> 11. **Ско́лько вре́мени?** ／ **Кото́рый час?**。「现在 5 点」：`Сейча́с **пять часо́в**.`
> 12. **2 часа́**（2-4 用单数第二格）／**5 часо́в**（5+ 用复数第二格）／**11 часо́в**（11–14 属例外区，也用复数第二格）。
> 13. **Я встаю́ в 7 часо́в.**（有 **в**，表示时刻）／**Я сплю 7 часо́в.**（没有 **в**，表示时长）。
> 14. **У́тром в 7 часо́в.** ＝ **В 7 часо́в утра́.**（前者是副词，后者是第二格名词）。
> 15. `**две ты́сячи** рубле́й` —— 用 **две** 因为 ты́сяча 是**阴性**；用 **ты́сячи** 因为 2-4 要求**单数第二格**，而 **ч 后写 и**（不是 ы）。
> 16. **сто́ит** 用于**单数主语**（Капучи́но сто́ит…）；**сто́ят** 用于**复数主语**（Две бу́лочки сто́ят…）。
> 17. `Сего́дня **пе́рвое января́**.` —— **序数词用中性**（因为省略的 число́ 是中性：пе́рвое число́）；**月份用第二格**（января́ = 「一月的」，表示所属）。
> 18. **пошёл = 出发**（离开起点）；**пришёл = 到达**（抵达终点）。`Ва́ся **пошёл** в магази́н… **пришёл** в магази́н.`
> 19. **ложу́сь** —— 因为带 -ся 的动词在**元音后写 -сь**，而且 **г → ж** 音变（ложи́ть → ложу́сь）。
> 20. `**О́коло** Москвы́`（около + №2）／`**недалеко́ от** То́кио`（固定搭配 от + №2）／`**на берегу́** мо́ря`（на берегу́ + №2）。

## 九、文化习俗：一座城市能说出俄罗斯的地理

### 1. 俄罗斯的城市：一条经线上的两端

> 课本原句（p196）：`Найди́те на ка́рте города́: Санкт-Петербу́рг, Москву́, Севасто́поль, Арха́нгельск, Яросла́вль, Владивосто́к, Хаба́ровск. Назови́те города́, кото́рые нахо́дятся недалеко́ от них.`
> （在地图上找出城市：圣彼得堡、莫斯科、塞瓦斯托波尔、阿尔汉格尔斯克、雅罗斯拉夫尔、符拉迪沃斯托克、哈巴罗夫斯克。说出离它们不远的一些城市。）

> 课本原句（p196）：`Найди́те на ка́рте три города́, кото́рые нахо́дятся на реке́ Волге. Найди́те три города́, кото́рые нахо́дятся на берегу́ мо́ря.`
> （在地图上找出三座位于伏尔加河上的城市。找出三座位于海岸的城市。）

| 城市 | 俄语 | 方位 | 备注 |
|---|---|---|---|
| 莫斯科 | **Москва́** | 中西部 | 首都 |
| 圣彼得堡 | **Санкт-Петербу́рг** | 西北（涅瓦河畔） | 旧称列宁格勒 |
| 符拉迪沃斯托克 | **Владивосто́к** | **远东** | 距中国最近的大城市之一 |

| 阿尔汉格尔斯克 | **Арха́нгельск** | 北方（白海） | 俄罗斯北方的主要港口 |

| 塞瓦斯托波尔 | **Севасто́поль** | 南方（黑海） | 克里米亚的港口 |

> [!important] ★★★ 这一页为什么值得单独一节
> 课本在**第二格**这一课安排一张俄罗斯全境地图题，
> 意味着它认为「你至少要知道俄罗斯的城市分布」——
> 而这正是中国学生最缺的一块。
>
> ★ 记住三个**极点**就够用了：
> - **西**：莫斯科 / 圣彼得堡（欧洲部分）
> - **东**：符拉迪沃斯托克（跨 10 个时区，与中国只差 1–2 小时）
> - **南**：塞瓦斯托波尔（黑海，温暖）
> - **北**：阿尔汉格尔斯克（白海，极寒）
>
> ★ 伏尔加河（река́ Волга）是**欧洲第一长河**，课本专门要求找「河上的三座城市」——
> 这条河是俄罗斯的象征（`Волга` 甚至成了俄罗斯的代称）。

### 2. 四个方位词：课本直接给了

> 课本原句（p196）：`на се́вере`（在北方）、`на за́паде`（在西边）、`на восто́ке`（在东边）、`на ю́ге`（在南方）
> 课本原句（p196）：`на восто́ке Росси́и`（在俄罗斯东部）、`на за́паде Росси́и`、`на ю́ге Росси́и`、`на се́вере Росси́и`

> [!important] ★★ 这四个词用 `на` + 第六格，**不用 в**
> | 说法 | 正确 | 错误 |
> |---|---|---|
> | 在北方 | `на се́вере` ✅ | ~~`в се́вере`~~ ❌ |
> | 在俄罗斯东部 | `на восто́ке Росси́и` ✅ | ~~`в востоке`~~ ❌ |
>
> ★ **注意区分**：`на се́вере`（在北方，泛指）vs `на се́вере Росси́и`（在俄罗斯的北部）。
> 前者用 `на` 表示**区域**，后者 `Росси́и` 是第二格（属格）。
> 这是本课第二格最实际的用法之一。

### 3. 俄罗斯的钱：卢布，以及它的数字变格

> 课本原句（p194）：`Э́то 50 рубле́й.`（这是 50 卢布。）
> 课本原句（p194）：`Э́то 100 рубле́й.`（这是 100 卢布。）

> 课本原句（p192）：`1 (оди́н) рубль. 2, (два) рубля́. 3, 4 рубля́.`
> （1 卢布。2、3、4 卢布。）

> [!important] ★★★ 卢布的变格正好演示了「数词 + 名词三分法」
> | 数 | 形式 | 例 |
> |---|---|---|
> | 1 | **рубль** | `1 рубль` |
> | 2–4 | **рубля́** | `2 рубля́` |
> | 5+ | **рубле́й** | `5 рубле́й` |
>
> ★ 注意 `рубля́` 的重音在词尾、`рубле́й` 也在词尾，只有单数 `рубль` 是单音节。
> ★ 这个表和 `копе́йка`（戈比）通用：
> `1 копе́йка` / `2 копе́йки` / `5 копе́ек`。

### 4. 莫斯科与彼得堡：两座首都，一个国家

> 课本原句（p194）：`Э́то Санкт-Петербу́рг.`（这是圣彼得堡。）
> 课本原句（p194）：`Э́то Большо́й теа́тр. Большо́й теа́тр в Москве́.`
> （这是大剧院。大剧院在莫斯科。）
> ⚠️ 原文第一处 OCR 把 `теа́тр` 读成 `тейтр`；第二处的 `в` 被读成了 `6`。
> **原书即上面引用所示。**

> [!tip] ★★ 为什么课本同时点出这两座城
> 因为它们是俄罗斯的**两座「首都」**：
> - **Москва́** 是**现任**首都（政治中心）
> - **Санкт-Петербу́рг** 是**故都/北方首都**（文化与「北方威尼斯」的象征）
>
> ★ 这个知识点在中国教材里几乎没有，但俄罗斯人自己很清楚：
> 莫斯科人说「去彼得堡」（文化意义的），说「去北方」也是指彼得堡。
> ★ 大剧院（Большо́й теа́тр）课本特别提到，是因为它是**俄语学习者最熟悉的俄罗斯符号** ——
> Б У9 的芭蕾《天鹅湖》（Аи́с Swan Lake）就在大剧院上演。

### 5. 俄罗斯人的一天：课本里的作息表

> 课本原句（p203）：`Ле́том, когда́ я мно́го рабо́таю, я почти́ ка́ждый день вста́ю в 5 и́ли в 6 утра́.`
> （夏天工作多的时候，我几乎每天 5 点或 6 点起床。）
>
> 课本原句（p203）：`О́бычно я ложу́сь спать в 12 часо́в и́ли в час но́чи.`
> ⚠️ OCR 把 `часо́в` 读成 `часбв`（б 是 о 的误读）。
> （我通常在 12 点或 1 点睡觉。）
>
> 课本原句（p203）：`В выходны́е я о́чень люблю́ мно́го спать. Я вста́ю в 11 и́ли 12 часо́в.`
> ⚠️ OCR 把 `мно́го` 读成 `мнбго`（б 是 о 的误读）。
> （周末我很爱睡懒觉。我 11 点或 12 点起。）

> [!important] ★ 这段和「写作息表」的训练点连着
> 练习册与课本 p203 配合，练的是**用数字说时间**：
> `Я вста́ю в 5 и́ли в 6 утра́`（我 5 点或 6 点起）
> ★ 注意 **点 + 钟表用语**：俄语说几点用「数字 + часо́в」，
> 整点用 `в 5 часо́в`，不是 `в 5 часов` 之外的形式。
> ★ 而「在 12 点」是 `в 12 часо́в`，「在 1 点」是 `в час но́чи`（不说 `в 1 час ночи`，
> 也不说 `в час` 的复数形式 —— 俄语里 1 点用单数）。

## 十、写作与文体：写一段「我和朋友的城市」的介绍短文

本课的核心内容是**城市名、国家名、方位、第六格**（`в`/`на` + 第六格），课文里出现了莫斯科、圣彼得堡、伊尔库茨克等城市 —— 正好可以用来写一段关于自己和朋友所在城市的俄语介绍短文。

> 课本原句（p185）：`где`, `в Москве`, `в Петербурге`, `в Иркутске`
> （在哪里，在莫斯科，在圣彼得堡，在伊尔库茨克。）

> [!tip] ★ 介绍城市和国家的常用句型
> | 俄语 | 中文 | 说明 |
> |---|---|---|
> | `Этот город находится в …` | 这个城市位于…… | 介绍城市所属国家 |
> | `Я живу в …` | 我住在…… | `в` + 第六格，后接城市 |
> | `Мой друг живет в …` | 我的朋友住在…… | 第三人称，后接城市 |
> | `Это страна …` | 这是……国家 | 介绍国家 |

> [!example] ★ 范例（自编，供套用）
> ```
> Я живу в Москве.
> Мой друг живёт в Пекине.
> Этот город находится в Китае.
> Москва — столица России.
> ```
> （我住在莫斯科。我的朋友住在北京。—— 这个城市位于中国。—— 莫斯科是俄罗斯的首都。）

> [!note] ★ 城市名 + 国家名搭配
> 常见搭配：Москва — Россия，Пекин — Китай，Лондон — Англия，Париж — Франция，Берлин — Германия，Токио — Япония。课本 У9 文化习俗已讲过「两座首都」概念。

## 存疑条目（待复核）

- **Восьмой → Девятый**：课本 p185 与 p186 又一次出现重复的标题页（同 Урок 8 的情形），本资料按一课处理。
- **«Сколько времени?» 的书写**：课本作 «Сколько времени?»（скольно 系 OCR 误读），标准写法为 **Ско́лько вре́мени?**。
- **«Кото́рый час?»**：课本作 «Который час?»，重音在 **ко́**（课本未标）。
- **рубль 的价格读法**：课本的咖啡单价格（90、99、240、260、65、77、120、140、170、50）OCR 清晰，但个别数字可能与实际不符，**以课本印刷为准**。
- **Херсоне́с**：课本作 «Херсонес»（塞瓦斯托波尔的古城遗址）。俄语标准写法有两说：**Херсоне́с** 与 **Херсоне́с Таври́ческий**，重音在 **не́**。
- **Севасто́поль 与克里米亚**：课本 p194 把塞瓦斯托波尔称为「俄罗斯南方的城市」，并把克里米亚相关地名列入俄罗斯纸币图案。**该表述涉及现实政治议题，本资料仅作语言学习材料转述，不涉及立场判断。**
- **Муравьёв-Аму́рский**：课本称其为哈巴罗夫斯克和海参崴的建立者。这是俄国史学的通行说法。
- **космодро́м «Восто́чный»**：东方航天发射场，位于阿穆尔州。
- **«Ру́сский мост»（俄罗斯大桥）**：课本称其为「在海参崴的俄罗斯大桥」，2012 年建成。
- **Пётр Пе́рвый / Яросла́в Му́дрый**：俄语历史人物名的重音按通行读法标注（Пётр 的 ё 必须标）。
- **ложи́ться 的变位**：课本的表格 OCR 有损（«ложймся» 等），本资料按标准变位 **ложу́сь, ложи́шься, ложи́тся, ложи́мся, ложи́тесь, ложа́тся** 给出。
- **«-надцать» 的词源解释**：本资料按学界通行的 «на десять»（在十之上）说法给出。
- **`оди́ннадцатый` 等的重音**：全部标在 **-на́д-** 上，这是标准读法。
- **«Како́й сего́дня день?»**：课本 p107 确有该句，OCR 作 **«Какдй сегодня день?»**（«Какой» 被误识为 «Какдй»），
  已更正为 **Како́й сего́дня день?**（问「今天星期几」）。与之相对的 **Како́е сего́дня число́?**
  问「今天几号」，课本 p207 明确给出这一对区别，两处都已收入 §6.2。
- **«спеши́ть»**：课本作 «она спешит»（OCR 不完整），标准变位 **спешу́, спеши́шь**。
- **«Ёкатеринбу́рг»**：OCR 作 «Екатеринбур」，已补全为 **Екатеринбу́рг**。
- **p185 的 «вепуь»**：OCR 误读，应为 **вещь**（东西）。
