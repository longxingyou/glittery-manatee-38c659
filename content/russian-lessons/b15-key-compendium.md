## 一、六格体系总表

> ★★ **这是 Базовый 最重要的一张表。** 六格在十课里的分布：

| 格 | 名称 | 核心问题 | 最典型用法 | 学于 |
|---|---|---|---|---|
| **1** | Имени́тельный | кто? что? | 主语 | Э 阶段 |
| **2** | Роди́тельный | кого́? чего́? | 没有、所属、数量、来处 | **Б3（单数）· Б4（复数）** |
| **3** | Да́тельный | кому́? чему́? | 给予、需求、朝向 | **Б7** |
| **4** | Вини́тельный | кого́? что? | 直接宾语、方向 | **Б5（单数）· Б6（复数）** |
| **5** | Твори́тельный | кем? чем? | 工具、身份、伴随 | **Б8** |
| **6** | Предло́жный | о ком? о чём? | 位置（`в/на`） | **Б2** |

> **记忆顺序建议**：先记「2 → 4 → 3 → 5 → 6」这个顺序，
> 因为 Базовый 就是这么推进的，且**每学一个新格都与已学的对比**。

### 各格的前置词

| 格 | 前置词 | 例 |
|---|---|---|
| **2** | `из, с, от, до, у, без, для, кроме, наза́д` | `из до́ма`、`до университе́та` |
| **3** | `к, по, благодаря́` | `к врачу́`、`по Москве́` |
| **4** | `в, на, че́рез, за, по́д`（方向） | `в музе́й`、`че́рез неде́лю` |
| **5** | `с, над, под, за, пе́ред, ме́жду, ря́дом с` | `с дру́гом`、`над столо́м` |
| **6** | `в, на, о, при` | `в музе́е`、`о Москве́` |

|---|---|---|---|---|
| 1 | но́вый | но́вое | но́вая | но́вые |

## 四、动词体系

### 1. 体（вид）

| 未完成体 | 完成体 | 意义 |
|---|---|---|
| чита́ть | прочита́ть | 读 |
| писа́ть | написа́ть | 写 |
| де́лать | сде́лать | 做 |
| говори́ть | сказа́ть | 说 |
| покупа́ть | купи́ть | 买 |
| начина́ть | нача́ть | 开始 |
| конча́ть | ко́нчить | 结束 |
| продолжа́ть | продо́лжить | 继续 |
| успева́ть | успе́ть | 来得及 |
| ошиба́ться | ошиби́ться | 犯错 |

> **判断用法**：
> - **未完成体** = 过程、反复、习惯、事实本身
> - **完成体** = 一次完成、结果、将来一定实现

### 2. 运动动词（★ Базовый 的重点）

#### 无前缀：定向 vs 不定向

| 定向（一次、有方向） | 不定向（经常、往返） | 交通方式 |
|---|---|---|
| идти́ | ходи́ть | 步行 |
| е́хать | е́здить | 乘车 |
| лете́ть | лета́ть | 飞 |
| плыть | пла́вать | 水 |
| нести́ | носи́ть | 手拿 |
| вести́ | води́ть | 领人 |
| везти́ | вози́ть | 车载 |

#### 加前缀：九个方向

| 前缀 | 方向 | 前置词 + 格 | 例 |
|---|---|---|---|
| **по-** | 出发 | — | `пойти́` |
| **при-** | 到达 | `в/на` + 4 | `прие́хать в го́род` |
| **у-** | 离去 | `из/с` + 2 | `уе́хать из го́рода` |
| **в(о)-** | 进入 | `в/на` + 4 | `войти́ в дом` |
| **вы-** | 出去 | `из/с` + 2 | `вы́йти из до́ма` |
| **пере-** | 穿过 | 直接 4 | `перейти́ у́лицу` |
| **до-** | 抵达终点 | `до` + 2 | `дойти́ до университе́та` |
| **под-** | 接近 | `к` + 3 | `подойти́ к Кремлю́` |
| **от-** | 远离 | `от` + 2 | `отойти́ от окна́` |

> [!important] ★★ 这张表是 Базовый 最有价值的语法总结
> 九个前缀 + 三个前置词配对（`из/с` · `до/от` · `к`），
> 全部在 Б5–Б8 学完。**背下来就能准确表达任何位移**。

#### 及物版本（Б9）

| 不及物 | 及物（手拿） | 及物（领人） | 及物（车载） |
|---|---|---|---|
| прийти́ | **принести́** | **привести́** | **привезти́** |
| уйти́ | унести́ | увести́ | увезти́ |
| войти́ | внести́ | ввести́ | ввезти́ |
| вы́йти | вы́нести | вы́вести | вы́везти |

### 3. -ся 动词（Б10）

| 类型 | 例 | 特征 |
|---|---|---|
| **纯反身** | одева́ться、мы́ться | 动作回到自己 |
| **相互** | встреча́ться、знако́миться | 互相做 |
| **被动** | Дом стро́ится. | 主语是被做的对象 |
| **只有 -ся** | нра́виться、смея́ться、боя́ться | 去掉 -ся 不成词 |

### 4. 命令式（Б10）

| 规则 | 条件 | 例 |
|---|---|---|
| **-й** | 词干以元音结尾 | чита́й、гуля́й |
| **-и** | 辅音结尾 + 第一人称重音在末 | говори́、позвони́ |
| **-ь** | 辅音结尾 + 第一人称重音不在末 | отве́ть、встань |
| **-те** | 复数/敬称 | чита́йте、говори́те |

**特殊**：`будь`、`дай`、`ешь`、`пей`、`иди́`、`сядь`、`ляг`

### 2. чтобы 的两种用法（★易混）

| 用法 | 结构 | 例 |
|---|---|---|
| **愿望**（主句主语想要别人做） | `хочу́, что́бы` + **过去时** | `Я хочу́, что́бы ты пришёл.` |
| **目的**（同一主语） | `что́бы` + **不定式** | `Я пришёл, что́бы учи́ться.` |
| **目的**（不同主语） | `что́бы` + **过去时** | `Я принёс кни́гу, что́бы ты прочита́л.` |

### 3. 间接引语四种（Б3 + Б4 + Б6 + Б9 完结）

| 原话 | 转述 | 例 |
|---|---|---|
| 陈述句 | `что` | `Он сказа́л, что придёт.` |
| 命令/请求 | `что́бы` | `Он сказа́л, что́бы я пришёл.` |
| 疑问（有疑问词） | 保留疑问词 | `Он спроси́л, где я был.` |
| 疑问（无疑问词） | `ли` | `Он спроси́л, был ли я там.` |

> ⚠️ **转述疑问句时语序变陈述序**：`Где ты был?` → `…, где я был.`（不是 `где был я`）

### 4. если 三时态（Б9）

| 类型 | 从句 | 主句 | 例 |
|---|---|---|---|
| **过去** | 过去时 | 过去时 | `Е́сли ты чита́л, ты понима́л.` |
| **习惯** | 现在时 | 现在时 | `Е́сли ты хо́дишь, ты зна́ешь.` |
| **将来** | 完成体将来 | 将来时 | `Е́сли ты посмо́тришь, ты поймёшь.` |

> ⚠️ `е́сли`（如果，不确定）vs `когда́`（当……时，确定）
> `е́сли бы` = 虚拟条件（+ `бы`）

### 5. `кото́рый` 从句：五格全表与「格怎么选」

> [!important] ★★★ 一条规则决定全部
> **`кото́рый` 的性、数由「先行词」决定；它的格由「它在从句里充当什么成分」决定。**
>
> 这是本书**最容易被忽略、也最容易错**的一条。记忆顺序：
> **① 先定先行词的性数 → ② 再看从句里缺什么成分 → ③ 由此定格。**
>
> ★ 中文没有「关系代词随从句变格」这回事，所以这条必须**刻意练**。

#### ① 五格全表（例句全部取自课本原文）

| 格 | 形式（阳性） | 从句里的角色 | 课本实例 | 出处 |
|---|---|---|---|---|
| **第一格** | **кото́рый** | 主语 | `А пе́рвой же́нщиной, **кото́рая** подняла́сь на Эвере́ст, ста́ла япо́нская альпини́стка.` | p210 |
| | | | `о́чень ми́лое живо́тное, **кото́рое** лю́бят во всём ми́ре` | p68 |
| **第二格** | **кото́рого** | 所属 / 否定 / 数量 | `на террито́рии **кото́рого** живу́т свое́й традицио́нной жи́знью коря́ки` | p104 |
| | | | `У неё был люби́мый, **кото́рого** зва́ли Бий.` | p115 |
| **第三格** | **кото́рому** | 接受者 | `челове́к, **кото́рому** ну́жно выполня́ть сле́дующие де́йствия` | p183 |
| | | | `О́чень дре́вний го́род, **кото́рому** уже́ бо́льше ты́сячи лет.` | p297 |
| **第四格** | **кото́рый / кото́рого** | 直接宾语 | `о програ́мме, **кото́рую** откры́л Сберба́нк` | p86 |
| | | | `че́рез **кото́рую** мо́жно войти́ в Кремль` | p176 |
| **第五格** | **кото́рым** | 工具 / 伴随 | `с **кото́рыми** я учи́лась в шко́ле и в университе́те` | p314 |
| | | | `глаго́лы, с **кото́рыми** мы испо́льзуем да́тельный паде́ж` | p168 |
| **第六格** | **кото́ром** | 地点 / 话题 | `Э́то библиоте́ка, в **кото́рой** есть кни́ги на всех язы́ках` | p40 |
| | | | `го́род, в **кото́ром** вы живёте` | p42 |
| | | | `язы́к, на **кото́ром** говоря́т их сосе́ди` | p43 |

> [!warning] ★★ 最容易错的一条：**第四格分「动物 / 非动物」**
> | 先行词 | 第四格形式 | 例 |
> |---|---|---|
> | **非动物** | 同**第一格** | `програ́мма, **кото́рую** откры́л…`（阴性非动物） |
> | **动物（阳性）** | 同**第二格** | `арти́ст, **кото́рого** вы зна́ете`·`друг, **кото́рого** зва́ли` |
>
> ★ 这和你 Э 学的**名词第四格规则完全一样**：
> **阳性动物名词第四格 = 第二格形式，其余 = 第一格形式。**
> `кото́рый` 只是**照抄**了这条规则。
> → 所以「`кото́рый` 的第四格」不是新知识，是**名词第四格的复用**。
> 课本练习册 p146 专门练这个：`арти́ста, **кото́рого** вы зна́ете` / `арти́стку, **кото́рую** пригласи́ли`。

#### ② 前置词必须「一起搬进去」

> [!important] ★★★ 中国学生最高频的错误
> 中文「我住的城市」→ 容易写 `го́род, **кото́рый** я живу́` ❌
> ✅ `го́род, **в кото́ром** я живу́`
>
> **原因**：`жить` 要求「`в` + 第六格」。
> 从句里的动词保持着它对格的要求，所以 `кото́рый` 必须**连同前置词一起**变成 `в кото́ром`。
>
> ★ 判断法：**先把从句还原成独立句，看动词要求什么格**：
> 1. 从句 `я живу́ в э́том го́роде` → 独立句里是 `в` + 第六格
> 2. 把 `э́том го́роде` 换成 `кото́рый` → `в кото́ром`
> 3. 结果：`го́род, в кото́ром я живу́` ✅
>
> **三步法对任何从句都成立**，不要凭感觉。

#### ③ 常用「前置词 + который」搭配表

> 下表是从课本与练习册实例归纳的，**左边是动词/名词的要求，右边是固定搭配**：

| 从句里的动词/名词 | 要求 | 搭配 | 课本实例 |
|---|---|---|---|
| `жить` | `в` + 6格 | `в кото́ром` | p42 |
| `говори́ть` | `на` + 6格（语言） | `на кото́ром` | p43 |
| `учи́ться` | `с` + 5格（同伴） | `с кото́рыми` | p314 |
| `испо́льзовать` | `с` + 5格 | `с кото́рыми` | p168 |
| `войти́` | `че́рез` + 4格 | `че́рез кото́рую` | p176 |
| `жить`（地域） | `на террито́рии` + 2格 | `на террито́рии кото́рого` | p104 |
| `ну́жно`（需要） | 3格 | `кото́рому` | p183 |
| 年龄表达 | 3格 | `кото́рому … лет` | p297 |
| `нра́виться`（话题） | `о` + 6格 | `о кото́ром` | p40 |

> [!tip] 记忆窍门：**看 `кото́рый` 后面跟的是名词还是动词**
> - 后面**紧接动词**（`кото́рый живёт`）→ 它作**主语**，用**第一格**
> - 后面**紧接名词**（`на террито́рии кото́рого…`）→ 它作**定语**，用**第二格**
> - 中间**有前置词** → 格由**前置词**决定
>
> ★ 这三条能覆盖大部分情况。

## 六、易混辨析速查

### 1. 第二格 vs 第四格 vs 第六格复数

| 格 | 形容词 | 名词 | 例 |
|---|---|---|---|
| **2 格** | -ых/-их | -ов/-ей/零 | `нет но́вых друзе́й` |
| **4 格**（动物） | -ых/-их | -ов/-ей | `ви́жу но́вых друзе́й` |
| **4 格**（非动物） | -ые/-ие | 同 1 格 | `ви́жу но́вые дома́` |
| **6 格** | -ых/-их | **-ах/-ях** | `о но́вых друзья́х` |

> ★ **2 格、4 格动物、6 格的形容词词尾完全相同**！
> 只能靠**名词词尾**和**前置词**判断。

### 2. где / куда́ / отку́да

| 问 | 格 | 前置词 | 例 |
|---|---|---|---|
| **Где?** | 6 | в/на | `в теа́тре` |
| **Куда́?** | 4 | в/на | `в теа́тр` |
| **Отку́да?** | 2 | из/с | `из теа́тра` |

### 3. 需要（ну́жен）的四种形式

| 被需要的东西 | 形式 | 例 |
|---|---|---|
| 阳性 | **ну́жен** | `Мне ну́жен слова́рь.` |
| 阴性 | **нужна́** | `Мне нужна́ кни́га.` |
| 复数 | **нужны́** | `Мне нужны́ уче́бники.` |
| 要做某事 | **ну́жно** + 不定式 | `Мне ну́жно сдать.` |

### 4. 以及物/不及物运动动词

| 问 | 答 |
|---|---|
| 有直接宾语吗？ | 有 → 及物（`принести́ кни́гу`）；无 → 不及物（`прийти́`） |

| 一次/经常？ | 一次 → 定向；经常 → 不定向 |

### 5. 三个「自己」

| 词 | 用法 | 例 |
|---|---|---|
| **себя́** | 反身代词（宾语） | `люби́ть себя́` |

> ⚠️ 「我自己做」→ `Я сам де́лаю.`（不是 `я себя́`）

### 5. 构词法怎么用（实用建议）

> [!tip] 三个立刻能用的推论
> 1. **看到 `-тель` / `-ник` / `-ист` / `-ец`** → 几乎一定是**人**（或拟人化的物）

#### ① 形容词构成：`-Н-` 与 `-СК-`（练习册 Урок 1 p34）

练习册把两组放在一起，是因为**选哪个后缀不是随意的**：

|---|---|---|

| | **длина́ → дли́нный** | 长度 → 长的 |

| | **контро́ль → контро́льный** ※ | 检查 → 检查的 |

| | **коне́ц → коне́чный** ※ | 末端 → 最终的 |
| **-СК-** | **Арба́т → арба́тский** | 阿尔巴特街 → 阿尔巴特的 |
| | **Ки́ев → ки́евский** ※ | 基辅 → 基辅的 |
| | **Ленингра́д → ленингра́дский** | 列宁格勒 → 列宁格勒的 |
| | **Петербу́рг → петербу́ргский** | 彼得堡 → 彼得堡的 |

| | **де́тектив → детекти́вный** | 侦探 → 侦探的 |

> [!important] ★★★ 本节最有价值的一条：**辅音交替**
> 练习册在这一页**专门标出了交替**（`г/ж`、`ц/ч`、`л/ль`）：
>
> | 交替 | 例 | 说明 |
> |---|---|---|
> | **г → ж** | **Ри́га → ри́жский** ※（里加 → 里加的） | `-ск-` 前 г 变 ж |
> | | **кни́га → кни́жный**（书 → 书的） | 但这里用的是 `-н-`，也是 г→ж |
> | **ц → ч** | **коне́ц → коне́чный**（末端 → 最终的） | ц 变 ч |
> | **л → ль** | **Брази́лия → брази́льский**（巴西 → 巴西的） | л 变软 |
>
> ★ 这不是零散现象，而是**俄语构词的硬规则**：
> **后缀 `-ск-` 和 `-н-` 加在 г/к/х/ц 后面时，这些辅音必交替**。
> - `г → ж`：`Ри́га → ри́жский`、`доро́га → доро́жный`
> - `к → ч`：`Москва́` 例外（莫斯科是 `моско́вский`），但 `рука́ → ручно́й`
> - `х → ш`：`возду́х → возду́шный`
> - `ц → ч`：`коне́ц → коне́чный`、`оте́ц → оте́ческий`
>
> ★ **拼写规则**（你在 Э 学过）：`к/г/х` 与 `ж/ш/ч/щ` 后面不能写 `ы`，要写 `и`；
> 不能写 `ю/я`，要写 `у/а`。**辅音交替正是这条拼写规则的上游原因。**

## 十一、写作训练（来源：Б 练习册《Я пишу по-русски. Базовый уровень》）

> [!note] 为什么单独开这一节
> **Б 课本完全不教写作** —— 它的十课都是语法与阅读。
> 而 Б 练习册的整个编写目的就是写作（书名直译「我用俄语写」），
> 它有 **5 类固定写作栏目**，共分布在 6 个 Урок 里。
>
> ★ 这一节把练习册散落在各课的写作方法**汇总成一套体系**，
> 因为写作是**技能**，不是某一个语法点的附属。
> 全部素材出自 `_extract/ypu_baz/`，页码可回查。

### 1. 练习册的 5 类写作栏目（按难度阶梯）

| 栏目 | 俄语原名 | 出现页 | 训练什么 |
|---|---|---|---|
| **① 写书信** | `Учимся писа́ть письмо́` | p10 · p44 | 交际性写作：问候、叙事、提问、结尾 |
| **② 处理文本** | `Учи́мся рабо́тать с те́кстом` | p13 · p59 · p161 | 阅读理解 + 新词 + 拆解词族 |
| **③ 写短文** | `Учи́мся писа́ть текст` | p21 · p56 | 按**句型模型**造段 |
| **④ 写转述** | `Учи́мся писа́ть изложе́ние` | p21 · p29 · p62 · p80 | 缩写：提提纲 → 找支撑词 → 复述 |
| **⑤ 写作文** | `Учи́мся писа́ть сочине́ние` | p133 · p160 | 自由写作：人物评述 |

> [!important] ★★ 这个顺序本身就是方法论
> **书信 → 处理文本 → 短文 → 转述 → 作文**
> 从「有模板可套」到「自由表达」，**每一步都建立在前一步之上**。
> ★ 请注意 **④ изложение 的位置**：它要求你先**读懂**、再**列提纲**、
> 再**复述** —— 这是中国学生最缺、也最实用的能力（考试常考）。

### 2. 书信的固定结构（练习册 p10 · p44）

练习册用**同一对人物**（Макс ↔ Том）写了两封信，是为了让你看出**模板的复用性**。

**第一封（p10）：自我介绍式**

| 段落 | 功能 | 练习册原文开头 |
|---|---|---|
| ① 称呼 | `Приве́т, Том!` | 非正式 |
| ② 引出 | `Пишу́ тебе́ пе́рвое письмо́ из Москвы́.` | 「我从莫斯科给你写第一封信」 |
| ③ 正文 | 学习 / 兴趣 / 去过哪 | 三层展开 |
| ④ 反问 | `А как твои́ дела́?` | **转折点，把话头交给对方** |
| ⑤ 结尾 | `До свида́ния! Пиши́.` | 「再见！写信来。」 |
| ⑥ 署名 | `Макс.` | |

**第二封（p44）：兑现承诺式**

> 练习册原文（p44，**词尾是留给学生填的空**）：
> `В прошл… письме я обеща́л тебе́ рассказа́ть о ру́сск… худо́жнике Исаа́ке Левита́не.`
> （在上一封信里我答应过你要讲讲俄罗斯画家伊萨克·列维坦。）
>
> ⚠️ **`прошл…` 和 `ру́сск…` 的省略号不是我省的，是原书的填空处**。
> 正确词尾是 `в про́шлом письме́`、`о ру́сском худо́жнике`（阳性第六格）。
> 练习册整封信都是这种填空题 —— **这正是你要练的形容词变格**。

> [!tip] ★★★ 这一句是书信写作的「钥匙句」
> `В про́шлом письме́ я обеща́л тебе́ рассказа́ть о…`
> —— 它同时做到三件事：
> 1. **承接上一封**（`в прошлом письме`）
> 2. **交代本封主题**（`рассказать о…`）
> 3. **建立连续性**（`обещал` 表明这是承诺的兑现）
>
> ★ 中国人写俄语信最容易犯的错是**没有这个过渡句**，直接开始讲内容，
> 让收信人不知道这封信为什么写。**加上这一句，信立刻像样。**

> [!warning] ★ 练习册的这两封信是**填空练习**
> 原页把形容词词尾留空（`перв__ письмо`、`эт__ прекрасн__ город`、
> `Московск__ государственн__ университете`），让学生填。
> **本精讲不代填**——那正是你要练的。
> 需要答案时请对着课本 §三/§四 的形容词变格表自己核。

### 3. 处理文本的方法：词族与复合词（练习册 p161）

练习册 p161 有一组**极有价值**的词汇练习，它教的不是「背单词」，而是**看穿构词**。

**① 同一个词根的一组词（словообразова́тельное гнездо́）**

> 练习册原题（p161）：`Найди́те в слова́х о́бщий ко́рень.`
> （找出这些词的共同词根。）

| 词族 | 成员 |
|---|---|
| **-помин- / -помн-** | `по́мнить`（记得）· `вспомина́ть`（回忆）· `упомина́ть`（提及）· `упомина́ться` · `упомина́ние`（提及） |
| **-пис-** | `писа́ть`（写）· `описывать`（描写） |
| **-существ-** | `существова́ние`（存在）· `существова́ть`（存在） |
| **-княж- / княз-** | `князь`（大公）· `князья́`（复数）· `кня́жество`（公国） |
| **-земл-** | `земля́`（土地）· `земля́к`（同乡） |
| **-хват-** | `захва́тывать`（占领）· `захва́тчик`（侵略者） |
| **-план-** | `план`（计划）· `плани́ровать`（规划）· `планиро́вка`（布局） |
| **-образ-** | `образе́ц`（样品）· `образцо́вый`（标准的） |

> [!important] ★★ 为什么这比背单词表有效
> 记住「`упомина́ть` = 提及」是一次性投入；
> 记住 **`-помин-` = 「提到/记起」** 是一次投入、长期复用 ——
> 之后遇到 `упомина́ние`、`вспомина́ть`、`напомина́ть` 你都能猜出意思。
>
> ★ **俄语词汇量爆炸式增长的唯一路径就是词族**。
> 一个词根平均能派生 10–15 个词，**背词根比背词省 10 倍力气**。

**② 复合词怎么拆**

> 练习册原题（p161）：`Из каки́х слов состои́т сло́во градострои́тельство?`
> （`градостроительство` 这个词由哪些词组成？）

**答案：`град`（城市）+ `о`（连接元音）+ `строи́тельство`（建设）= 城市建设**

> [!tip] 俄语复合词的两个连接元音
> | 连接元音 | 用在哪 | 例 |
> |---|---|---|
> | **-о-** | 第一成分以**硬辅音**结尾 | `град**о**строительство` · `сам**о**лёт`（飞机） |
> | **-е-** | 第一成分以**软辅音/ж ш ч щ ц**结尾 | `земл**е**трясе́ние`（地震） · `птиц**е**фа́брика` |
>
> ★ 这和你 Э 学的拼写规则是同一套逻辑：
> **`ж/ш/ч/щ/ц` 后不能写 `о` 之外的某些元音** —— 连接元音的选择也受它管。
> 例：`пеш**е**хо́д`（步行者，ш 后用 е）、`пул**е**мёт`（机枪）。

### 4. 传记类写作的句型模型（练习册 p34）

练习册 p34 给了一张**写人物传记的句型表**，这是它最有价值的写作工具：

| 功能 | 句型模型 | 中文 |
|---|---|---|
| **谈到出生** | `Кто? роди́лся где? когда́?` | 谁 在哪里 何时 出生 |
| **谈到教育** | `Кто? получи́л како́е? образова́ние` | 谁 受过什么 教育 |
| | `Когда́? кто? поступи́л куда́?` | 何时 谁 考入 哪里 |
| | `Когда́? кто? око́нчил что?` | 何时 谁 毕业于 什么 |
| | `Когда́? кто? продолжи́л что? где?` | 何时 谁 继续 什么 在哪里 |
| **谈到工作** | `Когда́? кто? рабо́тал где?` | 何时 谁 在哪里 工作 |
| | `Где? кто? занима́лся чем?` | 在哪里 谁 从事 什么 |
| | `Когда́? кто? стал кем? и на́чал рабо́тать где?` | 何时 谁 成为 谁 并 开始 在哪里 工作 |

> 练习册给的**范例句**（p34）：
> `Климе́нт Арка́дьевич Тимиря́зев роди́лся в Петербу́рге в 1843 году́.`
> （克利门特·阿尔卡季耶维奇·季米里亚捷夫 1843 年生于彼得堡。）

> [!important] ★★★ 同一页还有一个**极实用的小技巧**
> 练习册专门列出**同一个人的不同指代方式**：
> > `В ка́честве субъе́кта кто употребля́йте слова́:`（作主语时请使用这些词）
> > `Климе́нт Арка́дьевич Тимиря́зев, Климе́нт Арка́дьевич, Климе́нт Тимиря́зев,`
> > `Тимиря́зев, учёный, он.`
>
> **这是为了解决「名字重复」这个所有初学者都有的毛病**：
> 写人物传记时，一句话一个人名，读起来非常笨。
> 俄语的正确做法是**逐步缩短**：
> **全名（首次）→ 名+父称 → 名+姓 → 姓 → 身份名词 → 代词 он**
>
> ★ 中文习惯是「他」从头用到尾；**俄语要求你交替使用**，
> 否则会显得词汇贫乏。这是**中文母语者写俄语文章时最明显的破绽**。

### 5. 转述（изложение）的标准流程

练习册把 изложение 拆成**固定三步**，每篇都这么做：

> 练习册原题（p21）：`Напиши́те план те́кста.` → `Вы́пишите опо́рные слова́ и словосочета́ния к пу́нктам пла́на.` → `Напиши́те изложе́ние.`

| 步 | 做什么 | 中文 |
|---|---|---|
| **①** | `Напиши́те план те́кста` | 写出课文提纲 |
| **②** | `Вы́пишите опо́рные слова́` | 摘出每段的**支撑词** |
| **③** | `Напиши́те изложе́ние` | 合上原文，凭提纲+支撑词复述 |

> [!tip] ★★ 为什么第 ② 步是关键
> 「支撑词」（`опо́рные слова́`）不是随便摘的，练习册的原话是
> `опо́рные слова́ и словосочета́ния, кото́рые по́могут вам отве́тить на вопро́сы`
> （**能帮你回答问题的**词与词组）。
> 也就是说：**先有问题，再找词**。
>
> ★ 这个方法和你在 Э 学精读时用的「先看题目再读文章」是同一个道理，
> 但写作时它是**产出**训练：你得先知道自己要说什么，才知道该记哪些词。

### 6. 怎么用这一节

> [!tip] 建议的练习顺序（每课约 30 分钟）
> 1. **先练词族**（第 3 节的方法）：每天挑一个词根，写出它的 5 个派生词
> 2. **再练句型模型**（第 4 节）：用句型表写一段 80 字的人物简介
> 3. **然后写信**（第 2 节）：套书信六段结构，写一封 120 字的信
> 4. **最后练转述**（第 5 节）：找课本任何一段课文，走「提纲→支撑词→复述」三步
>
> ★ 四步里**第 4 步最难也最有用**，因为它同时练阅读和写作。
> 练习册把它放在最后一个栏目（`Учи́мся писа́ть сочине́ние` 之前），是有道理的。
