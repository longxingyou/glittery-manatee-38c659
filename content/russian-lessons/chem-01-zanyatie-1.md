# Занятие 1 · Вещества и их формулы（物质及其式）

> **《Готовимся слушать лекции по общей химии》配套讲义 · 第 1 讲**
>
> **主题**：物质（вещество́）及其化学式 · 物质的物理性质与化学性质
> **本讲四件事**：
> ① 十二个**描述物质性质的形容词性名词**（颜色、气味、味道、温度、密度、溶解度…）
> ② 由名词**派生形容词**的两条路：`-ическ-`（学科→学科的）与 `-н-/-ов-`（名词→性质形容词）
> ③ 化学式的**三级读法**：读字母名 / 读俄语元素名 / 读拉丁元素名 ← **本讲最大难关**
> ④ 五个基础句型：`ЧТО какого цвета?`、`ЧТО делится на ЧТО`、`ЧТО имеет ЧТО`…
>
> **承上启下**：这是化学俄语的**起点**。学完这一讲你能做到「看见一个物质，
> 说出它什么颜色、什么气味、什么状态、由什么构成」；下一讲（Занятие 2）
> 才正式回答「化学研究什么」。

## 一、这一讲讲什么

| 你要掌握的 | 具体内容 |
|---|---|
| **12 个性质名词** | вещество́ · фо́рмула · строе́ние · соста́в · сво́йство · агрега́т · цвет · за́пах · вкус · температу́ра · пло́тность · раствори́мость |
| **形容词派生** | `хи́мия → хими́ческий`、`цвет → цветно́й`、`жи́дкость → жи́дкий`、`яд → ядови́тый` |
| **性数一致** | `хими́ческий элеме́нт` / `хими́ческая нау́ка` / `хими́ческое вещество́` |
| **复数变化** | `просто́е вещество́ → просты́е вещества́`（两部分都变） |
| **化学式读法** | `H₂O` → аш-два-о（读字母）· `Al₂O₃` → алюми́ний-два-о-три（读俄语名） |
| **五个句型** | 见 §六 |

> **一句话**：这一讲教的是「**怎么用俄语描述一个物质**」。
> 化学内容本身不难（单质/化合物、颜色、气味），难的是**形容词要跟着名词变性数**。

### 关于「三栏词汇表」的说明

本资料的词表不是普通词表，而是**三栏对照**：

```
Русский язык  |  Английский язык  |  Родной язык
（俄语）       |  （英语）          |  （母语）
```

> **怎么用**：英语栏不是装饰。化学术语的**俄英同源率极高**
> （`фо́рмула = formula`、`температу́ра = temperature`、`пло́тность = density`），
> 看到英语就能推出俄语。反过来，**俄语和英语不同源的那些**（如 `вещество́ = substance`）
> 才是真正要背的。本讲义每讲会标出「同源词」与「异源词」。

## 三、词源与记忆法

> 化学术语的俄语命名有很清晰的规律：**国际词直接音译，本土概念用构词法造词**。
> 认清这两条路，词汇量立刻减半。

### 3.1 国际词：和英语几乎一样

| 俄语 | 英语 | 说明 |
|---|---|---|
| фо́рмула | formula | 拉丁 formula |
| температу́ра | temperature | 拉丁 temperatura |
| пло́тность | density | 俄语本土（见下） |
| кристалли́ческий | crystalline | 希腊 krystallos（冰） |
| органи́ческий | organic | 希腊 organon（器官） |

> ★ **规律**：以 `-ция / -тура / -изм / -ический` 结尾的多为国际词，
> 和英语对应词只差词尾。**看到就大胆读**。

### 3.2 俄语本土词：靠构词法

| 词 | 拆解 | 字面意思 |
|---|---|---|
| **вещество́** | вещь（物）+ -еств- | 「物」的集合 → 物质 |
| **сво́йство** | свой（自己的）+ -ств- | 「属于它自己的东西」→ 性质 |
| **строе́ние** | стро́ить（建造）+ -ени- | 「建造的方式」→ 结构 |
| **соста́в** | со-（共同）+ став-（放） | 「放在一起的东西」→ 组成 |
| **раствори́мость** | раствор-（溶液）+ -им- + -ость | 「能成溶液的程度」→ 溶解度 |
| **пло́тность** | пло́тный（密实的）+ -ость | 「密实的程度」→ 密度 |
| **жи́дкость** | жи́дкий（稀的）+ -ость | 「稀的状态」→ 液体 |

> ★ **一条规律记住三个词**：`-ость` 是「抽象名词」后缀，
> 把形容词变成「……的程度/状态」：
> `пло́тный → пло́тность`、`жи́дкий → жи́дкость`、`раствори́мый → раствори́мость`。
> 这条规律在后面的讲里会反复出现（`кисло́тность` 酸度、`твёрдость` 硬度…）。

### 3.3 「物质」一词的三层

| 词 | 含义 | 区别 |
|---|---|---|
| **вещество́** | 物质 | 化学意义上的「物质」，有组成、有性质 |
| **материа́л** | 材料 | 工程意义上的「材料」，强调用途 |
| **те́ло** | 物体 | 具体的一个东西（`твёрдое те́ло` 固体） |

> ★ 化学课上说的「物质」一律用 **вещество́**。

## 四、同义词与反义词

> 资料用两个符号：**`=` 同义**、**`#` 反义**。
> ⛔ 注意：这里的 `#` 是「反义」标记，**不是**编号或注释符号。

### 4.1 СИНОНИМЫ（同义词）

| 词组 | 中文 | 说明 |
|---|---|---|
| **ре́зкий = си́льный** (за́пах) | 刺鼻的 = 强烈的（气味） | 都指气味浓烈 |
| **ядови́тый = токси́чный** | 有毒的 | 后者更书面 |

> ★ `ре́зкий` 的搭配范围比「刺鼻」广：`ре́зкий за́пах`（刺鼻气味）、
> `ре́зкий вкус`（刺激的味道）、`ре́зкое сло́во`（尖锐的话）。

### 4.2 АНТОНИМЫ（反义词）

| 反义对 | 中文 |
|---|---|
| **просто́е # сло́жное** (вещество́) | 单质 # 化合物 |
| **органи́ческое # неоргани́ческое** | 有机的 # 无机的 |
| **прия́тное # неприя́тное** (за́пах) | 好闻的 # 难闻的 |
| **сла́дкий # го́рький** (вкус) | 甜的 # 苦的 |

> ★ 后三对的对方词都是**加否定前缀**造出来的：
> `прия́тный → не-прия́тный`、`органи́ческий → не-органи́ческий`。
> 只有第一对 `просто́е / сло́жное` 是**两个独立的词**，必须单独记。

### 4.3 味道与气味的完整词族（资料 §9 给出）

**味道（вкус）**：

| 俄语 | 中文 |
|---|---|
| **сла́дкий** | 甜的 |
| **го́рький** | 苦的 |
| **ки́слый** | 酸的 |
| **солёный** | 咸的 |

**气味（за́пах）**：

| 俄语 | 中文 | 说明 |
|---|---|---|
| **прия́тный** | 好闻的 | |
| **неприя́тный** | 难闻的 | |
| **ре́зкий** | 刺鼻的 | = си́льный |
| **е́дкий** | 呛人的 | 强调「腐蚀性」的刺激 |
| **специфи́ческий** | 特有的 | 委婉说「有股味儿」 |

> ★ `е́дкий` 和 `ре́зкий` 的区别：`ре́зкий` 只是「强烈」，
> `е́дкий` 带「呛、蚀」的感觉（`е́дкий дым` 呛人的烟）。

## 五、缩写与符号

> ★★ **这一节极其重要**。俄语化学教材**大量使用词中省略缩写**，
> 不认这些缩写，句子会读成乱码。资料的 `Список общепринятых сокращений` 一栏就是为此设的。

### 5.1 缩写规则：词中间用连字符省略

| 全称 | 缩写 | 省略了什么 |
|---|---|---|
| вещество́ | **вещ-во** | вещ**ество** → 只留首尾 |
| вещества́ | **вещ-ва** | |
| веще́ств | **вещ-в** | |
| сво́йство | **св-во** | св**ойство** |
| сво́йства | **св-ва** | |
| сво́йств | **св-в** | |
| раствори́мость | **раст-ость** | раст**воримость** |
| раство́р | **р-р** | р**аствор** |
| раство́ры | **р-ры** | |
| раство́ров | **р-ров** | |
| раствори́тель | **раст-тель** | раст**воритель** |
| температу́ра | **t°-ра** | t° + ра |
| кислота́ | **к-та** | к**ислота** |
| следовательно | **сл-но** | сл**едовательно** |

> ★ **读法**：缩写只用于**书写**，口头朗读时一律读**全称**。
> 所以看到 `вещ-во` 要读 `вещество́`，看到 `р-р` 要读 `раство́р`。

### 5.2 化学式的三级读法（★本讲核心难点）

资料 Таблица 13 把化学式读法分成**三组**，这是俄语化学入门最大的一个坎：

#### 第一组：读**字母名**（Произносится название буквы）

> 适用：**非金属**元素的符号 + 复杂化学式中的字母部分

| 符号 | 字母名 | 化学式 | 读法 |
|---|---|---|---|
| **H** | аш | H₂ | **аш-два** |
| **O** | о | H₂O | **аш-два-о** |
| **C** | цэ | H₂CO₃ | **аш-два-цэ-о-три** |
| **P** | пэ | H₃PO₄ | **аш-три-пэ-о-четы́ре** |
| **N** | эн | HNO₃ | **аш-эн-о-три** |
| **S** | эс | H₂SO₄ | **аш-два-эс-о-четы́ре** |

> ★ **怎么判断用哪组**：看这个元素是不是**金属**。
> 非金属的符号**读字母名**（H=аш、O=о、C=цэ、N=эн、S=эс、P=пэ）。

#### 第二组：读**俄语元素名**（Произносится русское название элемента）

> 适用：**金属**元素的符号（以及少数非金属，见下）

| 符号 | 俄语名 | 化学式 | 读法 |
|---|---|---|---|
| **Al** | алюми́ний | Al₂O₃ | **алюми́ний-два-о-три** |
| **Ba** | ба́рий | BaO | **ба́рий-о** |
| **Ca** | ка́льций | CaCO₃ | **ка́льций-цэ-о-три** |
| **K** | ка́лий | KOH | **ка́лий-о-аш** |
| **Mg** | ма́гний | Mg(OH)₂ | **ма́гний-о-аш-два́жды** |
| **Mn** | марга́нец | KMnO₄ | **ка́лий-марга́нец-о-четы́ре** |
| **Na** | на́трий | Na₂O | **на́трий-два-о** |
| **Ni** | ни́кель | Ni(NO₃)₂ | **ни́кель-эн-о-три-два́жды** |
| **Pt** | пла́тина | PtO₂ | **пла́тина-о-два** |
| **Zn** | цинк | ZnSO₄ | **цинк-эс-о-четы́ре** |

> ★ **`два́жды` / `три́жды`**：括号后面数字的读法。
> `Mg(OH)₂` = 整个括号内的内容「两遍」→ **два́жды**；
> `Fe(OH)₃` = **три́жды**。这是俄语化学式读法的特色，英语用 "twice/three times"。

#### 第三组：读**拉丁元素名**（Произносится латинское название элемента）

> 适用：**古老的金属**（金、银、铜、铁、汞、铅、锡…），符号来自拉丁文

| 符号 | 拉丁读音 | 俄语名 | 中文 | 化学式 | 读法 |
|---|---|---|---|---|---|
| **Ag** | арге́нтум | серебро́ | 银 | AgCl | **арге́нтум-хлор** |
| **Au** | ау́рум | зо́лото | 金 | Au₂O₃ | **ау́рум-два-о-три** |
| **Cu** | ку́прум | медь | 铜 | CuSO₄ | **ку́прум-эс-о-четы́ре** |
| **Fe** | фе́ррум | желе́зо | 铁 | Fe(OH)₃ | **фе́ррум-о-аш-три́жды** |
| **Hg** | гидра́ргирум | ртуть | 汞 | HgS | **гидра́ргирум-эс** |
| **Pb** | плю́мбум | свине́ц | 铅 | PbO₂ | **плю́мбум-о-два** |

> ★★ **这就是本讲最难的地方**：`Fe` 要读 **фе́ррум**，但元素本身叫 **желе́зо**。
> **两套名字必须分开记**：一套「符号怎么念」，一套「元素叫什么」。
>
> **为什么**：符号来自拉丁文（Fe ← Ferrum），俄语名称是本土词（желе́зо）。
> 这类「拉丁符号 + 本土名称」的元素共 **11 个**，见 §七 速查表。

#### 三组读法的判断流程

```
看到一个化学式
    ↓
提问：式中的元素是「金属」还是「非金属」？
    ↓
非金属 → 读字母名（H=аш, O=о, C=цэ, N=эн, S=эс, P=пэ, Cl=хлор*, Br=бром*）
    ↓
金属 → 是「古老金属」（Cu/Fe/Ag/Au/Hg/Pb/Sn）吗？
            ↓ 是                    ↓ 否
        读拉丁名               读俄语元素名
        （ку́прум/фе́ррум…）      （на́трий/ка́льций…）
```

> \* 注意 `Cl`（хлор）、`Br`（бром）、`F`（фтор）、`I`（йод）是**非金属**，
> 但它们的俄语名称**本身就是单音节国际词**，所以「读字母名」和「读元素名」重合了。
> 资料 Таблица 11 专门列了这组「**同名同读**」的元素（见 §七）。

## 六、句型构造

> 资料的 `КОНСТРУКЦИИ` 一栏给出本讲的**句型骨架**。
> 化学俄语的学习诀窍：**先把骨架背下来，再往里填词**。

### 6.1 本讲的五个句型

| № | 句型 | 中文 | 示例 |
|---|---|---|---|
| 1 | **ЧТО какого цве́та?** | 某物是什么颜色？ | `Како́го цве́та вода́?` |
| 2 | **ЧТО хорошо́ / пло́хо растворя́ется в ЧЁМ** | 某物在某物中易/难溶 | `Са́хар хорошо́ растворя́ется в воде́.` |
| 3 | **ЧТО дéлится на ЧТО** | 某物分为…… | `Вещества́ де́лятся на просты́е и сло́жные.` |
| 4 | **ЧТО име́ет ЧТО** | 某物具有…… | `Вещество́ име́ет цвет и за́пах.` |
| 5 | **ЧТО не име́ет ЧЕГО́** | 某物没有……（第二格） | `Вещество́ не име́ет за́паха.` |

> ★ **注意第 1 句**：问「什么颜色」用 **како́го цве́та**（第二格），
> 不是 `како́й цвет`。回答也用第二格：
> `Вода́ како́го цве́та? — Вода́ бе́лого цве́та` 或直接 `Бе́лого цве́та.`
>
> ★ **注意第 5 句**：`не име́ть` 后面接**第二格**（`не име́ет за́паха`），
> 这是俄语「否定及物动词接第二格」的规则。

### 6.2 颜色的完整说法（资料 §7）

颜色词要回答 `како́й цвет?`（第一格）或 `како́го цве́та?`（第二格）：

| 第一格（како́й цвет?） | 第二格（како́го цве́та?） | 中文 |
|---|---|---|
| **бе́лый** цвет | бе́лого цве́та | 白色 |
| **чёрный** цвет | чёрного цве́та | 黑色 |
| **кра́сный** цвет | кра́сного цве́та | 红色 |
| **си́ний** цвет | си́него цве́та | 深蓝色 |
| **голубо́й** цвет | голубо́го цве́та | 浅蓝色 |
| **жёлтый** цвет | жёлтого цве́та | 黄色 |
| **зелёный** цвет | зелёного цве́та | 绿色 |
| **фиоле́товый** цвет | фиоле́тового цве́та | 紫色 |
| **кори́чневый** цвет | кори́чневого цве́та | 棕色 |
| **се́рый** цвет | се́рого цве́та | 灰色 |
| **лило́вый** цвет | лило́вого цве́та | 淡紫色 |
| **вишнёвый** цвет | вишнёвого цве́та | 樱桃红 |
| **сире́невый** цвет | сире́невого цве́та | 丁香紫 |
| **ро́зовый** цвет | ро́зового цве́та | 粉红色 |

> ★ **规律**：第二格 = 第一格去掉词尾 `-ый/-ий/-ой`，加 `-ого`（硬变化）或 `-его`（软变化）。
> `си́ний → си́него`（软），`голубо́й → голубо́го`（重音在尾）。
> ★ **口语捷径**：日常对话直接说 `Бе́лый.` / `Кра́сный.` 就够了，
> 完整第二格形式主要出现在**书面语和考试**里。

## 七、语法表格

> ★★ **读表格的方法**：这批资料的表格**横纵两个维度都有含义**。
> 读之前先问一句：「横排是什么、竖列是什么？」搞反了整张表就废了。

### 7.1 Таблица 1：学科 → 形容词（`-ическ-` 后缀）

| 名词（学科） | 形容词 | 中文 |
|---|---|---|
| **арифме́тика** | арифмети́ческий | 算术 → 算术的 |
| **а́лгебра** | алгебраи́ческий | 代数 → 代数的 |
| **фи́зика** | физи́ческий | 物理 → 物理的 |
| **хи́мия** | хими́ческий | 化学 → 化学的 |
| **биоло́гия** | биологи́ческий | 生物 → 生物的 |
| **физиоло́гия** | физиологи́ческий | 生理 → 生理的 |
| **анато́мия** | анатоми́ческий | 解剖 → 解剖的 |

> **横纵关系**：横排是「一个学科名词 + 它的形容词」，一对一行。
> **纵向规律**：全部用 **`-ическ-`** 后缀，重音都落在 **и́** 上（`хими́ческий`）。
>
> ★ **记忆法**：`-ическ-` ≈ 英语 `-ic`。看到学科名，直接把词尾换成 `-ический` 即可。
> 唯一要注意的是 `а́лгебра → алгебраи́ческий`（多了一个 а）。

### 7.2 Таблица 2：形容词的性数一致

| 横：形容词（阳/阴/中） | 纵：名词 | 搭配 |
|---|---|---|
| **хими́ческий** | элеме́нт（阳） | хими́ческий элеме́нт |
| **хими́ческая** | нау́ка（阴） | хими́ческая нау́ка |
| **хими́ческое** | вещество́（中） | хими́ческое вещество́ |

> **横纵关系**：**横排是形容词的三种性**，**竖列是名词**。
> ★ 读法：**每个名词只能配一个性的形容词**——纵列决定选哪个横排。
> `элеме́нт` 是阳性 → 只能配 `хими́ческий`；`нау́ка` 是阴性 → 只能配 `хими́ческая`。
>
> ★★ **这就是本讲的语法核心**：不是「哪个形容词对」，而是「**名词的性决定形容词的词尾**」。

### 7.3 Таблица 3：名词 → 性质形容词（不是 `-ическ-` 那条路）

| 名词 | 形容词 | 中文 |
|---|---|---|
| **цвет** | цветно́й | 颜色 → 彩色的 |
| **жи́дкость** | жи́дкий | 液体 → 液态的 |
| **яд** | ядови́тый | 毒物 → 有毒的 |
| **газ** | газообра́зный | 气体 → 气态的 |

> **横纵关系**：横排「名词 → 形容词」一对一。
> **纵向规律**：这条路的后缀**不统一**（`-н-`、`-к-`、`-овит-`、`-образн-`），
> 必须逐个记。表 3 的价值就在这里——它列的是**不能靠规律推的**那几个。

### 7.4 Таблица 4：名词词组的复数

| 单数 | 复数 |
|---|---|
| **вещество́** | вещества́ |
| **просто́е вещество́** | просты́е вещества́ |
| **сло́жное вещество́** | сло́жные вещества́ |
| **органи́ческое вещество́** | органи́ческие вещества́ |
| **неоргани́ческое вещество́** | неоргани́ческие вещества́ |
| **ядови́тое вещество́** | ядови́тые вещества́ |
| **неядови́тое вещество́** | неядови́тые вещества́ |

> ★★ **最容易犯的错**：词组变复数时**形容词和名词都要变**，不是只变一个。
> `просто́е вещество́ → просты́е вещества́`（两个词都变了）。
> 这是中国学习者最常见的错误之一。

### 7.5 Таблица 5：第二格（「第二名词」的变化）

| 第一格（И.п.） | 第二格（Р.п.） |
|---|---|
| сво́йство | сво́йств |
| за́пах | за́пахов |
| цвет | цвето́в |
| вкус | вку́сов |
| пло́тность | пло́тностей |
| раствори́мость | раствори́мостей |
| строе́ние | строе́ний |

> **纵列读法**：这是「复数第二格」——`чего́?` 的答案。
> 用于 `температу́ра (чего́?) плавле́ния`（熔化温度）这类**属格搭配**。
> ★ 注意 `пло́тность → пло́тностей`：`-ость` 结尾的阴性名词，
> 复数第二格去掉 `-ь` 加 `-ей`。

### 7.6 Таблица 6：名词 → 动词 → 动名词（三位一体）

| 动词（不定式） | 名词（动名词） | 中文 |
|---|---|---|
| **превраща́ться — преврати́ться** | превраще́ние | 转化 |
| **кипе́ть — закипе́ть** | кипе́ние | 沸腾 |
| **пла́виться — распла́виться** | плавле́ние | 熔化 |
| **растворя́ться — раствори́ться** | раствори́мость | 溶解 |

> **横纵关系**：**横排**是一个词的三态（未完成体 — 完成体 → 动名词）。
> ★ **本资料的核心编排逻辑**：动词成对给（НСВ / СВ），动名词单列。
> 后面每讲都会出现这个模式，认熟了会轻松很多。

### 7.7 Таблица 7：第四格（`изуча́ть` 支配的宾格）

| 第一格 | 第四格（В.п.） |
|---|---|
| матема́тика | матема́тику |
| фи́зика | фи́зику |
| хи́мия | хи́мию |
| биоло́гия | биоло́гию |
| анато́мия | анато́мию |

> **横纵关系**：横排「原形 → 宾格」，竖列各学科。
> ★ 规律：`-а → -у`，`-ия → -ию`。
> 用于 `изуча́ть (что?) хи́мию`（研究化学）。

### 7.8 Таблица 8/9/10：三个关于「有/无/分」的句型表

**Таблица 8：`ЧТО изуча́ет ЧТО` / `ЧТО име́ет ЧТО`**

| Что?（主语） | Что?（В.п. 宾语） | Чего́?（Р.п.） |
|---|---|---|
| Хи́мия изуча́ет | соста́в | — |
| | строе́ние | — |
| | сво́йства | — |
| | превраще́ния | — |
| Вещество́ име́ет | за́пах / цвет / вкус / сво́йство | — |

> **横纵关系**：横排是「主语 + 动词」，竖列是**能填进宾语位置的词**。
> ★ 注意表格右侧还有一列 `Чего́?`——那是提示：**否定时**这些词要变第二格。

**Таблица 9：`ЧТО не име́ет ЧЕГО́`（否定接第二格）**

| Что? | Чего́?（Р.п.） | = Без (чего́) |
|---|---|---|
| Вещество́ не име́ет | за́паха | = без за́паха |
| | цве́та | = без цве́та |
| | вку́са | = без вку́са |

> **横纵关系**：表格**横向对照**两种否定表达：
> `не име́ет за́паха`（没有气味）**=** `без за́паха`（无气味）。
> ★ 这个「=」很重要：同一个意思两种句式，作文时换着用。

**Таблица 10：`ЧТО де́лится на ЧТО`**

| Что? | На что?（В.п.） |
|---|---|
| Вещества́ де́лятся на | просты́е и сло́жные |
| | органи́ческие и неоргани́ческие |
| | ядови́тые и неядови́тые |

> **横纵关系**：横排「总 + 分」，竖列三种分类标准。
> ★ 注意 `дели́ться на` 后面接**第四格**（不是第二格）。
> 三组分类可以叠用：`Вода́ — э́то просто́е и неоргани́ческое вещество́.`

## 八、练习与自测

### 8.1 资料原题（精选）

**Задание 3**（p6）：用 `-ическ-` 把名词变形容词。
- `фи́зика → ?` → **физи́ческий**
- `хи́мия → ?` → **хими́ческий**
- `биоло́гия → ?` → **биологи́ческий**

**Задание 4**（p6）：用 Таблица 2 组词组。
- `хими́ческий + элеме́нт` → **хими́ческий элеме́нт**
- `хими́ческая + нау́ка` → **хими́ческая нау́ка**
- `хими́ческое + вещество́` → **хими́ческое вещество́**

**Задание 9**（p13）：按模型完成句子。

> 模型：`Водоро́д — э́то хими́ческий элеме́нт. H — э́то его́ хими́ческий си́мвол.`
> （氢是化学元素。H 是它的化学符号。）

- `Кислоро́д — ... . O — ...` → **Кислоро́д — э́то хими́ческий элеме́нт. O — э́то его́ хими́ческий си́мвол.**
- `Желе́зо — ... . Fe — ...` → **Желе́зо — э́то хими́ческий элеме́нт. Fe — э́то его́ хими́ческий си́мвол.**

> ★ 模型分三种（资料 `а) б) в)`）：
> **а)** 元素 + 符号（阳性名词用 `его́`）
> **б)** 元素 + 符号（阴性名词用 `её`，如 `Сера — э́то хими́ческий элеме́нт. S — э́то её хими́ческий си́мвол.`）
> **в)** 元素 + 化学式（`O₂ — э́то его́ хими́ческая фо́рмула.`）

### 8.2 自测清单

合上资料，试着回答：

1. 「物质」「性质」「组成」「结构」四个词分别怎么说？
2. `-ость` 后缀造的是什么类型的名词？举三个例。
3. 气味的「刺鼻」和「呛人」分别用哪个形容词？区别在哪？
4. `просто́е вещество́` 的复数是什么？（两部分都要变）
5. 「什么颜色？」完整问法用第几格？回答也用第几格？
6. `H₂O` 怎么读？`Fe(OH)₃` 怎么读？
7. `Fe` 的符号名是什么？元素名是什么？为什么不一样？
8. `вещ-во`、`св-во`、`р-р` 三个缩写读什么？
9. `не име́ет` 后面接第几格？举例。
10. `дели́ться на` 后面接第几格？

> [!success]- 答案要点
> 1. вещество́ · сво́йство · соста́в · строе́ние
> 2. 抽象名词（「……的程度/状态」）：пло́тность（密度）、жи́дкость（液体）、раствори́мость（溶解度）
> 3. ре́зкий（刺鼻，只表强烈）／е́дкий（呛人，带腐蚀感）
> 4. просты́е вещества́
> 5. 都用 **第二格**：`Како́го цве́та?` / `Бе́лого цве́та.`
> 6. `H₂O` = аш-два-о（读字母）；`Fe(OH)₃` = фе́ррум-о-аш-три́жды（读拉丁名 + три́жды）
> 7. 符号名 **фе́ррум**（拉丁 Ferrum），元素名 **желе́зо**（俄语本土词）
> 8. вещество́ / сво́йство / раство́р（缩写只用于书写，读全称）
> 9. 第二格：`Вещество́ не име́ет за́паха.`
> 10. 第四格：`Вещества́ де́лятся на просты́е и сло́жные.`

## 九、小结

> **一页纸回顾本讲**

### 9.1 三个核心

| 核心 | 内容 |
|---|---|
| **词** | 12 个性质名词 + 9 个分类形容词 + 溶液两词 |
| **法** | 形容词必须跟名词**变性数**；词组变复数时**两部分都变** |
| **难** | 化学式**三级读法**（字母名 / 俄语名 / 拉丁名）+ `два́жды/три́жды` |

### 9.2 必须背下来的三张清单

**① 缩写（书写用，读全称）**
`вещ-во` = вещество́ · `св-во` = сво́йство · `р-р` = раство́р · `к-та` = кислота́

**② 反义对**
`просто́е # сло́жное` · `органи́ческое # неоргани́ческое` · `прия́тное # неприя́тное` · `сла́дкий # го́рький`

**③ 化学式读法的判断**
非金属 → 读字母名 · 普通金属 → 读俄语名 · 古老金属（Cu/Fe/Ag/Au/Hg/Pb/Sn）→ 读拉丁名

### 9.3 下一讲的衔接

第 2 讲（Занятие 2）回答「**化学研究什么**」，会引入：
- `спосо́бность`（能力）、`превраща́ться`（转化）、`различа́ть`（区分）
- 四类无机物：`окси́д`（氧化物）、`основа́ние`（碱）、`кислота́`（酸）、`соль`（盐）
- `а́том`（原子）、`моле́кула`（分子）

> 本讲学的「性质形容词」和「`-ость` 名词」在下一讲会大量复用。
