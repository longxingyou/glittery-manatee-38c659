## 一、概念链：七个 Занятие 的知识网络

### 1.1 主链

```
物质 вещество́
  │
  ├─ 有「性质」сво́йство
  │    ├─ 物理性质 физи́ческое сво́йство（颜色、气味、密度、熔沸点…）
  │    └─ 化学性质 хими́ческое сво́йство（能转化成别的物质）
  │
  ├─ 有「组成」соста́в
  │    ├─ 质的组成 ка́чественный соста́в（有哪些元素）
  │    └─ 量的组成 коли́чественный соста́в（各有多少原子）
  │
  ├─ 有「结构」строе́ние
  │    └─ 分子 моле́кула → 原子 а́том → 电子 электро́н
  │
  ├─ 能「分类」
  │    ├─ 单质 просто́е ↔ 化合物 сло́жное
  │    ├─ 有机 органи́ческое ↔ 无机 неоргани́ческое
  │    ├─ 无机四类：окси́д · основа́ние · кислота́ · соль
  │    └─ 高分子 ВМС：мономе́р → полиме́р / сополи́мер（термопла́ст / реактопла́ст）
  │
  ├─ 能「成型加工」
  │    ├─ 物理三态：стеклообра́зное / высокоэласти́ческое / вязкотеку́чее（Tст, Tпл, Tдестр）
  │    ├─ 流变指标：ПТР（MFR）· уса́дка · вя́зкость
  │    └─ 成型工艺：экстру́зия · литьё под давле́нием · вы́дувное формова́ние · каландри́рование · прессова́ние
  │
  ├─ 能「变化」→ 化学反应 хими́ческая реа́кция
  │    ├─ 反应物 исхо́дные вещества́ (реаге́нты)
  │    ├─ 生成物 проду́кты реа́кции
  │    └─ 化学方程式 хими́ческое уравне́ние
  │
  └─ 能「计量」
       ├─ 相对原子质量 Ar
       ├─ 相对分子质量 Mr
       ├─ 物质的量 n（моль）
       └─ 摩尔质量 M（г/моль）
```

### 1.2 三阶段

| 阶段 | 讲次 | 核心问题 | 关键词 |
|---|---|---|---|
| **定性·是什么** | 1–4 | 物质是什么、由什么构成 | вещество́ · соста́в · строе́ние |
| **变化·怎么变** | 5 | 物质怎么变成别的物质 | реа́кция · уравне́ние |
| **定量·多少** | 6–7 | 有多少、有多重 | ма́сса · моль |

## 二、句式总表（★最实用的一节）

> ★★ **化学课文是科技文体，句式重复率极高**。
> 把下面这些句式背成条件反射，阅读速度能快一倍以上。

### 2.1 下定义（4 个句式）

| № | 句式 | 中文 | 例 |
|---|---|---|---|
| 1 | **X — э́то Y** | X 是 Y | `Моль — э́то коли́чество вещества́.` |
| 2 | **X называ́ется Y-ом** | X 被称为 Y | `…называ́ется хими́ческой реа́кцией.` |
| 3 | **X — э́то отноше́ние A к B** | X 是 A 与 B 的比值 | `Ar — э́то отноше́ние ма́ссы а́тома к 1/12 …` |
| 4 | **X, кото́рый Y, называ́ется Z** | 具有 Y 性质的 X 叫 Z | `Вещества́, кото́рые вступа́ют в реа́кцию, называ́ются …` |

### 2.2 描述组成（3 个句式）

| № | 句式 | 中文 | 格 |
|---|---|---|---|
| 1 | **X состоя́ит из Y** | X 由 Y 组成 | из + **第二格** |
| 2 | **Y вхо́дит в соста́в X** | Y 是 X 的组成部分 | в соста́в + **第二格** |
| 3 | **X содержи́т Y** | X 含有 Y | **第四格** |

> ★★ **这三句说的是同一件事，主宾关系不同**（第 4 讲详讲）：
> ```
> состоя́ть из     ：整体 → 由 → 部分
> входи́ть в соста́в：部分 → 属于 → 整体
> содержа́ть        ：整体 → 含有 → 部分（常带数量）
> ```

### 2.3 描述反应（4 个句式）

| № | 句式 | 中文 | 格 |
|---|---|---|---|
| 1 | **X реаги́рует с Y** | X 与 Y 反应 | с + **第五格** |
| 2 | **X образу́ет Y** | X 生成 Y | **第四格**（及物） |
| 3 | **Образу́ется Y** | 生成了 Y | 主语是被生成物（不及物） |
| 4 | **Образу́ется в результа́те X** | 由 X 反应生成 | в результа́те + **第二格** |

### 2.4 描述条件（2 个句式）

| № | 句式 | 中文 | 格 |
|---|---|---|---|
| 1 | **при X** | 在 X 条件下 | **第六格** |
| 2 | **при температу́ре X** | 在 X 温度下 | **第六格** |

### 2.5 描述依据（1 个句式）

| № | 句式 | 中文 | 格 |
|---|---|---|---|
| 1 | **X различа́ется по Y** | X 按 Y 区分 | по + **第三格** |

### 2.6 描述数量（4 个句式）

| № | 句式 | 中文 |
|---|---|---|
| 1 | **ЧТО пока́зывает ЧТО** | 某物说明某物 |
| 2 | **X во сто́лько-то раз бо́льше, чем Y** | X 是 Y 的几倍 |
| 3 | **X во сто́лько-то раз бо́льше Y（第二格）** | 同上（第二格版） |
| 4 | **X чи́сленно равна́ Y** | X 数值上等于 Y |

### 2.7 五个「必须条件反射」的搭配

> ★★★ 看到左边的词，立刻想到右边的格：

| 看到 | 想到 | 含义 |
|---|---|---|
| **из** | **第二格** | 由……（组成/做成） |
| **с** | **第五格** | 与……（反应/化合） |
| **по** | **第三格** | 按……（区分/分类） |
| **при** | **第六格** | 在……（条件/温度） |
| **называ́ется** | **第五格** | 被称为…… |

## 三、四类无机物参照表（★核心知识）

| 类型 | 俄语 | 通式 | 例 | 中文名 |
|---|---|---|---|---|
| 氧化物 | **окси́д** | ЭлₓOᵧ | CO₂ · CaO · SO₂ | 二氧化碳、氧化钙、二氧化硫 |
| 碱 | **основа́ние** | Ме(OH)ₙ | NaOH · Ca(OH)₂ | 氢氧化钠、氢氧化钙 |
| 酸 | **кислота́** | HₙКисл | H₂SO₄ · HCl · HNO₃ | 硫酸、盐酸、硝酸 |
| 盐 | **соль** | МеₓКислᵧ | NaCl · CaCO₃ · CuSO₄ | 氯化钠、碳酸钙、硫酸铜 |

### 3.1 命名规律（★能自己造词）

| 类型 | 构词模板 | 例 |
|---|---|---|
| 氧化物 | **окси́д + 元素第二格** | окси́д се́ры（硫的氧化物）、окси́д ка́льция（氧化钙） |
| 碱 | **гидро́ксид + 元素第二格** | гидро́ксид на́трия（氢氧化钠）、гидро́ксид ка́льция（氢氧化钙） |
| 含氧酸 | **-ная / -ая кислота́** | се́рная кислота́（硫酸）、азо́тная кислота́（硝酸）、фо́сфорная кислота́（磷酸） |
| 无氧酸 | **-истая / -оводоро́дная** | соляна́я кислота́（盐酸） |
| 盐 | **-ид / -ат + 元素第二格** | хлори́д на́трия（氯化钠）、карбона́т ка́льция（碳酸钙） |

> ★★ **掌握这五个模板，就能造出大部分无机物的俄语名**。
> 遇到没见过的物质名，先拆成「类型词 + 元素第二格」再理解。

### 3.2 酸的命名四规则（★据 РХТУ 教材补，详见第 30 篇 §5.4）

> ★★★ **俄语酸的命名有严格系统，这是「见名知价」的关键**。

#### 规则 1：按价态选 `-ная` / `-истая`

| 价态 | 词尾 | 例 |
|---|---|---|
| **高价** | **-ная / -овая** | H₂S⁺⁶O₄ **се́рная** кислота́（硫酸） |
| **低价** | **-истая** | H₂S⁺⁴O₃ **се́рнистая** кислота́（亚硫酸） |
| 高价 | -ная | HNO₃⁺⁵ **азо́тная** кислота́（硝酸） |
| 低价 | -истая | HNO₂⁺³ **азо́тистая** кислота́（亚硝酸） |

> ★ **中文的「酸 / 亚酸」正好对应俄语的 `-ная` / `-истая`**：
> 硫酸 се́рная / 亚硫酸 се́рнистая、硝酸 азо́тная / 亚硝酸 азо́тистая。

#### 规则 2：按含水量选 `орто-` / `пиро-` / `мета-`

| 前缀 | 含水量 | 例（都是 P⁺⁵） |
|---|---|---|
| **орто-** | 最多 | H₃PO₄ **ортофо́сфорная** |
| **пиро-** | 中等 | H₄P₂O₇ **пирофо́сфорная** |
| **мета-** | 最少 | HPO₃ **метафо́сфорная** |

#### 规则 3：按含氧与否

| 类型 | 俄语 | 例 |
|---|---|---|
| 无氧酸 | бескислоро́дная кислота́ | HCl、HBr、H₂S |
| 含氧酸 | кислородсодержа́щая кислота́ | HNO₃、H₂SO₄ |

#### 规则 4：按可电离氢数（元数）

| 元数 | 俄语 | 例 |
|---|---|---|
| 一元 | одноосно́вная | HCl、HNO₃ |
| 二元 | двухосно́вная | H₂SO₄、H₂CO₃ |
| 三元 | трёхосно́вная | H₃PO₄ |

### 3.3 盐的命名对照（★由酸名派生）

| 酸名 | 盐类名 | 例 |
|---|---|---|
| H₂SO₄ **се́рная** | **сульфа́т** | Na₂SO₄ сульфа́т на́трия |
| H₂SO₃ **се́рнистая** | **сульфи́т** | Na₂SO₃ сульфи́т на́трия |
| H₂CO₃ **у́гольная** | **карбона́т** | CaCO₃ карбона́т ка́льция |
| HNO₃ **азо́тная** | **нитра́т** | KNO₃ нитра́т ка́лия |
| HNO₂ **азо́тистая** | **нитри́т** | KNO₂ нитри́т ка́лия |
| H₃PO₄ **фо́сфорная** | **фосфа́т** | Ca₃(PO₄)₂ фосфа́т ка́льция |
| HCl **соляна́я** | **хлори́д** | NaCl хлори́д на́трия |
| H₂S **сероводоро́дная** | **сульфи́д** | Na₂S сульфи́д на́трия |

> ★★ **三条派生规律**：
> ```
> -ная 酸 → -ат 盐（сульфат · карбонат · нитрат · фосфат）
> -истая 酸 → -ит 盐（сульфит · нитрит）
> 无氧酸 → -ид 盐（хлорид · сульфид · бромид · иодид）
> ```
> **记住这三条，大部分盐名都能自己造。**

### 3.4 酸酐（ангидри́д）与碱的俗名

**酸酐 = 对应酸去掉水**：

| 酸 | 酸酐（окси́д） |
|---|---|
| H₂SO₄ | SO₃（серный ангидрид） |
| H₂SO₃ | SO₂（сернистый ангидрид） |
| H₂CO₃ | CO₂ |
| H₂SiO₃ | SiO₂ |

> ★ **词源**：`ан-`（否定）+ `гидро-`（水）+ `-ид` = 「**失去水的**」。

**碱的俗名（教材要求记）**：

| 化学式 | 俄语俗名 | 中文 |
|---|---|---|
| **NaOH** | **е́дкий натр** | 烧碱 |
| **KOH** | **е́дкое ка́ли** | 苛性钾 |
| **Ca(OH)₂** | **гашёная и́звесть** | 熟石灰 |

### 3.5 三种氧化物（★讲义 02 未细分）

| 类型 | 俄语 | 对应 | 例 |
|---|---|---|---|
| 碱性 | основно́й окси́д | 碱 | Na₂O → NaOH |
| 酸性 | кисло́тный окси́д | 酸 | SO₃ → H₂SO₄ |
| 两性 | амфоте́рный окси́д | 既碱又酸 | ZnO、Al₂O₃、Cr₂O₃ |

## 三之二、化学计算三公式与四大常数（★据 РХТУ 教材补）

### 3b.1 一个公式统三种计算

```
        m      N      V
   n = —— = —— = ——
        M     N_A    V_m
```

| 符号 | 含义 | 单位 |
|---|---|---|
| **n** | коли́чество вещества́（物质的量） | моль |
| **m** | ма́сса（质量） | г |
| **M** | моля́рная ма́сса（摩尔质量） | г/моль |
| **N** | число́ части́ц（粒子数） | — |
| **N_A** | число́ Авога́дро（阿伏伽德罗常数） | 6,02×10²³ моль⁻¹ |
| **V** | объём（体积） | л |
| **V_m** | моля́рный объём（摩尔体积） | **22,4 л/моль** |

### 3b.2 四个必背常数

| 常数 | 值 | 俄语 |
|---|---|---|
| **N_A** | 6,02×10²³ моль⁻¹ | число́ Авога́дро |
| **V_m** | 22,4 л/моль（н.у.） | моля́рный объём |
| **н.у.** 的温度 | 273 К = 0°С | температу́ра |
| **н.у.** 的压强 | 101325 Па = 760 мм рт.ст. | давле́ние |

> ★ `н.у.` = норма́льные усло́вия（标准状况）。

### 3b.3 五条基本定律

| 定律 | 俄语 | 提出者 |
|---|---|---|
| 质量守恒 | зако́н сохране́ния ма́ссы | **Ломоно́сов** |
| 定组成 | зако́н постоя́нства соста́ва | **Пруст** |
| 倍比 | зако́н кра́тных отноше́ний | — |
| 气体体积比 | зако́н кра́тных объёмных отноше́ний | **Гей-Люсса́к** |
| 阿伏伽德罗 | зако́н Авога́дро | **Авога́дро** |

## 三之三、化学反应四类型与氧化还原（★据 РХТУ 教材补）

### 3c.1 四种基本反应

| 类型 | 俄语 | 通式 | 例 |
|---|---|---|---|
| 化合 | реа́кция соедине́ния | A + B → AB | 2H₂ + O₂ = 2H₂O |
| 分解 | реа́кция разложе́ния | AB → A + B | 2KClO₃ = 2KCl + 3O₂ |
| 置换 | реа́кция замеще́ния | A + BC → AC + B | Fe + CuSO₄ = FeSO₄ + Cu |
| 复分解 | реа́кция обме́на | AB + CD → AD + CB | NaOH + HCl = NaCl + H₂O |

### 3c.2 氧化还原核心术语

| 俄语 | 中文 | 定义 |
|---|---|---|
| **окисле́ние** | 氧化 | **失**电子（价升高） |
| **восстановле́ние** | 还原 | **得**电子（价降低） |
| **окисли́тель** | 氧化剂 | 得电子（自身被还原） |
| **восстанови́тель** | 还原剂 | 失电子（自身被氧化） |
| **сте́пень окисле́ния** | 氧化态 | — |

### 3c.3 三种价态的氧化还原能力（★最实用规律）

| 价态 | 能做什么 | 例 |
|---|---|---|
| **最高价** | **只能做氧化剂** | Mn⁺⁷（KMnO₄）、N⁺⁵（HNO₃） |
| **最低价** | **只能做还原剂** | N⁻³（NH₃）、S⁻²（H₂S） |
| **中间价** | **既氧化又还原** | N⁺³（HNO₂）、S⁺⁴（SO₂） |

### 3c.4 氧化态的三条判定

| # | 规则 |
|---|---|
| 1 | 单质中氧化态 = **0** |
| 2 | 金属在化合物中**只有正价** |
| 3 | 最高价 = **族号**；最低价 = **族号 − 8**（非金属） |

## 三之四、化学动力学与平衡（★讲义原无，据 РХТУ 教材补）

### 3d.1 反应速率的四因素

| 因素 | 影响 | 俄语要点 |
|---|---|---|
| **浓度** | 增大 → 速率增大 | зако́н де́йствия масс |
| **温度** | 每升 10°C 速率 **2–4 倍** | **пра́вило Вант-Го́ффа** |
| **催化剂** | 大幅增大 | катализа́тор |
| **压强**（气体） | 增大 → 速率增大 | давле́ние |

> ★ **速率方程只写气态和液态**：
> `В кинети́ческое уравне́ние впи́сываются вещества́ в жи́дкой и газообра́зной фа́зах.`
> （固体**不进**速率方程。）

### 3d.2 勒夏特列原理（★平衡核心）

> **При́нцип Ле Шателье́-Бра́уна**：
> 改变平衡系统的条件，平衡向**对抗该改变**的方向移动。

| 改变 | 平衡移动 |
|---|---|
| **增大压强** | 向**气体体积减小**的方向 |
| **升高温度** | 向**吸热**方向（эндотерми́ческая） |
| **增大反应物浓度** | 向**正反应**方向 |

| 术语 | 俄语 |
|---|---|
| 可逆反应 | обрати́мая реа́кция |
| 化学平衡 | хими́ческое равнове́сие |
| 平衡常数 | конста́нта равнове́сия (K) |
| 吸热 | эндотерми́ческий |
| 放热 | экзотерми́ческий |

## 四、化学式读法总表（★全书最难的一关）

> 详见 **00a 预备篇**。这里给速查版。

### 4.1 三级读法

| 级别 | 适用 | 例 |
|---|---|---|
| **一级：读字母名** | 非金属 | H = аш · O = о · C = цэ · N = эн · S = эс · P = пэ |
| **二级：读俄语元素名** | 普通金属 | Na = на́трий · K = ка́лий · Ca = ка́льций · Mg = ма́гний |
| **三级：读拉丁元素名** | 古老金属 | Ag = арге́нтум · Au = ау́рум · Cu = ку́прум · Fe = фе́ррум · Hg = гидра́ргирум · Pb = плю́мбум · Sn = ста́ннум |
