## 一、本讲概览与知识定位

高分子化合物（ВМС）不同于低分子物，其核心特征在于**分子量巨大**（通常 $10^4 \sim 10^6\ \text{g/mol}$）且由大量重复的**链节（элемента́рные звенья）**组成。
本讲将系统梳理三层递进知识链：

```
有机官能团与典型单体（мономе́ры）
  │   （烷烃、烯烃、二烯烃、芳烃、极性单体）
  ↓
聚合反应两大反应类型（синтез полиме́ров）
  │   （加成聚合 полимериза́ция vs 逐步缩聚 поликонденса́ция）
  ↓
大分子链结构与分子量多分散性（строе́ние и ММР）
      （均聚/共聚、线型/支化/网状、数均/重均分子量）
```

## 三、高分子合成反应两大基石（Полимериза́ция и поликонденса́ция）

高分子合成反应按反应机理分为两大基本类别：**加成聚合（полимериза́ция）**与**缩合聚合（поликонденса́ция）**。

### 3.1 加聚反应（Полимериза́ция）

加聚反应是含有不饱和重键（双键、三键）或环状结构的单体相互加成，生成高分子化合物而不析出低分子副产物的反应。

$$n\,\text{M} \longrightarrow -(-\text{M}-)_n-$$

**特征（При́знаки）**：
1. **Соста́в**: Элемента́рный соста́в полиме́ра соотве́тствует соста́ву мономе́ра（聚合物的元素组成与单体一致）。
2. **Побо́чные проду́кты**: Реакция протека́ет без выделе́ния побо́чных низкомолекуля́рных веще́ств（反应不析出低分子副产物）。
3. **Цепно́й механи́зм**: По механи́зму э́то цепна́я реа́кция（机理上属于链式反应）。

#### 链式聚合的三大基元阶段（Элемента́рные ста́дии цепно́й полимериза́ции）

1. **Иниции́рование（链引发）**：
   产生自由基（радика́лы）或离子（ио́ны），与单体反应生成链引发活性中心。
   * **Инициа́тор**（引发剂）：如过氧化苯甲酰（перокси́д бензои́ла）、偶氮二异丁腈（ДАК / порофо́р）。
   $$\text{I} \xrightarrow{k_d} 2\text{R}^\bullet,\quad \text{R}^\bullet + \text{M} \xrightarrow{k_i} \text{R}-\text{M}^\bullet$$
2. **Рост цепи́（链增长）**：
   活性中心迅速与大量单体分子连续加成：
   $$\text{R}-\text{M}^\bullet + \text{M} \xrightarrow{k_p} \text{R}-\text{M}-\text{M}^\bullet \longrightarrow \text{R}-(\text{M})_n^\bullet$$
3. **Обры́в цепи́（链终止）**：
   活性中心失活，失去继续加成单体的能力。
   * Рекомбина́ция（复合终止）：两个活性自由基相互碰撞结合。
   * Диспропорциони́рование（歧化终止）：自由基之间发生氢原子转移。
4. **Переда́ча цепи́（链转移）**：
   活性中心转移给单体、溶剂、引发剂或大分子自身，形成新的自由基，可能引发支化（разветвле́ние）。

#### 聚合反应的活性中心分类

* **Радика́льная полимериза́ция（自由基聚合）**：最通用的工业方法（高压聚乙烯 LDPE、聚苯乙烯 PS、聚氯乙烯 PVC）。
* **Ио́нная полимериза́ция（离子聚合）**：
  * **Катио́нная полимериза́ция（阳离子聚合）**：以路易斯酸（кисло́ты Лью́иса，如 $\text{AlCl}_3, \text{BF}_3$）为催化剂（如丁基橡胶的合成）。
  * **Анио́нная полимериза́ция（阴离子聚合）**：以强碱或有机金属（如丁基锂 бутилли́тий）为引发剂，可实现“活加聚”（жива́я полимериза́ция）。
* **Координацио́нная полимериза́ция（配位聚合）**：
  使用齐格勒-纳塔催化剂（катализа́торы Ци́глера — На́тта，如 $\text{TiCl}_4 + \text{Al}(\text{C}_2\text{H}_5)_3$），实现定向立体规整聚合（стереорегуля́рная полимериза́ция，如等规聚丙烯 PP、低压高密度聚乙烯 HDPE）。

---

### 3.2 缩聚反应（Поликонденса́ция）

缩聚反应是含有两个或两个以上反应性官能团的单体分子之间相互作用，缩合成高分子链，同时**析出低分子副产物**（如水 $\text{H}_2\text{O}$、氯化氢 $\text{HCl}$、氨 $\text{NH}_3$、醇 $\text{ROH}$）的反应。

$$n\,\text{a}-\text{A}-\text{a} + n\,\text{b}-\text{B}-\text{b} \longrightarrow \text{a}-(-\text{A}-\text{B}-)_n-\text{b} + (2n-1)\,\text{ab}$$

**特征（При́знаки）**：
1. **Побо́чный проду́кт**: Всегда́ выделя́ется низкомолекуля́рное вещество́（总是析出低分子副产物）。
2. **Ступенча́тый механи́зм**: Реакция протека́ет ступенча́то（逐步机理），中间体可在任意阶段分离。
3. **Равнове́сный хара́ктер**: Мно́гие реа́кции обрати́мы（平衡可逆性），必须及时移除低分子副产物以提高分子量。

#### 工业缩聚经典实例

1. **Полиэтилентерефтала́т (ПЭТФ / PET)**：
   对苯二甲酸与乙二醇缩聚，副产物为水：
   $$n\,\text{HOOC}-\text{C}_6\text{H}_4-\text{COOH} + n\,\text{HO}-\text{CH}_2\text{CH}_2-\text{OH} \longrightarrow \text{H}-(-\text{O}-\text{CH}_2\text{CH}_2\text{O}-\text{CO}-\text{C}_6\text{H}_4\text{CO}-)_n-\text{OH} + (2n-1)\,\text{H}_2\text{O}$$
2. **Полиами́д-6,6 (ПА-6,6 / PA-66)**：
   己二酸与己二胺缩聚：
   $$n\,\text{HOOC}-(\text{CH}_2)_4-\text{COOH} + n\,\text{H}_2\text{N}-(\text{CH}_2)_6-\text{NH}_2 \longrightarrow -(-\text{NH}-(\text{CH}_2)_6-\text{NH}-\text{CO}-(\text{CH}_2)_4-\text{CO}-)_n- + 2n\,\text{H}_2\text{O}$$

## 四、大分子链的结构与形态（Строе́ние макромоле́кул）

### 4.1 几何构型（Геометри́ческая фо́рма цепи́）

高分子链按空间几何形状分为三类：

```
1. Лине́йные полиме́ры (线型高分子):
   ●───●───●───●───●───●───●───●   (热塑性、溶胀溶解、流动性好)

2. Разветвлённые полиме́ры (支化高分子):
   ●───●───●───●───●───●───●───●
           │           │
           ●───●       ●───●───●   (结晶度下降、熔体粘度特性改变)

3. Се́тчатые / сши́тые полиме́ры (网状/交联高分子):
   ●───●───●───●───●───●───●
   │       │           │
   ●───●───●───●───●───●───●
   │           │       │
   ●───●───●───●───●───●───●   (热固性、不溶不熔、高模量耐热)
```

* **Лине́йная цепь（线型链）**：聚乙烯（HDPE）、聚苯乙烯（PS）、聚酰胺。易溶解、受热熔融（термопла́сты）。
* **Разветвлённая цепь（支化链）**：低密度聚乙烯（LDPE）。侧链阻碍紧密堆积，密度和结晶度相对较低。
* **Сши́тая / се́тчатая структу́ра（交联/三维网络结构）**：硫化橡胶（рези́на）、环氧树脂（эпокси́дная смола́）、酚醛树脂（фенолоформальдеги́дная смола́）。不溶不熔（реактопла́сты）。

### 4.2 均聚物与共聚物（Гомополиме́ры и сополиме́ры）

根据大分子链中链节的种类分类：
* **Гомополиме́р（均聚物）**：仅由一种单体单元构成（`-A-A-A-A-A-`）。
* **Сополи́мер（共聚物）**：由两种或两种以上不同单体单元共聚而成：
  1. **Статисти́ческий сополи́мер（无规共聚物）**：`-A-B-B-A-B-A-A-B-`
  2. **Череду́ющийся сополи́мер（交替共聚物）**：`-A-B-A-B-A-B-A-B-`
  3. **Блок-сополи́мер（嵌段共聚物）**：`-A-A-A-A-B-B-B-B-`（如 SBS 热塑性弹性体）
  4. **Привито́й сополи́мер（接枝共聚物）**：主链为 A，侧链接枝 B（如高抗冲聚苯乙烯 HIPS、ABS 树脂）。

## 五、聚合物的分子量及其多分散性（Молекуля́рная ма́сса и полидиспе́рсность）

### 5.1 分子量的不均一性

低分子化合物具有严格确定的相对分子质量，而高分子化合物是由一系列聚合度不同的同系大分子组成的混合物，具有**多分散性（полидиспе́рсность / моле́кулярно-ма́ссовое распределе́ние, ММР）**。

因此，高分子的分子量只能用**统计平均值**来表征：

### 5.2 平均分子量计算公式（Сре́дние молекуля́рные ма́ссы）

1. **Среднечислова́я молекуля́рная ма́сса（数均分子量 $\overline{M}_n$）**：
   按分子数目统计的平均值，常通过渗透压法（осмометри́я）或端基分析法测定：
   $$\overline{M}_n = \frac{\sum N_i M_i}{\sum N_i} = \sum n_i M_i$$
2. **Среднема́ссовая молекуля́рная ма́сса（重均分子量 $\overline{M}_w$）**：
   按分子质量份额统计的平均值，常通过静态光散射法（светорассе́яние）测定：
   $$\overline{M}_w = \frac{\sum m_i M_i}{\sum m_i} = \frac{\sum N_i M_i^2}{\sum N_i M_i}$$
3. **Коэффицие́нт полидиспе́рсности（多分散系数 $Đ$ / $K_d$）**：
   衡量分子量分布宽窄的指标：
   $$Đ = \frac{\overline{M}_w}{\overline{M}_n} \ge 1$$
   * 若 $Đ = 1$：单分散体系（монодиспе́рсная систе́ма，如天然蛋白质）。
   * 工业合成聚合物：通常 $Đ = 1.5 \sim 5$（加聚产物）甚至大于 $10$（宽分布聚烯烃）。
   * **工程意义**：宽分布（высо́кая полидиспе́рсность）有利于改善熔体加工流动性，而窄分布有利于提升制品的力学韧性与均匀度。

## 七、核心句式与科技文表达（Нау́чные и техни́ческие выраже́ния）

### 7.1 描述合成反应与机理

* `Полимериза́ция протека́ет по цепно́му радика́льному механи́зму.`
  聚合反应按自由基链式机理进行。
* `В результа́те поликонденса́ции выделя́ется низкомолекуля́рный побо́чный проду́кт — вода́.`
  在缩聚反应中析出低分子副产物——水。
* `Для иниции́рования реа́кции вво́дят перокси́дные инициа́торы.`
  为引发反应，加入过氧化物引发剂。
* `Катализа́торы Ци́глера — На́тта позволя́ют получа́ть стереорегуля́рные полиме́ры.`
  齐格勒-纳塔催化剂能够合成立体规整聚合物。

### 7.2 描述结构与分子量

* `С ро́стом сте́пени полимериза́ции возраста́ет моля́рная ма́сса и вязкопласти́ческие сво́йства.`
  随着聚合度的提高，摩尔质量和粘弹性随之增大。
* `Молекуля́рно-ма́ссовое распределе́ние ока́зывает суще́ственное влия́ние на перераба́тываемость распла́ва.`
  分子量分布对熔体的可加工性具有重要影响。
* `Лине́йный полиэтиле́н облада́ет бо́лее высо́кой сте́пенью кристалли́чности по сравне́нию с разветвлённым.`
  与支化聚乙烯相比，线型聚乙烯具有更高的结晶度。

## 八、专业构词规律与词形辨析（Словообразова́ние）

### 8.1 词缀衍生规律

1. **`со-`（表共同、协同，相当于 co-）**：
   * `полимер` $\to$ **сополи́мер**（共聚物）
   * `полимеризация` $\to$ **сополимериза́ция**（共聚反应）
   * `экструзия` $\to$ **соэкстру́зия**（共挤出）
2. **`-иза́ция`（表动作、过程抽象名词，相当于 -ization）**：
   * `полимер` $\to$ **полимериза́ция**（聚合反应）
   * `вулканизировать` $\to$ **вулканиза́ция**（硫化反应）
   * `пластифицировать` $\to$ **пластифика́ция**（塑化、增塑）
   * `деструкция` $\to$ **деструктуриза́ция** / **дестру́кция**（降解破坏）
3. **`-пласт`（表塑料材料，来自 греч. plastos）**：
   * **термопла́ст**（热塑性塑料）
   * **реактопла́ст**（热固性塑料）
   * **фторопла́ст**（氟塑料）
   * **пенопла́ст**（泡沫塑料）

### 8.2 易混术语精准辨析

> [!warning] каучу́к vs рези́на
> * **Каучу́к**（生胶）：尚未硫化的弹性高分子聚合物生胶原料，受热发生塑性流动，具有一定溶解性。
> * **Рези́на**（硫化胶 / 熟橡胶）：生胶经**硫化（вулканиза́ция）**后形成的具有三维交联网络结构的弹性材料，不溶不熔，具备高回弹性与抗撕裂性。

> [!warning] термопла́ст vs реактопла́ст
> * **Термопла́ст**（热塑性塑料）：加热软化熔融、冷却硬化定型，该物理过程可多次重复（обрати́мый проце́сс），边角料可回收再造粒。
> * **Реактопла́ст**（热固性塑料）：初次加热固化成型过程中发生不可逆化学交联（необрати́мый проце́сс отвержде́ния），再次加热不再熔融，继续升温直接炭化分解。

## 九、自测与习题（Упражне́ния）

### 9.1 概念自测判断

1. Моле́кулы мономе́ра всегда́ содержа́т кра́тные свя́зи и́ли функциона́льные гру́ппы. （Да / Нет）
2. При полимериза́ции обяза́тельно выделя́ются побо́чные низкомолекуля́рные веще́ства. （Да / Нет）
3. Лине́йные полиме́ры отно́сятся к термопла́стам. （Да / Нет）
4. Коэффицие́нт полидиспе́рсности мо́жет быть ме́ньше едини́цы. （Да / Нет）

> [!success]- 点击展开核对答案
> 1. **Да**（单体必须具备双键、三键、开环能力或至少两个反应性官能团方可聚合）。
> 2. **Нет**（加聚反应不析出副产物；析出副产物的是缩聚反应 поликонденсация）。
> 3. **Да**（线型聚合物分子间非共价结合，加热可熔融流动，属于热塑性塑料）。
> 4. **Нет**（$Đ = \overline{M}_w / \overline{M}_n \ge 1$ 恒成立，单分散极限值为 1）。

### 9.2 翻译与句式填空

用括号内单词的正确语法形式补全科技例句：
1. Молекуля́рная ма́сса полиэтиле́на зави́сит от (сте́пень) полимериза́ции.
2. Стиро́л превраща́ется в полистиро́л в результа́те (радика́льная полимериза́ция).
3. При поликонденса́ции дикарбо́новых кисло́т с диами́нами образу́ются (полиами́ды) и вода́.

> [!success]- 点击展开核对答案
> 1. `сте́пени`（第二格：зави́сеть от чего́?）
> 2. `радика́льной полимериза́ции`（第二格：в результа́те чего́?）
> 3. `полиами́ды`（第一格复数：что образу́ется?）
