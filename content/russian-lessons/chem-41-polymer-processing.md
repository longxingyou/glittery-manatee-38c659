## 一、本讲概览与聚合物加工全局图景

聚合物加工是将高分子聚合物（树脂或生胶原料）通过加热塑化、成型受力流动并冷却固化（或化学交联），制成具有特定几何形状与物理机械性能制品的工程技术。

```
聚合物物理状态与流变特性（Фи́зика и реоло́гия）
  │   （玻璃态/高弹态/粘流态 · 转变温度 · 剪切变稀 · 熔融指数 ПТР）
  ↓
配方系统与改性助剂（Рецептурострое́ние и доба́вки）
  │   （基体 + 增塑剂 + 稳定剂 + 填料 + 阻燃剂 + 色母粒）
  ↓
五大成型加工工艺与工业装备（Спо́собы перерабо́тки и обору́дование）
  │   ├── 1. 挤出成型 (Экстру́зия) —— 单/双螺杆、机头、管材/异型材/薄膜
  │   ├── 2. 注塑成型 (Литьё под давле́нием) —— ТПА、模具系统、成型周期、缺陷排除
  │   ├── 3. 吹塑成型 (Вы́дувное формова́ние) —— 中空吹塑、瓶体与容器
  │   ├── 4. 压延成型 (Каландри́рование) —— 辊筒系统、胶片与人造革
  │   └── 5. 模压成型 (Прессова́ние) —— 热固性塑料与橡胶硫化
  ↓
回收再利用与循环工程（Реци́клинг и грануля́ция）
```

## 二、聚合物的物理力学状态与热转变（Физи́ческие состоя́ния и перехо́ды）

线型无定形高分子在不同温度区段表现出三种不同的力学物理状态，这是聚合物成型加工的理论基石。

### 2.1 三大力学状态与特征转变温度

```
形变量 ε (Деформация)
  ▲
  │                       高弹态
  │                 ┌───────────────┐
  │                 │ Высоко-       │     粘流态 (加工窗口)
  │                 │ эластическое  │  Вязкотекучее
  │   玻璃态        │ состояние     │  состояние
  │  Стекло-        │               │       ╱
  │  образное       │               │      ╱
  │  состояние      │               │     ╱
  │   ──────┐       │               │    ╱
  │         └───────┘               └───╱
──┴─────────┬───────────────────────┬───────────────► 温度 T
           Tст (Tg)                Tт (Tf)         Tдестр (Td)
      температура             температура     температура
      стеклования              текучести       деструкции
```

| 物理状态（俄文） | 状态特征 | 分子运动机理 | 工程应用与意义 |
|---|---|---|---|
| **Стеклообра́зное состоя́ние**<br>（玻璃态） | 坚硬、刚性、形变量极小（$\varepsilon \sim 1\text{–}3\%$） | 只有振动运动，主链与链段均被“冻结” | 塑料制品的常规使用温度区间（低于 $T_{ст}$） |
| **Высокоэласти́ческое состоя́ние**<br>（高弹态） | 模量低、可逆形变量极大（$\varepsilon$ 可达数百 %） | 链段（сегме́нты）获得热运动能力，但整链不发生质心位移 | 橡胶与弹性体的工作使用状态 |
| **Вязкотеку́чее состоя́ние**<br>（粘流态 / 熔融流动态） | 产生不可逆塑性流动变形 | 链段运动剧烈，整条大分子链质心发生宏观滑动位移 | **聚合物成型加工的工作区间**（$T_т < T < T_{дестр}$） |

### 2.2 关键温度判据（Крити́ческие температу́ры）

* **$T_{ст}$ (температу́ра стеклова́ния, $T_g$)**：玻璃化转变温度。聚合物由玻璃态转变为高弹态的临界温度。
* **$T_т$ (температу́ра теку́чести, $T_f$)**：粘流转变温度（针对非晶态聚合物）。聚合物转入粘流态流动的临界温度。
* **$T_{пл}$ (температу́ра плавле́ния, $T_m$)**：熔融温度（针对结晶聚合物，кристалли́ческие полиме́ры）。晶格瓦解为各向同性熔体的温度。
* **$T_{дестр}$ (температу́ра дестру́кции, $T_d$)**：热降解温度。大分子主链化学键热断裂分解的温度上限。

> [!important] 加工温度窗口（Температу́рный интерва́л перерабо́тки）
> 塑料的热加工温度必须严格控制在：
> $$T_т\ (\text{或 } T_{пл}) < T_{\text{переработки}} < T_{дестр}$$
> 若低于下限，物料不能充分熔融塑化，设备超负荷；若超过上限，物料发生热氧老化降解，制品变黄、脆化甚至炭化。

## 三、聚合物熔体流变学与加工性能（Реоло́гия распла́вов）

聚合物熔体属于典型的**非牛顿流体（неньюто́новские жи́дкости）**，其粘度随受力和流动条件剧烈变化。

### 3.1 剪切变稀现象（Псевдопласти́чность / сдви́говое утонче́ние）

聚合物熔体普遍表现为**假塑性流体（псевдопласти́чные распла́вы）**：
* 当剪切速率（ско́рость сдви́га $\dot{\gamma}$）或剪切应力（напряже́ние сдви́га $\tau$）增大时，大分子链沿流动方向高度取向（ориента́ция）并发生解缠结，导致**有效熔体粘度（эффекти́вная вя́зкость распла́ва $\eta$）显著降低**。
* **工程价值**：在注塑高压高速注入浇口时，熔体粘度骤降成千上万倍，极利于高速充模填充型腔。

### 3.2 熔体流动速率（Показа́тель теку́чести распла́ва · ПТР）

**ПТР (Melt Flow Rate, MFR)** 是工业生产和质量检验中表征热塑性塑料加工流动性的最核心指标（依据 **ГОСТ 11645-2021** 及 ISO 1133）。

#### 物理定义
在规定温度和标称载荷下，聚合物熔体在 10 分钟内通过标准毛细管口模（内径 $d = 2.095\ \text{mm}$，长 $l = 8.00\ \text{mm}$）所挤出的质量（克数），单位为 **$г/10\ мин$**。

$$\text{ПТР} = \frac{600 \cdot m}{t}$$
* $m$ — 切割物料段的平均质量（$г$）
* $t$ — 切割时间间隔（$с$）
* $600$ — 换算系数（将秒换算为 10 分钟）

#### ПТР 与加工工艺选择导向

| ПТР 范围 ($г/10\ мин$) | 分子量水平 | 熔体强度 | 最适合的成型加工工艺 |
|---|---|---|---|
| **$0.1 \sim 0.8$**（超低流速） | 极高分子量 | 极高（抗熔垂） | **Экстру́зия труб**（管材挤出）、大中型吹塑容器 |
| **$0.8 \sim 2.5$**（低流速） | 高分子量 | 高 | **Экстру́зия плёнок**（吹塑薄膜）、异型材挤出 |
| **$2.5 \sim 15$**（中等流速） | 中等分子量 | 适中 | **Литьё под давле́нием**（常规注塑成型） |
| **$15 \sim 50+$**（高流速） | 较低分子量 | 低 | **Тонкосте́нное литьё**（薄壁注塑）、纺粘非织造布（спанбо́нд） |

### 3.3 成型收缩率（Уса́дка при формова́нии · $S$）

由于聚合物在冷却过程中体积收缩及结晶紧密堆积，成型制品的尺寸小于模具型腔尺寸：

$$S = \frac{L_{\text{формы}} - L_{\text{изделия}}}{L_{\text{формы}}} \cdot 100\%$$

* **Амо́рфные полиме́ры**（非晶态，如 PS, PC, PMMA）：收缩率极小，一般为 **$0.4\% \sim 0.8\%$**，尺寸稳定精密。
* **Кристалли́ческие полиме́ры**（半结晶态，如 PE, PP, PA）：因结晶致密化，收缩率大，通常为 **$1.5\% \sim 3.0\%$**，模具设计需预留足额补偿。

## 四、配方设计与功能助剂系统（Рецептурострое́ние и доба́вки）

纯树脂在工业上极少直接使用，必须配合多种助剂复合改性为**塑料工程混合物（полиме́рный компа́унд）**。

| 助剂大类（俄文） | 中文名称 | 作用机理与功能 | 常用典型代表（俄 / 汉） |
|---|---|---|---|
| **Пластифика́торы** | 增塑剂 | 插入大分子链间减弱范德华力，降低 $T_{ст}$ 和熔体粘度，大幅提高柔软性与延展性 | **Диоктилфтала́т (ДОФ)**（邻苯二甲酸二辛酯）<br>**Диоктиладипина́т (ДОА)**（己二酸二辛酯） |
| **Термостабилиза́торы** | 热稳定剂 | 捕获加工高温下脱除的活性分解自由基或酸性副产物（如捕获 PVC 释放的 $\text{HCl}$），抑制链降解 | **Стеара́т ка́льция**（硬脂酸钙）<br>**Стеара́т ци́нка**（硬脂酸锌）<br>**Оловооргани́ческие соедине́ния**（有机锡） |
| **Антиоксида́нты** | 抗氧剂 | 终结热氧老化链式自由基反应，防止大分子断链或氧化交联 | **Фено́льные антиоксида́нты**（受阻酚类，如 Ирганокс 1010）<br>**Фосфи́ты**（亚磷酸酯辅助抗氧剂） |
| **Светостабилиза́торы** | 光稳定剂 | 吸收紫外光高能辐射或捕获光生自由基，防止户外暴晒泛黄开裂 | **УФ-поглоти́тели**（紫外线吸收剂）<br>**ХАЛС (HALS)**（受阻胺类光稳定剂） |
| **Наполни́тели** | 填料 | 降低原材料成本，显著提高材料刚性、弯曲模量、耐热变形温度与尺寸稳定性 | **Мел (карбона́т ка́льция)**（重钙 / 轻钙）<br>**Тальк**（滑石粉）<br>**Стекловолокно́**（玻璃纤维）<br>**Са́жа / техни́ческий углеро́д**（碳黑） |
| **Антипире́ны** | 阻燃剂 | 吸热分解释放不燃气体或形成表面炭化隔离层，阻止火势蔓延燃烧 | **Гидрокси́д алюми́ния**（氢氧化铝）<br>**Гидрокси́д ма́гния**（氢氧化镁）<br>**Броми́рованные антипире́ны**（溴系阻燃剂） |
| **Сма́зки (лубрика́нты)** | 润滑剂 | 减少物料与螺杆/模腔金属表面的摩擦粘壁（外润滑），降低分子间内摩擦（内润滑） | **Полиэтиле́новый воск**（聚乙烯蜡）<br>**Стеари́новая кислота́**（硬脂酸） |
| **Суперконцентра́ты / Мастерба́тчи** | 色母粒 / 功能母粒 | 将高浓度颜料或助剂预分散于载体树脂中制成的颗粒料，计量添加均匀、无粉尘飞扬 | **Суперконцентра́т краси́теля**（彩色母粒）<br>**Бе́лый мастерба́тч ($\text{TiO}_2$)**（钛白母粒） |

## 五、核心成型加工工艺与工业装备（Спо́собы перерабо́тки）

### 5.1 挤出成型工艺（Экстру́зия）

挤出成型是聚合物加工中产量最高、应用最广的连续成型工艺，广泛用于管材、异型材、板片材、吹塑薄膜、电缆包覆及造粒。

#### 螺杆挤出机三大工作区段（Зо́ны шне́ка одношне́кового экстру́дера）

```
                     ┌────────── 压缩比 β = H1 / H3 ──────────┐
                     │                                         │
┌────────────────────┴──────────┬──────────────────────────────┴───────────────┬──────────────────────────────┐
│  Зо́на пита́ния (загру́зки)     │   Зо́на сжа́тия (пластика́ции)                  │   Зо́на дози́рования           │
│  加料段 (深槽输送固体颗粒)    │   压缩塑化段 (锥度渐变螺槽，固体受压熔融)    │   计量段 (浅槽均化定量泵送)  │
└───────────────────────────────┴───────────────────────────────────────────────┴──────────────────────────────┘
 ◄────── L1 (0.25~0.3 L) ──────► ◄────────────── L2 (0.4~0.5 L) ──────────────► ◄────── L3 (0.25~0.35 L) ─────►
```

1. **Зо́на пита́ния（加料段 / 输送区）**：
   * 固态塑料颗粒由料斗（бу́нкер）靠重力落入螺槽，在旋转螺杆推动下压实成固体塞向前推移。
   * 此区段需保持恒定冷却循环水，防止颗粒过早粘结在料口产生“架桥搭桥”事故。
2. **Зо́на сжа́тия / пластика́ции（压缩段 / 熔融塑化区）**：
   * 螺槽深度沿轴向逐渐变浅，产生极大径向压力；配合机筒外部加热圈（электронагрева́тели）与物料剪切粘性耗散生热，塑料颗粒完全熔融塑化为均匀连续熔体。
   * **Сте́пень сжа́тия（压缩比 $\beta$）**：加料段与计量段螺槽深度之比（$\beta = H_1 / H_3$），常规通常在 $2.5 \sim 4.0$ 之间。
3. **Зо́на дози́рования（计量段 / 均化段）**：
   * 螺槽最浅且等深，将熔融均化的物料定量、定压、定温推入成型模头。
   * **Отноше́ние $L/D$（长径比）**：螺杆工作长度与外径之比，现代挤出机通常为 $25 \sim 36$。

#### 挤出生产线核心组件（Ли́ния экстру́зии）

* **Материа́льный цили́ндр**（机筒 / 料筒）与 **Шнек (червя́к)**（螺杆）
* **Форму́ющая голо́вка (филье́ра)**（挤出机头 / 口模）：
  * **Дорн**（芯模 / 芯棒）与 **Ма́трица**（外口模圈）配合形成环形截面，挤出管材或电缆外套。
* **Калибра́тор**（定径套 / 定型套）：真空或内压定径，精确控制管材外径与圆度。
* **Охлажда́ющая ва́нна**（喷淋冷却水箱 / 水槽）。
* **Тя́нущее устро́йство**（牵引机）：履带式或皮带式恒速牵引。
* **Отрезно́е устро́йство / Намо́тчик**（切断机 / 卷取机）。

### 5.2 注塑成型工艺（Литьё под давле́нием · ТПА）

注塑成型是利用**注塑机（термопластавтома́т · ТПА）**在高压下将受热熔化的塑料注入闭合的模具型腔内，经过冷却定型后脱模获得高精度三维复杂制品的周期性成型方法。

#### 1. 注塑机两大核心总成

* **У́зел пластика́ции и впры́ска（塑化注射装置）**：包含料筒、往复旋转螺杆、止逆环止逆阀（обра́тный кла́пан）以及液压/伺服注射油缸。螺杆兼具熔融塑化与活塞推料注射双重功能。
* **У́зел смыка́ния и запира́ния（合模与锁模装置）**：液压缸或双曲肘机械连杆（коле́нно-рыча́жный механи́зм），提供巨大的锁模力（уси́лие смыка́ния），抵抗熔体注入型腔产生的高压胀模。

#### 2. 注塑模具结构系统（Пресс-фо́рма）

* **Литнико́вая систе́ма（浇注系统）**：
  * **Центра́льный литни́к**（主流道）
  * **Разводя́щие кана́лы**（分流道）
  * **Впускно́й литни́к (воро́та)**（浇口 / 点浇口 / 潜伏浇口）
* **Оформля́ющая по́лость（成型模腔零件）**：
  * **Ма́трица**（凹模 / 定模部分，成型制品外表面）
  * **Пуансо́н**（凸模 / 动模芯，成型制品内表面）
* **Систе́ма охлажде́ния（温控冷却水道）**：
* **Систе́ма выта́лкивания（顶出脱模系统）**：顶针（толка́тели）、推板（плита́ выта́лкивателей）。

#### 3. 注塑生产循环各阶段（Ста́дии литьево́го ци́кла）

```
[1. Набо́р до́зы] ──► [2. Смыка́ние фо́рмы] ──► [3. Впрыск под давле́нием]
  塑化计量与回退          合模闭紧锁模              高速高压充模
                                                       │
                                                       ▼
[6. Выта́лкивание] ◄── [5. Размыка́ние] ◄── [4. Вы́держка под давле́нием и охлажде́ние]
  顶针顶出制品            开模移动动模             保压补缩 + 模内冷却固化
```

1. **Смыка́ние фо́рмы**（合模）：动模移向定模并施加额定锁模力。
2. **Впрыск (инже́кция)**（注射充模）：螺杆如活塞快速向前推进，以极高注射压力（давле́ние впры́ска $80 \sim 180\ \text{MPa}$）将熔体压入型腔。
3. **Вы́держка под давле́нием（保压补缩）**：熔体冷却发生体积收缩，螺杆持续施加保压压力（давле́ние подпи́тки），补充注入熔体，防止制品出现缩水痕迹。
4. **Охлажде́ние и пластика́ция（冷却与预塑化计量）**：浇口冻结后，模具继续循环水冷却制品；同时螺杆旋转后退，塑化下一次注射所需的料量（до́за впры́ска）。
5. **Размыка́ние фо́рмы и выта́лкивание（开模与顶出）**：模具打开，顶针推出固化成型的塑料成品。

#### 4. 常见注塑缺陷成因与排除（Дефе́кты литья́）

| 缺陷名称（俄文） | 中文名称 | 外观表现特征 | 产生原因（Причи́ны） | 工业解决对策（Реше́ния） |
|---|---|---|---|---|
| **Недоли́в / Недозаполне́ние** | 欠注 / 短射 | 制品边缘末端残缺不全，未充满模腔 | 注射压力过低、熔体温度低、注射量不足或排气不良 | 提高注射压力与速度；升高料温模温；增大注射行程；清理排气槽 |
| **Обло́й / Грат** | 飞边 / 毛刺 | 制品分型面或顶针四周溢出薄塑料边 | 锁模力不足、注射压力过大、模具分型面受损磨损或有异物 | 增大锁模力；降低注射压力和保压；检修分型面密合度 |
| **Уса́дочные ра́ковины (утя́жины)** | 缩孔 / 缩陷 | 制品厚壁表面凹陷、内部形成真空孔洞 | 保压压力过低或保压时间太短；壁厚设计不均匀 | 延长保压时间；提高保压压力；增加冷却；优化壁厚过渡 |
| **Спа́йные ли́нии (холо́дные сты́ки)** | 熔接痕 / 熔接线 | 两股或多股熔体前沿汇合处出现可见细缝或强度低下 | 汇聚时熔体温度太低、流速慢、排气孔不通畅 | 提高料温与模具温度；加快注射速度；优化浇口位置避开受力区 |
| **Коробле́ние (пово́дка)** | 翘曲变形 | 制品从模具取出后发生弯曲扭曲变形 | 模内冷却不均、制品不同部位收缩率相差过大、脱模内应力大 | 优化模具冷却回路布局；降低注射压力；延长模内冷却定型时间 |
| **Серебря́ные поло́сы (серебря́нка)** | 银丝纹 / 气痕 | 制品表面沿流动方向呈现白色银光细丝条纹 | 原料含水分未烘干、熔体过热降解挥发气泡或吸卷空气 | 强化原料前处理干燥（су́шка грану́л）；适当降低熔融温度 |

### 5.3 吹塑中空成型（Вы́дувное формова́ние）

用于制造各类中空容器（塑料瓶、壶、油箱、化工桶）：
1. **Экструзио́нно-вы́дувное формова́ние (EBM)**：先挤出管状热熔型坯（паризо́н / загото́вка），模具合拢夹住型坯切断，通入压缩空气（сжа́тый во́здух $0.4 \sim 0.8\ \text{MPa}$）将型坯贴壁吹胀成型。
2. **Инжекцио́нно-вы́дувное формова́ние с растяже́нием (ISBM)**：先注塑成型带螺纹口的冷管坯（префо́рма），再加热轴向拉伸并吹胀（ПЭТ 矿泉水瓶标准生产工艺）。

---

### 5.4 压延工艺（Каландри́рование）

利用一组平行排列、反向旋转的重型加热辊筒（валки́ кала́ндра，I形、L形、Z形布置），将经过密炼塑化的物料经多次辊隙挤压延展，制成连续均匀薄膜、片材或与织物贴合复合（лино́леум, иску́сственная ко́жа）。
* **Кали́бр / зазо́р**（辊隙开度）：控制成品膜厚度精度。
* **Фри́кция**（辊速比）：相邻两辊筒转速不同产生的摩擦剪切，有助于薄膜表面光泽平整。

---

### 5.5 模压成型（Прессова́ние）

主要用于热固性塑料（реактопла́сты，如电木胶木粉、SMC/BMC 玻璃钢复合材料）及橡胶硫化：
* **Прямо́е прессова́ние（直接压制）**：将预热物料置于敞开加热模腔中，液压机合模施压（$10 \sim 30\ \text{MPa}$），物料流动充满型腔并在高温高压下发生化学不可逆交联固化（отвержде́ние）。

---

### 5.6 聚合物回收再利用（Реци́клинг полиме́ров）

工业废料与消费后塑料（потреби́тельские отхо́ды）的循环闭环：
1. **Сортиро́вка**（按树脂品种自动或人工分选）
2. **Измельче́ние (дробле́ние)**（破碎机 дроби́лка 制成片状碎屑 дро́бленка）
3. **Отмы́вка и су́шка**（洗涤清洗去油污并离心脱水烘干）
4. **Компаунди́рование и фильтра́ция распла́ва**（熔体过滤除杂并补加抗氧稳定剂）
5. **Грануля́ция**（造粒机 экстру́дер-грануля́тор 切制成均匀圆柱形再生颗粒 втори́чный грануля́т）

## 六、车间现场工程指令与工艺术语（Практи́ческие фра́зы и кома́нды）

在工厂车间、实验室和工艺设计中，科技俄语遵循高度规范的操作祈使句式：

* `Увели́чьте давле́ние вы́держки для устране́ния утя́жин на деве́ти.`
  提高保压压力以消除制件上的缩陷。
* `Температу́ра распла́ва по зо́нам цили́ндра соста́вит: 180°C — 200°C — 210°C — 205°C.`
  料筒各区段熔体温度设定为：180°C — 200°C — 210°C — 205°C。
* `Пе́ред загру́зкой в бу́нкер полиами́д необходи́мо вы́сушить до вла́жности не бо́лее 0.2%.`
  在装入料斗之前，聚酰胺必须干燥至含水率不超过 0.2%。
* `Ско́рость враще́ния шне́ка составля́ет 60 оборо́тов в мину́ту.`
  螺杆转速为每分钟 60 转。
* `Прове́рьте чистоту́ кана́лов охлажде́ния пресс-фо́рмы.`
  检查注塑模具冷却水路的畅通与清洁。
* `Не допуска́ется превыше́ние температу́ры деструкции во избежа́ние выделе́ния лету́чих га́зов.`
  严禁超过降解温度，以免析出挥发性气体。

## 八、自测与习题（Упражне́ния）

### 8.1 工艺选择匹配题

请将下列塑料制品与其最经济合理的成型加工工艺用线连接：
1. Напо́рная полиэтиле́новая труба́ для водопрово́да (高压供水 PE 管)
2. Ко́рпус моби́льного телефо́на из поликарбона́та (PC 手机精密外壳)
3. Пла́стиковая бути́лка для газиро́ванной воды́ (碳酸饮料 PET 瓶)
4. Лино́леум из пластифици́рованного ПВХ (软质 PVC 塑料地板革)

> [!success]- 点击展开核对答案
> 1. $\to$ **Экстру́зия**（连续挤出定径成型，生产无限长均匀直管）。
> 2. $\to$ **Литьё под давле́нием (на ТПА)**（精密注塑成型，获得复杂薄壁与高光洁度）。
> 3. $\to$ **Вы́дувное формова́ние (ISBM)**（注拉吹中空成型，高强度薄壁透明容器）。
> 4. $\to$ **Каландри́рование**（辊筒连续压延复合，成卷宽幅高平整度面层）。

### 8.2 缺陷排查简答题

在生产聚丙烯（ПП）较厚壁制品的注塑试验中，发现制品加强筋背面频繁出现深陷的**凹痕（усадочные раковины）**，且分型面边缘出现了轻微的**飞边（облой）**。请从工艺参数（温度、压力、保压时间、锁模力）角度提出两项调整措施。

> [!success]- 点击展开核对答案
> 1. **消除缩陷（усадочные раковины）**：延长**保压时间（вре́мя вы́держки под давле́нием）**，使浇口充分保持打开补缩；同时可适度提高保压压力，补偿厚壁处的体积收缩。
> 2. **消除飞边（облой）**：适当降低**注射压力（давле́ние впры́ска）**和保压峰值；或者提高合模机构的**锁模力（уси́лие смыка́ния）**；检查模具分型面是否有微细异物阻碍完全闭合。
